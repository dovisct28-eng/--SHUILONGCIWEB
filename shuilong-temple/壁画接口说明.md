# 壁画位置与高清探索接口

五幅壁画以青绿色墙面区域和金色边线占位，不包含壁画内容。编号按钮通过虚线连接真实墙面位置；屋顶或墙体可能遮挡区域，可隐藏屋顶并旋转模型核对。编号是定位标注，不表示壁画在屋顶上。

最新调整：主殿向后增加进深，第二、第五幅沿两侧墙展开，暂定宽高比为 5.5:2（2.75:1）。第三、第四幅随后墙后移，后墙处的柱子和木板已删除。前檐柱保留。院落、戏台及第一幅位置不变，底座与主殿屋顶同步向后延伸。这些比例仍为示意值。

以入口朝主殿看：第一幅在右廊内墙，整个区域越过戏台靠主殿一端；第二幅在主殿右内墙；第三幅在后墙右侧；第四幅在后墙左侧；第五幅在主殿左内墙。位置依据示意图，墙面高度和画幅大小为暂定值，并非实测尺寸。

## 接入高清探索

在预览页面的同一 window 上监听事件：

```js
window.addEventListener('shuilong:mural-select', (event) => {
  event.preventDefault(); // 接管交互，隐藏内置占位提示
  const { id, label, wall, position } = event.detail;
  // 将 id 映射到你开发中的高清壁画资源或路由。
  // openYourMuralExplorer(id);
});
```

稳定 ID 为 `mural-01` 至 `mural-05`。默认只显示入口占位提示，不会跳转到尚未实现的探索页面。

```js
window.shuilongTemple.getMurals(); // 返回五幅壁画配置的副本
window.shuilongTemple.selectMural('mural-01'); // 触发同一选择流程
window.shuilongTemple.replayIntro(); // 重播完整开场
window.shuilongTemple.getIntroState(); // 开场状态、旋转进度和镜头状态
```

拖动超过 6 像素、多指操作或取消手势不会触发墙面点击。编号按钮支持键盘操作。直接点击墙面遵循遮挡关系；编号按钮可用于选择被屋顶遮挡的壁画。

开场期间编号隐藏，选择接口返回 false；开场结束后恢复。可监听 `shuilong:intro-start` 与 `shuilong:intro-complete` 事件。完成事件只在完整旋转一周、生长结束及镜头复位后派发。

GLB 新增五个独立节点，名称与 ID 相同，节点的 `extras.mural` 保存编号、位置、画幅和所在墙面。`mural-locations.json` 提供相同配置。坐标 Y 向上，+Z 为入口方向，-Z 为主殿方向。第一幅中心 Z=4.8、范围 Z=3.2～6.4；戏台屋顶靠主殿的边缘约 Z=6.85，因此第一幅整体位于戏台朝主殿一侧。

如果通过 iframe 嵌入，此事件只在预览自己的 window 中派发，不会自动跨 iframe；应在预览内监听后接入你自己的通信层，并验证接收来源。
