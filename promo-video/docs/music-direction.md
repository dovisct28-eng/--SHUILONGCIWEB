# 配乐深化提案 · P1.1 / 130秒

2026-10-15，根据用户“配乐丰富一点、好听一点”修订。以下是创作建议，没有生成、选定或试听任何音乐，不能据文字方案宣布听感已通过。当前维持纯器乐、无歌词、无旁白方向。

## 1. 听感目标

希望观众在开场记住一个简短主题，在A03听到它展开，在图鉴段感到轻盈与探索，在交互段听见清楚的操作反馈，高潮时认出主题的更宽广变奏，最后由同一主题收束。情绪从好奇、走近、主动探索，走向开阔和回望。

主风格建议为东方旋律与电影配器的融合。古筝负责颗粒和清晰线条，箫提供呼吸与长句，弦乐承担和声及情绪展开，低音/打击支撑空间感，少量电子纹理连接数字界面。所有音色是现代影片创作选择，不称为勾蓝瑶传统曲目、当地仪式原声或历史复原音乐。

## 2. 一个主题，逐段变化

暂拟一个四小节主题，可先从`1–降3–4–5｜降7–5–4–降3`的轮廓发展，片尾回主音。它只表示待作曲的音高轮廓，节奏、调性、装饰音与具体旋律仍需打样；不引用现成曲牌或流行旋律。

创作时让主题有可哼出的起伏、停顿与回答，约每8–16秒形成一次清楚的乐句走向。和声可从开放五度及小调延伸和弦出发，逐渐增加温暖的转位/对旋律，高潮扩展音区，片尾形成可感知的解决。不要把“东方”简化为全程同一五声音阶琶音。

编辑参考120BPM、4/4，每小节2秒；主旋律按半拍速约60BPM的舒展感演奏。130秒约65小节，可在段落入口用弱起、延音和乐句跨越处理镜头切点；不是所有镜头都要硬卡强拍。最终采用授权音乐时，以其真实结构重新对齐，并更新全部时码。

## 3. 分段配器

| 时间 | 主旋律与和声发展 | 节奏与层次 | 希望产生的感受 |
| --- | --- | --- | --- |
| 0–6秒 | 2–3个有间隔的古筝音建立主题，暗弦长音承托 | 气息与低频轻起，不连续铺鼓 | 材料从暗处被发现，第一耳就有旋律线索 |
| 6–15秒 | 古筝完成短句，10秒建筑揭示时弦乐和声展开 | 一次低鼓和低音进入，随后给标题稳定空间 | 空间打开，有向前的吸引力 |
| 15–23秒 | 主题开始完整陈述，弦乐形成轻对旋律 | 低音推动，少量木质轻打击 | 走近建筑与壁画位置 |
| **23–29秒 / A03** | **24–28秒箫接过主题，古筝应答，长弦提供开阔和声** | **保留4秒稳定乐句，不密集堆重音；28秒用拾音承接路线** | **让“出庙／入庙”的主题关系被记住** |
| 29–45秒 | 弦乐接续主题，经过路线和三幅图像后留半句呼吸 | 轻鼓/低音逐步推进；第五与第一幅各3秒保持连续旋律 | 路线可理解，各幅图像有独立存在感 |
| 45–65秒 | 古筝变奏、木管短答，加入少量弦乐对位 | 轻打击和稀疏电子琶音产生探索感 | 明亮一些、轻盈一些，不挤压点击和文字 |
| 65–73秒 | 保留主题片段，减少中低频密度 | 低音脉冲逐步建立，为手势输入留空间 | 身体介入前有期待感 |
| 73–100秒 | 主题片段与弦乐交替，OPEN时适度展开，阅读处减层 | 75/87/97秒单次确认音；稳定驻留期间不堆高频声效 | 看得懂也听得出输入与反馈的关系 |
| 100–116秒 | 弦乐主奏完整主题的高音区变奏，古筝错位应答，箫长音支撑 | 低音、电影鼓和适量电子宽度形成全片最大层次；保留主次 | 有旋律的高潮，内容与情绪共同放大 |
| 116–120秒 | 收回对旋律，逐层撤鼓与电子脉冲 | 下降至留白，给理念字幕空间 | 向文化对象收束 |
| 120–130秒 | 回到古筝开场主题，箫一句应答，薄弦解决和声 | 撤去节拍，尾音自然结束 | 记得住作品，有完成感 |

## 4. 可编辑音轨分工

建议保留六组音乐分轨，另将交互音效独立成轨。音乐层不要求同时全开。

| 分轨 | 职责 | 调整原则 |
| --- | --- | --- |
| M1 古筝 | 主主题、颗粒感和分解和弦 | 主奏时留出频段；应答时降低存在感 |
| M2 箫/木管 | A03主题陈述、句间回应、尾声 | 保留呼吸，避免整片连续吹奏 |
| M3 弦乐 | 和声、对旋律、高潮主奏 | 逐段改变音区和密度，演奏层次有起伏 |
| M4 低音 | 低频根基、柔和脉冲 | 和电影鼓错开冲击，保护听感清晰 |
| M5 打击 | 揭示重音、路线推进与高潮支撑 | 图鉴轻、交互局部退后、片尾撤去 |
| M6 电子纹理 | 数字空间的空气和少量琶音 | 以连接段落为主，旋律仍清楚可辨 |
| SFX | 点击、驻留确认、面板开合 | 一次输入对应一次有效反馈；与音乐分开调音 |

NEXT、OPEN、CLOSE确认声必须与F2250、F2610、F2910对齐。音乐在这些瞬间做短暂、平滑的局部让位，确认声不必很响。驻留声可随进度轻微变化，不能掩盖或抢先宣布动作已完成。

## 5. 进入制作后的试听与选择

分镜获准进入制作后，先做两段试听：一段覆盖建筑→A03→路线，检验主题是否动听且连续；另一段覆盖交互→高潮→片尾，检验层次、冲击和主题回归。它们是后续试听任务，本轮没有生成。

建议在相同感知响度下比较候选，而非用更响的版本占优势；用耳机和普通扬声器各听一次。重点判断主题是否可记住、音色是否清楚、高潮是否来自旋律与和声发展、长段是否疲劳、反馈音是否可辨、结尾是否自然。听感由实际试听和用户选择确认，自动化只能检查时码、峰值与响度等技术项。

如果使用生成配乐，在当前可用工具与用户确认的纯器乐方向下提交；如果选现成曲目，先核对比赛展示、网络传播、剪辑改编及署名许可，避免与匿名要求冲突。所有音乐来源、许可和编辑点进入素材清单；不根据文本方案宣称版权已解决。
