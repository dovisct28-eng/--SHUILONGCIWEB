# 《出兵入将》120 秒完整分镜 · 规划稿

版本P1，2026-10-15。待用户审阅；**没有制作或导出视频**。逐镜唯一时码源为`../planning/timeline.json`，30镜、3600帧；[shot-list.md](shot-list.md)按该配置生成。

创意主线：**空间让观众找到壁画；选择让观众进入人物；手势让身体参与探索。** 片头用原壁画线势与真实建筑轮廓连接，片尾回到原壁画，形成可辨认的首尾呼应。影片允许独立镜头设计，网页仍保持其原有观看逻辑。

## 2. 镜头导演决策

S01：首0.4秒只做低幅度暗入，不让前5秒成为空黑等待。纹理取真实第二幅已有图，沿画面原有笔线移动；“线条与建筑连接”采用方向匹配剪辑，避免把壁画扭曲成建筑。6–10秒在同一真实GLB上后撤揭示；10秒重音落在完整建筑出现，标题10–15秒有稳定阅读时间。原壁画不受模拟扫光调色，扫光只作用于建筑/外层显现遮罩。

S02：以真实页面操作建立可信度，电影运镜集中放在S01/S05。当前A02没有360度自由环绕，不新增此网页功能。A04源录制保留完整45秒；影片23–28秒只选取停靠和转向的原速代表片段，通过切点表达省略，不能把45秒加速成5秒。28–32秒给第五与第一幅各约2秒幅名及独立图像，32–35秒回到第二幅和A08点击。影片是节选，不宣称完成三幅全文阅读；原网页完整导读不缩短。

S03：以鼠标拖动、缩放、热点和索引选择为视觉动词，原壁画→线稿→数字色稿是实际可用切换。影片用“原壁画”替代任务书笼统的“原稿”，避免把数字线稿当原物。细节放大通过影片构图实现时标“图像对照”，不伪造B02新增手势或工具。01三图尺寸相同，但仍需实际画面锚点对齐；figure画布不同，不混成第四个配准图层。人物02切换后只保留必要介绍，不塞满正文。

S04：按现行单手驻留逻辑重写原任务书中宽泛的动作表达。匿名骨骼为程序动画，只有同一控制手产生光标；先稳定，再进入目标，驻留完整约1秒后才触发。NEXT后必须移开释放，再进行OPEN。阅读态不切人，用上/下阅读区域表示滚动，稳定死区表示停止，最后用同一view目标CLOSE。保留真实布局的右侧正文和环绕图像面板，不把环绕图像改成虚构历史知识节点。

S05：不是再示范未经解释的手势触发。人物切换属于影片剪辑，图像面板只用已有真实局部或已标数字演绎素材。原壁画、数字人物和模型墙面分层，有限透视与视差建立纵深；不变形人物四肢，不将多个人物拼回原壁画，不设计不存在的古代符号。90–105秒无主字幕，105–109秒才落一句理念。

S06：数字人物退出后切回原壁画，不能用无标识变形让观众误以为数字色稿是原件修复。110–114秒缓慢拉远，114–117秒文字收束；117秒标题进入，最后12帧淡出，尾音结束于120秒。

## 3. 关键手势时点

| 动作 | 输入与确认 | 触发 | 反馈与释放 |
| --- | --- | --- | --- |
| NEXT | 63秒靠近；64–65秒稳定驻留 | 65秒 / F1950 | 67秒前完成主要切换；71–71.4秒目标外释放 |
| OPEN | 75秒移入；76–77秒稳定驻留 | 77秒 / F2310 | 到77.8秒展开；80–80.4秒移开，随后阅读 |
| CLOSE | 85秒移入；86–87秒稳定驻留 | 87秒 / F2610 | 到87.8秒收拢；88.667–89.067秒移开 |

这些是影片关键帧计划，不是相机实测延迟。NEXT人物资源若真实录屏耗时较长，完整源录制保留等待，影片可以切掉加载停顿但不能声称为实测“瞬时响应”。输入骨骼和反馈均在同一整数帧时间轴上驱动，禁止两个独立计时器漂移。

## 4. 字幕、角标与版式

19条主字幕已独立编排至`timeline.json`与规划SRT。主字幕单通道不重叠，正文通常3–5秒、两行以内；章名约3秒。暖白为主，少量金色只用于重点。建议1080p说明字幕42–46px、章名56–68px、片名100–128px，均为待打样值，不能直接当最终冻结值。

基础安全区为画幅左右96px、上下72px。说明字幕优先落在底部内容安全带（候选y=906–996）；B03底部驻留控制占用时，将说明字幕移至顶部独立空区。角标候选28–30px、无厚底板、对比可辨；必须按实际按钮和人物有效轮廓重新测量，不能仅按坐标判断不遮挡。必要时减少面板而不是缩小字幕至不可读。

55–90秒持续显示“交互效果模拟演示”，并保留数字化演绎标识。90–110秒标“设计合成 · 数字化演绎”，不显示“摄像头已连接”“实时识别成功”等没有实测依据的字样。23–32秒另标“项目数字观看路径”，防止把模型路径当历史观看顺序。线稿/色稿对照均有图像类型标签，数字色稿不得脱离其演绎说明。

字幕采用6–8帧淡变作为候选，不遮住驻留环完整的增长过程。SRT不含持续角标；角标与字体、位置、入出动画保存在配置中独立管理。静音审片时应能从点击、驻留环和文字理解主要因果。

## 5. 音乐与音效设计

创作建议采用无歌词器乐与少量自制/合法授权音效，暂不配旁白。此为方案选择，未生成音乐、未消耗生成额度，也未确认某首音乐许可。

| 时间 | 音乐走向 | 音效与同步点 |
| --- | --- | --- |
| 0–15秒 | 低频空气、弱弦/拨弦音色，10秒揭示重音 | 3秒纹理/屋檐匹配切轻擦音；10秒低鼓 |
| 15–35秒 | 建立克制脉冲，给空间关系留时间 | 定位音跟随真实标记，不伪作传统仪式原声 |
| 35–55秒 | 旋律清晰，操作切点保持轻量 | 热点选择、两次三图切换各一次反馈 |
| 55–63秒 | 乐器减薄，突出输入 | 跟踪音弱于音乐，不满屏蜂鸣 |
| 63–90秒 | 回到稳定节拍 | 65、77、87秒三次确认；展开/收拢首帧声画同点 |
| 90–110秒 | 全片高潮，随后逐渐收束 | 94、98、102秒视觉切点重音；避免每个面板都有爆炸音 |
| 110–120秒 | 撤鼓、保留尾音 | 120秒自然结束，无突然截断 |

参考起点可用120BPM的半秒节拍网格，但必须以最终授权音乐结构调整，不能把临时网格当已完成配乐。所有调整仍保持六段边界和总帧数。混音候选整体约−16 LUFS、真峰值≤−1dBTP，属于本片工作目标，不是赛事已核实硬性要求；实际试听和响度测量在制作后执行。
