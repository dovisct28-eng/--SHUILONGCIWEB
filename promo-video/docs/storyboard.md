## 2. 镜头导演决策

S01：首0.4秒只做低幅度暗入，不让前5秒成为空黑等待。纹理取真实第二幅已有图，沿画面原有笔线移动；“线条与建筑连接”采用方向匹配剪辑，避免把壁画扭曲成建筑。6–10秒在同一真实GLB上后撤揭示；10秒重音落在完整建筑出现，标题10–15秒有稳定阅读时间。原壁画不受模拟扫光调色，扫光只作用于建筑/外层显现遮罩。

S02：以真实页面操作建立可信度，电影运镜集中放在S01/S05。15–23秒是A02建筑与位置；23–29秒独立展示A03。A03沿用现有左上“入庙”、右下“出庙”的巨型宋体，真实建筑在文字前形成遮挡，保留顶部“出兵入将”和两段说明；先建立主题关系，不提前播放路线。23–24秒入场，24–28秒稳定，28–29秒接A04。辅助字幕放在原正文和标题之外，无法避让时取消这条辅助字幕，不能盖住原文或改网页。

29–36秒选取A04停靠、转向和回撤的原速代表画面；源录制仍保留完整45秒，剪辑省略清楚可辨。36–42秒给第五与第一幅各约3秒独立展示，42–45秒回到第二幅和A08点击。影片是节选，不宣称完成三幅全文阅读；网页导读不缩短。当前A02没有360度自由环绕，不新增此网页功能。

S03：以鼠标拖动、缩放、热点和索引选择为视觉动词，原壁画→线稿→数字色稿是实际可用切换。影片用“原壁画”替代任务书笼统的“原稿”，避免把数字线稿当原物。细节放大通过影片构图实现时标“图像对照”，不伪造B02新增手势或工具。01三图尺寸相同，但仍需实际画面锚点对齐；figure画布不同，不混成第四个配准图层。人物02切换后只保留必要介绍，不塞满正文。

S04：按现行单手驻留逻辑重写原任务书中宽泛的动作表达。匿名骨骼为程序动画，只有同一控制手产生光标；先稳定，再进入目标，驻留完整约1秒后才触发。NEXT后必须移开释放，再进行OPEN。阅读态不切人，用上/下阅读区域表示滚动，稳定死区表示停止，最后用同一view目标CLOSE。保留真实布局的右侧正文和环绕图像面板，不把环绕图像改成虚构历史知识节点。

S05：人物切换属于影片剪辑，图像面板只用已有真实局部或已标数字演绎素材。原壁画、数字人物和模型墙面分层，有限透视与视差建立纵深；不变形人物四肢，不将多个人物拼回原壁画，不设计不存在的古代符号。100–115秒无主字幕，115–119秒才落一句理念。

S06：数字人物退出后切回原壁画，不能用无标识变形让观众误以为数字色稿是原件修复。120–124秒缓慢拉远，124–127秒文字收束；127秒标题进入，最后12帧淡出，尾音结束于130秒。

## 4. 字幕、角标与版式

20条主字幕已独立编排至`timeline.json`与规划SRT，新增A03辅助解释。主字幕单通道不重叠，正文通常3–5秒、两行以内；章名约3秒。暖白为主，少量金色只用于重点。建议1080p说明字幕42–46px、章名56–68px、片名100–128px，均为待打样值，不能直接当最终冻结值。

基础安全区为画幅左右96px、上下72px。说明字幕优先落在底部内容安全带（候选y=906–996）；B03底部驻留控制占用时，将说明字幕移至顶部独立空区。角标候选28–30px、无厚底板、对比可辨；必须按实际按钮和人物有效轮廓重新测量，不能仅按坐标判断不遮挡。必要时减少面板而不是缩小字幕至不可读。

65–100秒持续显示“交互效果模拟演示”，并保留数字化演绎标识。100–120秒标“设计合成 · 数字化演绎”，不显示“摄像头已连接”“实时识别成功”等没有实测依据的字样。29–42秒另标“项目数字观看路径”，防止把模型路径当历史观看顺序。线稿/色稿对照均有图像类型标签，数字色稿不得脱离其演绎说明。

字幕采用6–8帧淡变作为候选，不遮住驻留环完整的增长过程。SRT不含持续角标；角标与字体、位置、入出动画保存在配置中独立管理。静音审片时应能从点击、驻留环和文字理解主要因果。

## 5. 音乐与音效设计

配乐深化为有辨识度的东方主题旋律、电影弦乐与适量电子层次，保留无歌词器乐和无旁白方向。丰富度通过旋律变奏、器乐应答、和声、音区及密度进退来实现。详细作曲/编曲提案见[music-direction.md](music-direction.md)，可编辑分段和重音点已写入`timeline.json.audio`。未生成音乐、未消耗额度、未选择具体曲目或确认许可；是否好听仍需真实音频试听。

| 时间 | 音乐走向 | 音效与同步点 |
| --- | --- | --- |
| 0–15秒 | 古筝先呈示短主题，薄弦和空气层逐步进入，10秒和声打开 | 3秒纹理/屋檐轻擦音；10秒低鼓 |
| 15–45秒 | 主题扩成乐句；A03交给箫和长弦，随后低音与轻鼓推动路线 | 24秒旋律交接；定位音跟随真实标记 |
| 45–65秒 | 古筝分解和弦、木管短应答、弦乐对旋律，节奏更轻盈 | 热点选择、三图切换轻点，不盖旋律 |
| 65–100秒 | 先减层突出输入，再建立脉冲与渐强；阅读处保持旋律空间 | 75、87、97秒三次确认，音乐局部让位 |
| 100–120秒 | 弦乐扩展主旋律、古筝错位应答、低音与鼓形成高潮；116秒起减层 | 104、108、112秒镜头重音；不持续满编制 |
| 120–130秒 | 撤鼓回到开场主题，箫留应答，和声解决后自然尾音 | 130秒结束，无突然截断 |

提案以120BPM的编辑网格、约60BPM的舒展听感组织长乐句；每个2秒小节并不都要出现鼓点。主题允许跨镜头延续，操作确认音仍严格落触发帧。粗剪若需要更长时长，应同时调整镜头、字幕和乐句，不把尾部拉长为重复循环。混音候选整体约−16 LUFS、真峰值≤−1dBTP，属于工作目标而非赛事硬性要求；试听和响度测量尚未执行。
