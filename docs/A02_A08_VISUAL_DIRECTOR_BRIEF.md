## 8.1 建筑光照

- 建筑内部继续沉入阴影；
- 不同材质仍可被辨认。

目标：

> 从“模型被展示”
>

>
> “建筑从暗处被观看”。

它们应像：

共享：

- 深色图像空间；
- 同一字体；
- 同一尺度；
- 同一滚动逻辑；
- 同一介绍结构；

- 同一遮罩退场方式。

区别只来自：

# 58. 最终交付格式

完成后必须报告：

## 本次完成

逐项说明 A02–A08。

## 视觉变化

明确：

- A02；
- A03；
- A04；
- A04→A05；
- A05–A07；
- A08。

## 建筑真实性

明确确认：

> 本轮没有使用 AI 生成的错误建筑替换项目水龙祠设计模型。

## 测试

列出：

- unit；
- browser；
- regression；
- responsive；
- reverse；
- resize；
- refresh；
- reduced motion。

## 性能

列出重要变化。

## 文档

列出更新文件。

## Git

给出：

- commit SHA；
- push 状态；
- GitHub `master` 核实结果。

## 剩余问题

如果仍有：

- 字体；
- Accent；
- 色值；
- 极小视觉 polish；

明确列为后续视觉冻结项目。

# 59. 最终原则

如果需要在：

> “多做视觉效果”

和

> “保持项目模型的资料约束、真实壁画和清晰叙事”

之间选择，

始终选择后者。

整个模块最终应该让用户感觉：

> 一开始，设计带我进入水龙祠。
>
> 后来，建筑告诉我壁画在哪里。
>
> 再后来，我沿着空间来到壁画面前。
>
> 最后，建筑和界面都退开，只剩下壁画。
>
> 接下来，由我自己观看。
