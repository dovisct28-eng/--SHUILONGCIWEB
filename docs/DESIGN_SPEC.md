# 设计规格（DESIGN_SPEC）

> 本文件只描述实际的网页设计和交互逻辑，不描述研究背景与具体代码实现。项目背景见 PROJECT_CONTEXT.md。

## 模块 A：水龙祠壁画叙事引导页面

滚动驱动的空间与叙事变化：通过滚动控制镜头移动、空间缩放、建筑平面变化、壁画横向移动、信息出现/隐藏、视觉焦点变化。

### A01 开屏

- **目标**：建立水龙祠的空间认知。
- **内容**：水龙祠建筑/建筑平面；平面生长或空间生成动画；简短介绍；向下探索提示。
- **约束**：文字必须克制，不要做成历史资料首页。

#### A01 交互统一规格（2026-09-21 用户确认）

- **连续叙事**：空间穿越 → 建筑旋转生长 → 建筑右移 → 左侧文字浮现，四阶段属于同一段滚动驱动体验。
- **旋转完全随滚动**：旋转、生长、位移及文字显现均由滚动进度决定；向下推进、向上还原、停止滚动即保持当前状态。同一进度应得到相同画面，不依赖自动播放时间或此前是否完成动画。
- **壁画标记延后**：A01 全程及末尾阅读区间不显示壁画编号、定位标记或路线高亮；进入 A02 后再呈现。最终 Hero 为左侧标题、主题与简短介绍，右侧完整建筑，底部继续探索提示。该构图不代表壁画同墙由右向左排列，建筑模型也不得镜像。
- **阅读滚动区间**：四阶段动画完成后，设置独立的滚动距离区间，保持最终 Hero 构图和文字不变；滚过该区间后再进入 A02。反向滚动先返回稳定阅读状态，越过阅读区间起点后再反向还原 A01 动画。无需强制等待新的滚轮手势，也不设置自动倒计时。
- **初始参数**：动画段暂按 0%—20% 空间穿越、20%—65% 旋转生长、65%—82% 建筑右移、82%—100% 左侧文字浮现划分；阅读区间位于该动画段之后，不挤占上述比例。进入 A02 时建筑由右侧连续回到中央，再由 A02 引入壁画标记。动画滚动总距离、旋转角度及阅读区间长度由低保真原型验证后确定。
- **验收重点**：正反向跨阶段连续；停滚后状态稳定；阅读区间内建筑不再旋转或移动、文字完整可读；A01 与 A02 往返时壁画标记按边界显示或隐藏。
- **参考冲突处理**：Figma 草稿中的“自动旋转”和 A01 建筑移动后立即标出壁画位置，以本节确认结果为准。现有三维模型预览的自动开场仅作独立演示参考，不代表 A01 已实现上述交互；Figma 注释与原型代码尚待后续同步。

### A02 建筑空间

- 通过 Scroll 呈现：水龙祠整体 → 建筑布局 → 壁画位置。
- **目标**：让用户知道“壁画在哪里”。
- **承接 A01**：完成 A01 末尾阅读滚动区间后进入本阶段，再按滚动进度引入壁画编号、定位标记及相关空间说明；退回 A01 时隐藏这些标记。
- **空间基准**：以用户提供的布局示意图和站位说明为准。观众站在主殿、面向戏台时，身体右侧为第五幅；前行并左转到第一幅；继续前行到主殿右侧的第二幅。示意图见 `CONTENT_MAP.md`，不作为建筑测绘或历史观看路线证据。
- **本轮确认**：先显示全部五幅位置，再共同强调第五幅、第一幅、第二幅；此处不演示先后行进。草稿中的完整高亮路线统一放在 A04，主题短说明放在 A03。
- **第三、第四幅边界**：用户已确认第三幅、第四幅与“出兵·入将”主题无关。两者只在 A02 五幅位置总览中出现一次，核心三幅强调开始后弱化；A03—A06 不再展示，也不要求图像素材。

### A03 出兵·入将

- 沿用 A02 已建立的空间背景，简短说明接下来的主题与观看目的，不重复五幅位置介绍。
- **核心主题**：出兵·入将。
- **约束**：具体内容必须以可靠资料为准。
- **交接**：A01 副标题只作预告；本段补充观看引导。阅读结束后文字退出，A04 建立主殿面向戏台的出发站位。
- **低保真实现（2026-09-22）**：保留 A02 完整区间后新增3个视口高度；核心三幅与同一模型延续，第三/第四幅点线隐藏。主题说明引用李济民的研究视角，留出1.1个视口高度的稳定阅读区间，再回中并显示 A04 出发站位提示，完整行进仍留给 A04。详见 [A03 实现与文案依据](A03_PROTOTYPE.md)。

### A04 观看秩序

- **重点表现**：观众站在主殿、面向戏台时，从身体右侧的第五幅出发，前行、左转到第一幅，再前行到主殿右侧的第二幅，即第五幅 → 第一幅 → 第二幅。
- **交互方式**：向下滚动推进数字叙事；镜头应表达前行和转向，可在局部使用横向画面运动，但不能将整条路线简化为始终向左平移。
- **注意**：“右→左”是项目空间路线的简写，不是三幅壁画在同一墙面上的排列，也不是已经证实的历史观看顺序。交互操作方向与空间路线须区分。

### A05 图像导读

- **信息层级**：对应壁面 → 真实图像整体 → 2—3 处已核实局部线索 → 恢复整体。
- **建议**：沿用现有内容地图中的《入将图》导读方向。用户已确认第二幅壁画就是模块 B 的《入将图》；短文仍须区分可见内容和有来源的研究释读。
- **约束**：不复制模块 B 的自由缩放、热点和详细节点；不重复 A04 路线。第二幅的项目编号与目标素材已经对应，但其模型墙位仍是原型数据，空间对齐不得冒充现场实测结果。

### A06 聚焦《入将图》

- 沿用 A05 最终目标图像，弱化导读信息，突出《入将图》标题与稳定入口；不再次播放完整局部导读。
- **最终显示**：“进入探索”入口（进入模块 B）。
- **操作交接**：用户点击进入，滚动不自动跳转；验证浏览器返回到 A06 的状态恢复。

### A02—A06 连续边界（2026-09-21 统一规划）

- A01 结束于稳定 Hero 与独立阅读区间；A02 从阅读区间之后接管，不在 A01 提前显示壁画标记。
- A02 负责“壁画在哪里”：建筑布局与位置标记。A01 末尾右侧建筑应在过渡进度中连续回到中央，避免瞬移；A02 再接管中央视觉并引入位置标记。
- A03 负责“围绕什么主题观看”：主题与观看目的短说明，沿用 A02 的空间背景；不重讲位置，不演示路线。
- A04 负责“按什么空间路径观看”：第五幅 → 第一幅 → 第二幅，表现前行、左转、再前行；不把路线简化为持续向左平移，也不重复 A02 的位置标记说明。
- A05 负责画面整体及少量局部导读；A06 负责从导读切换到主动探索入口。两段沿用同一经核实的目标图像，避免重复聚焦。
- A01→A02 回中只有一次；复用现有尾部交接距离，不叠加另一段回中。任务与交接详见 [模块 A 总规划](MODULE_A_ROADMAP.md)。
- 顶部导航规则已确认、待开发：A01 全程隐藏，A02 回中完成后显示“全局导航＋叙事进度”。全局导航允许跳过章节，品牌返回 A01 稳定 Hero；进度仅指示 A02—A05 四个阶段，A06 延续图像导读状态。详见 [两层导航规划](MODULE_A_NAVIGATION_PLAN.md)，本轮不实现代码或正式视觉样式。
- 全局导航左侧品牌主标识为「出兵入将」，下方辅助说明为「水龙祠壁画数字交互叙事」；「水龙祠」表示文化遗产对象与建筑名称。整个品牌区作为同一返回开屏入口，右侧承载导航功能，字体与 Logo 样式待后续开发。
- Figma A02 完整画板 `25:7` 本次无法读取画布内容，故不得据此确认具体文案、标记位置、尺寸或导航样式；`25:9` 不作为完整画板依据。详见 `A02_DESIGN_REVIEW.md`。

## 模块 B：《入将图》交互探索（Mural-Exhibition）

### 核心原则

- 模块 B 的核心交互已基本完成，后续工作首先应保护现有功能，而不是重新设计。
- 模块 A 只负责提供进入模块 B 的入口。
- 模块 B 自身保持独立开发和维护。
- 模块 B 的具体交互内容以当前项目代码为准，本文件不重新定义。

### 现有入口与数据（以当前代码为准）

- 大屏展厅版（WebGL）：`http://localhost:3000/`（`Mural-Exhibition/public/index.html`）——模块 A“进入探索”的目标入口
- 移动端叙事长卷版：`http://localhost:3000/m`（`Mural-Exhibition/public/gallery.html`，归属模块 B，当前不接入模块 A）
- 数据接口：`/api/scan-assets`（动态扫描 `Mural-Exhibition/public/assets/` 下的壁画系列，返回各系列 org/line/color/info 素材路径）

### 模块 A → 模块 B 连接方式

- 通过明确的入口或路由完成，不做内部耦合；
- 模块 A 的“进入探索”按钮跳转到**大屏展厅版（WebGL）** `http://localhost:3000/`；
- 待开发的全局导航与 A06 使用相同探索入口；浏览器返回时恢复进入探索前的模块 A 章节及滚动位置，详见 [两层导航规划](MODULE_A_NAVIGATION_PLAN.md)；
- 移动端叙事长卷版（`/m`）当前不接入模块 A（忽略）；
- 不直接修改模块 B 的缩放逻辑、热点系统、Canvas/WebGL 核心、大图加载逻辑、节点系统。
