## 研究结论与建议

画中云纹随群像起伏，能辨出三个横向场域。上层车辇、旗盖和姿态各异的前列形成多个小群；中层用错开的骑、步队形和仪仗维持横向动势；下层在左端转为以祠门、桌案、供物和人群为中心的场景。中层人足邻近下层屋檐，是可直接比看的层间接点。上层祈愿文字与左下祭祀场面还能形成跨区的主题对照。三层在画面上并置，是否同时发生、是否分别表示三个连续时刻，现有证据不能定案。

推荐**全幅 → 辇车与随行者 → 两幅祈愿字幡 → 云纹间的错列人马 → 领队中的倒立身影 → 祠门与供桌 → 全幅**。五次停靠分别解决群组、文字、层次、领队和地点五个问题。横向为主，中段纵向比较三层，左端就地换层并允许反向回看。起点依据队伍整体向左的动势和左端可辨的建筑焦点；历史上观者从哪端读起仍待考。整个导读可跳过，入口和全幅归纳都保留图鉴、体感的自由选择。
