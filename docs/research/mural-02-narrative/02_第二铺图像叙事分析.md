# 第二铺壁画如何把队列带到祠门前

在全幅图上，从最右侧的车轮向左追踪，会遇到一处明显变化。起初，一组人围绕一辆车；到了中段，骑乘者与步行者成组交错，目光容易顺着旗杆和人物斜列转到另一层；到了左下，屋檐、祠门和桌案固定了地点，人们的手势和朝向围绕它重新组织起来。**行列使画面有了方向，祠前的聚集使这个方向有了可辨的落点。** 左上领队与左下供桌各有吸引视线的能力，这幅画也经得起从领队回望长队的第二次阅读。[图像组织标注](03_图像组织.png)

## 一、先辨认画了什么

上层右端能辨出车轮、乘者和左右随行者，旗、盖和高举的持物越出人肩，在人群上方形成剪影。几个车乘组合反复出现，轮与盖比脸部更容易从全幅上辨认。到中部偏右，两幅斜举的白底字幡分别可读“风调雨顺”“五谷丰登”。文字使观者获得具体的祈愿内容，也让两位持幡者从同行者中凸显出来。再向左，骑乘与步行相间，至左上领队处，抬臂、俯身和倒立打破先前的重复步态。刘灿姣、林伟记录了多辆辇车，陈勤学进一步讨论其中女性的形貌、侍从与身份。右端一辆车的乘者和另一辆车的乘者应分别核图，不能把女性群像研究的结论分配给每辆车。（刘灿姣、林伟，2016，第20页；陈勤学，2021，第115–117页；郑富天，2024，第103–108页。）

中层沿横向延伸得最清楚。几个人错开半个身位，前肩遮后身，骑者高出步行者，长杆和旗面从密集队列中伸出。画面偏左还有举牌、吹奏以及持扇者。若只把他们归为“士兵”，就会漏掉这支队列的两种面貌：成排的兵器和近似的装束使行列整齐，扇、锣鼓、吹奏动作又让人想到出行的仪仗和表演。吴灿把折扇解释为戏曲道具，贺景卫、彭迪通过服装与配饰合观提出军傩解释。现阶段可向观众展示这种并存，把仪式名称放在有出处的扩展阅读里。（吴灿，2017，第121–123页；贺景卫、彭迪，2019，第117–119页。）

下层右部有清晰度骤降的大片暗区，右缘亦见孔洞。在保存较清楚的中段，步行、骑乘、旗帜继续出现。到左部，能辨出牲畜、牵引者、端持器物者、桌面陈设，以及有门额和重重屋檐的建筑。桌旁有些人朝向与主队不同，手、身躯和器物围着桌案排开。这种局部反向恰好帮助辨认场面的变化。龙明盛把庙前牵牛持刀的局部与地方记录比较，指出文献所记横木在画中没有出现。可见的持刀、牵绳属于动作线索，仪式的完整做法需另有材料。（刘灿姣、林伟，2016，第20页；龙明盛，2019，第113页图1、2；彭迪等，2025，第115页图3。）

## 二、三层为什么能放在同一幅画里

最容易辨认层界的位置在左半幅至中央。云头围着人马的脚部和旗杆反复回旋；中层的马腿有时下探，邻层的旗又向上伸出。可以在完整处追出上、中、下三条人物带，但界线随人物和云纹起伏。把画面按高度等分，恰好会把人物的头和持物切到另一层。到右下暗区，这条分界也无法连续可靠地描出。图中以代表性区域标层，保留其余边界的不确定性。（刘灿姣、林伟，2016，第20页；程旭蕊，2022，第30页；林妙璇，2022，第54–56页。）

**三层的差别在于组织群像的办法。** 上层的车、盖、骑者和姿态突出者给各组一个中心。中层靠斜列、前后遮挡、骑步高差维持队伍的长度。下层到祠前，固定建筑、供桌与供物取代移动中的人物成为焦点。右端保留三个不同高度的行列，左端则同时提供领队与聚集场所；观众因此能在同一视野里读到“由哪些人组成”“队伍怎样行进”“向什么地方汇集”。彭迪等从神祇、仪仗、祭祀三者说明共同功用；这里进一步把这种联系落实到群像的排列方式。能确认的是同画并置；是否属于同一天、同一个仪式瞬间，仍无可核的时标。（彭迪等，2025，第115–116页；郑富天，2024，第98–120页。）

## 三、时间能读到什么程度

一幅画不用把人物画两次，也能让人感到动作正在发生。抬起的脚给尚未迈完的一步留下余地，牵引的牲畜、紧张的绳与持刀人的姿势让人预期下一刻。李济民甚至把祠旁炮手与一倒一立的火炮解释成已燃、待燃的时间差（2025，第120页图11）。这是一个可以检验到器物位置的**局部先后假说**；本次未把它设为停靠点，须先在项目原图中逐一核定炮具。龙迪勇所谓“空间的时间化”，在这里首先是由姿态、物的位置和上下文恢复可能的动作过程。（龙迪勇，2007，第39页及PDF第6–7页。）

全幅需要另一种论证。郑富天以三层容纳不同时刻，归为“纲要式叙事”，把从领队到祠前读成时间的流动（2024，第86–87、120页）。这能解释为什么供桌有收束感。问题在于相似的服饰和兵器出现多次，只能说明队伍的共性；画面没有据此锁定同一人连续经历三段事件。龙迪勇另论共同主题可以把不同场景并置（2011，第88–89页），为此处提供另一种读法：神祇、仪仗和祠前活动在一幅画里共同说明祭祀场面，观者自行建立关系。**本报告把主题并置、行进动势和局部的动作时间作为三种不同强度的证据。** 是否把全幅读成有固定先后的故事，留作可比较的学术观点。

## 四、为何首轮从右看，末端又要回看

右上清楚的车轮和成组随从适合做第一个辨识任务。随着目光向左，车乘的重复让位于两幅可读字幡；视野放宽后，三层旗杆、云头和人马的错位才容易比较。继续向左，先看上部倒立者，再在同一端向下找到屋檐、祠门和供桌，观众便可回想画中行列朝着哪里。此处最值得反向观察：从左端领队向右看，能读出一组一组如何向队尾展开；从供桌向右看，则能辨别站定迎候者与行进者。这样同时保留了程旭蕊的行列动势和林妙璇分析领队与队尾的视角。（程旭蕊，2022，第30页；林妙璇，2022，第54–56页。）

数字路线只安排观众先看到什么。发现报告的逆时针论述涉及几面墙中的队伍；彭迪等承认走廊损毁，全祠历史观看秩序存疑（2025，第114页）。从一面墙的画内朝向，无法推出观众在建筑内必从哪边走；从同一画面的局部动势，也无法推出历史观者的第一眼。模块A已经介绍五铺与仪式文化。第二铺导读的任务应缩小到这一个具体问题：**当目光从右侧车轮移到左下供桌，是哪些可见线索让观众把两处看成一幅画？** [五个选区与观众文案](04_叙事节点清单.md)

## 五、需要继续查证的部位

1. 以原图、文献图版和经授权的现场资料核对黑斑、孔洞及边缘的现状。发现报告记有烟熏，单凭数码图不能给所有暗区指定同一种成因。
2. 逐一校对左上持器者，特别是“西门”“北门”的异称，以及车中乘者的身份。图鉴名称保留其现有资料属性。
3. 将原图、建筑方位图以及不同作者采用的左右视角并排核对；历史观看秩序需要独立的观看记录或田野材料。
4. 如需将“信炮”或上下层带翼形象纳入观众讲解，先落实图像、图版、命名三个环节。原型审查也应请人检验祈愿幡是否够大、左端纵向换视野是否仍能定位。上述理解效果尚待观察。
