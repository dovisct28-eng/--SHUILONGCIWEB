# 静止的队伍如何让人读出行动

**第二铺最清楚地组织了参与者之间的关系，局部又把行动画在将成未成的时刻。** 同一画面容得下两种时间经验：马正在行进、有人正牵住牛，这些姿态让观者想象紧邻的前后；两个相距很远的场景也能因同一祈愿而互相解释，即使不知道哪件事先发生。下文以照片左下的祠门为方位参照。[全幅](../../../Mural-Exhibition/public/gallery/mural-02-detail.webp) · [局部与论文图版定位](08_第二铺图像内容与证据对照.md)

## 三层为何能读成一场仪式

上层以辇、骑者、华盖反复组织小群。核心人物周围有人掌盖、牵引、步随，靠前的倒立、持锣、举树等动作又打破整齐的步态。即便乘者尚不能逐一辨名，地位与随从关系已经可读。两片白底字幡穿插在这些人之间，风雨与收成遂成为神灵出行所携带的愿望。中层的重心落在队伍如何行动：执仪仗牌者留出开道的位置，扇、长兵与马匹错列，骑马乐手在队列内吹打，掌伞、持刀者随侍其间。人数众多而动作有别，让「仪仗」成为看得见的集体分工。下层仍有骑步与旗号，却多了被抬的兽、门前牵牛者、端盘者和鼓手；同一仪式在这里得到一个有名有址的行动场所。三层各有重心，持扇、仪卫、音乐等内容又跨层分布。刘灿姣、林伟20／PDF 3称「三界」，胡彬彬、吴灿23／PDF 2将下部与人间迎奉相联。云纹确实分层，把它精确解释成三界、三种身份或三段时间，则各需更多证据。

卷云勾出的横带让高举的旗杆、错列的马头和露在云边的脚各有位置。顺着反复出现的马首和步态，眼睛容易向照片左端移动，也可从前列向右追索是谁跟随。程旭蕊30／PDF 39图2-27指出组内人物自右向左上方倾斜；林妙璇54–55／PDF 64–65图4-1从左端猖兵看队伍向右延伸。画中行进方向与观察者查阅队伍的次序可以相反，两种分析说的是同一个构图的不同性质。

中层前列脚部与下层屋檐相邻，是具体的跨层接点。继续辨认屋檐，目光便能从一群行动中的人落到门额、供桌和相对而立的参加者。左下由此形成视觉聚焦。更重要的是，它使观者能解释画面另一端的内容：有这座祠和这张供桌，抬运、吹奏与威仪森严的行列便获得了祭祀的语境。建筑虽不居全幅的几何中央，却有这样的主题作用。林妙璇55／PDF 65、彭迪等115／PDF 2图3都从下层聚合解释供桌；后者116／PDF 3讨论全殿龙纹的焦点，分析尺度已扩大到建筑整体。

## 方位、动作和时间，哪些能互相推出

| 可核对的线索 | 可以建立的联系 | 再推进一步还缺什么 |
|---|---|---|
| 马首、跨步与错开的骑步队形 | 多组共享横向动势。前后有人簇拥，可以辨出队伍前后和主从。 | 队尾在空间上靠后，不能因此给队尾定一个较晚的事件时刻。 |
| 手举吹管至唇、执槌对鼓；祠前另有同类动作 | 静止的手势使人想到发声和拍点，观者可想象行列边走边奏。 | 何时起奏、是否同奏、祠前鼓乐是否接续中层乐曲，画面未给声谱或时标。 |
| 祠前绳索上牵、牛头随之抬起、旁有刀 | 一个动作内部有可推想的先后和力量方向；在供献场所，准备献牲是较强的解释。 | 完成宰祭是下一步的推想。另一端悬兽的物种和连续身份均未证实，不能写成同一头牛两次出镜。 |

| 双幡言风雨收成、祠额言地点、桌上陈供 | 两处远隔的图像各自提供了一半意义。读者可以用供桌解释字幡的礼仪场合，也可以用字幡解释献供所寄托的诉求。 | 文字没有说明祈求已获应验；祈愿、降雨、丰收、还愿的因果顺序超出图中所见。 |

龙迪勇《图像叙事：空间的时间化》45／PDF 7在单一场景中讨论「最富于孕育性的顷刻」。要点是一个姿态可以让人想到它的前因和后果；这些前后未必已经被画出。48／PDF 10所说的纲要式叙述则有更高要求：作者从不同时间点选择要素，放在同一幅中。把这一区别带回水龙祠，鼓槌与鼓面足以提示一个动作的历时性；要说上中下各取自一个不同时间点，还需证明所选事件确有可辨的先后。龙迪勇另在《图像叙事中的主题－并置叙事》88–89／PDF 1–2描述以共同主题联结多条线索的组织方式。字幡、乐队与供桌的关系适合这样分析。第二铺仍保有明确的队列方向、局部前后和供桌聚焦，不能据此把三层当成可以任意互换的三个独立故事。[两篇理论原文及对应页](07_第二铺整体仪式主题研究.md)

## 郑富天的「起点」和「终点」怎样使用

郑富天给出了一个有内容的时间假说。其86–87／PDF 94–95以**上层最左的领队**为时间起点，让中层最左的三位军士延续这股时间流，再把祠前供桌解释为抵达和聚集的终点。换言之，他看到的有前导、有趋向、有抵达；这比简单地给三层贴「开始、经过、结束」的标签具体得多。左端脚与屋檐相接、下层由长队变为相对聚集，确实使这个读法容易成立。

但同一论文在29–30／PDF 37–38的正文把起、终点写到右侧，30页图2-10却标在左上与左下；图2-11的祠前局部题作开始点，图2-12的上层人物题作终结点。120–121／PDF 128–129又从上层右侧谈起，把祠前读作高潮。**祠前收束是可准确归于郑的解释，左右起读和逐层时序不能据其图号直接定案。** 对照门额位置可校准照片方向，却不能据此修定作者心目中唯一的历史观看方式。

即使暂且搁置这些方向出入，仍有两条独立的证据限制。第一，前列军士临近屋顶是空间上的连续；现存可读部分缺少同一位领队连续跨三层、并有明确状态变化的对应。上层与门边都被识作雷神的形象可以主题呼应，重复神格也不足以确定「同一个人在稍后抵达」。第二，区分跨铺与铺内：程旭蕊36、51／PDF 45、60讨论祭祀先后时涉及第二、第五铺等墙面，彭迪等114／PDF 1也承认走廊已毁、原观看次序存疑。跨壁的出与入即便成立，也不会自动给一壁的三条横带各分配一个时段。

**综合判断。** 空间上可确认三层并列、队伍有向、祠前聚焦；行动上可推想吹打、负重、牵引、点炮的局部前后；全幅层面，祭神祈丰使这些动作彼此相关。逐层行至祠前是值得保留的学术读法，三层完全同时同样缺少证明。数字导读里某个局部先出现，能说明的只有展示者先指给观者看了什么。
