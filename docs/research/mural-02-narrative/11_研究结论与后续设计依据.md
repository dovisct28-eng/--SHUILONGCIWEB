# 研究结论与后续设计依据

**后续转译最值得保留的关系，是上层字幡写出了人们为什么祈求，庙前的供桌画出了人们怎样以礼迎奉。** 中间的骑步仪仗、马背上的鼓吹和队中的抬运，使这一联系有了具体的参与者。若只把画面读成从右向左经过的五处细节，观者可以看清许多人物，却仍说不清这支队伍为什么聚在水龙祠。

## 五处旧观察任务，经独立研究后怎样评价

对读范围包括前期01、02研究稿、两张03标注图、04清单及坐标、05交互规划和06核验表。以下N编号仅对应这些已有文件。原方案已经明写「数字导读」，也已区分抬运与牵牛；没有依据认定前期作者把数字路线当作历史事实。问题出在**编排可能传达的含义**与**最值得讲的内容**之间。[原观看路径](03_观看路径.png) · [原方案全文](05_循迹叙事交互规划.md)

| 前期观察任务 | 有图像支持的部分 | 新研究改变的重点与可能的误读 |
|---|---|---|
| N01 辇车与随行者 | 车轮、乘者、旗盖和随从提供了辨认局部组织的好例子。 | 要解释为什么值得围着车看：侍从与盖共同突出乘者的尊位，整队因而有迎奉神灵的意味。从车开始是展示选择，车上最尊者是否龙王或某位女神尚无定论。 |
| N02 两幅祈愿字幡（含翼形者、下方抬运） | 字幡是少数能直接读出愿望的证据，带翼者与文字同在上层；抬运局部可定位。 | 字幡与远处供桌的主题联系强于同框上下区域的垂直邻近。下层的兽可能是参与者带来的猎获或供献；字幡下方的位置无法证明有人因读幡而取牲，亦不能把兽提前命名为牛。 |
| N03 错列人马（含两位骑者及马背乐手） | 云纹、骑步、持物与仪仗层次可辨，骑者神名各有研究。 | 两个可命名的神祇容易盖过乐手在整场仪式中的作用。军装、兵器、乐器和扇同时出现，最能解释队伍为何既有纪律又有表演意味。即使神名暂缺，群体关系仍能成立。 |
| N04 前列的倒立身影 | 特殊姿态与同组持锣、持角、举树者明确；梅山图式比较给出了命名理由。 | 左端前导与右端车驾处于同一行列。在旧路线里较晚看到领队，并不表示领队在仪式后段才出场。把整组只讲成某个名字，会漏掉它同后方仪仗的引领关系。 |
| N05 祠门与供桌（含桌旁鼓手） | 场所、陈供、牵牲与迎候关系集中，和马上的乐手可作功能对照。 | 此处既能收束观看，也能反过来帮助观者从一开始就读懂全画。最后显示供桌容易被理解为仪式最终完成；画面呈现的是已陈供、仍在奉持与牵引的不同状态，尚未给出终场结果。 |

原稿已能比较字幡与供桌、行进乐与桌旁乐，06也明确警惕两处牲畜混同。本轮进一步给这些对照排出**证据轻重**：字幡与门额可以直接读，献牛有专门图式与地方材料支持，时间终点则是一种有争议的构图阐释。旧05解释维持五站、扩框容纳细部的理由，主要是取景范围和观看便利；这些理由能支持展示方式，不能用来论证古人曾以五个事件构成第二铺。此次没有证据要求为五个节点分别配上五个故事环节。

## 留给下一阶段的内容问题

1. 观众能否凭两项相隔较远的画面证据，解释风雨与收成为何出现在仪仗行列中？可以检验的内容是「字幡所言」和「祠前所做」能否联系起来。
2. 观众能否举出一个身穿军装却正在从事其他工作的人，并说清楚他的动作？骑马奏乐者尤其适合用来区分服饰、职能与研究者赋予的军傩含义。
3. 哪些解说必须带上「有学者认为」？尤其是把这幅辨为「入将」、把倒立形象辨为张五郎、把牵牛持刀辨为准备砍牛时，应让观者知道每个判断分别靠什么。
4. 观众能否分清画面可见、由姿态推想、由数字呈现安排这三件事？可用祠前一处正在进行的动作，与整幅尚难证明的先后顺序比较。这些是后续评价问题，目前没有观众测试结果。
