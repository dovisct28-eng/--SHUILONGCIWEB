# 第二铺的文献依据与解释分歧

本地资料夹 `相关文献/` 有 49 篇 PDF 和一份 Word 开题报告。全部 PDF 按物理页检索正文，短篇重点核对相关段落和图版，学位论文按章节定位；文后列出其余筛查范围。下列页码未加限定时均为刊页或论文正文页。PDF 插页会改变页序，尤以《梅山猖兵考释》为甚。引文在此均以转述为主。

## 研究结论怎样取舍

| 所见与问题 | 研究之间的关系 | 本项目采用到哪一步 |
|---|---|---|
| 云纹起伏，三带人物可辨 | 发现报告第20页说“三界”；彭迪等第115–116页侧重等级、信仰与祭祀分工；郑富天第86–87页把三层读成时间展开。用同一云纹能辨出分区，无法单凭它决定分区代表什么时间。 | **确认**三个横向场域。**分析判断**为共同仪式主题下的空间并置。“三界”作为有出处的读法保留。 |
| 多数人马向左，左端领队突出 | 程旭蕊第30页强调向左上倾的行列；林妙璇第54–56页从领队向右分析组织。两者讨论的分别是画中运动和眼睛追踪构图的起点，可以并存。 | **设计选择**从右向左，到左端可逆看。建筑逆时针观看另属一题，彭迪等第114页说明走廊损毁带来的疑问。 |
| 祠前出现人群与供物 | 胡彬彬、吴灿第22–24页重在祭水龙神；廖方容第20–21页以出巡、凯旋解释相对墙面；李济民第116–117、122页以迎神出庙、送神入庙解释多庙成对图式。证据单位包括单铺、两面山墙和跨村比较，三者不可直接互换。 | **可采用**祠前祭祀、仪仗和祈愿；**存在争议**的是整组仪式名称、进出环节及观察方位。观众统一读作“第二铺壁画”。 |
| 脚部与屋檐接近，祠前活动聚焦 | 郑富天第43、86–87、120页推论从上经中到下、到祠前收束。第86页将时间起点放在上层最左，第120页却写上层右侧先出现领队。林妙璇第55页以场面聚合解释同一焦点。 | **确认**画面邻接和视觉聚焦；**保留假设**为接近祠前的过程感。跨层缺少能在本图中复核的同一主角及明确时标。 |
| 左上倒立者及持乐器者 | 刘灿姣、杨会娟第53–55页以图像谱系辨读，并列西门谢五猖、北门雷五猖；彭迪等第115页写作“西门雷武猖”。这涉及方位、姓氏和称谓，不能用两个文本互相印证同一标签。 | **文献支持**倒立者的张五郎解释。图中默认提示倒立、持锣等动作。具体人物的方位名称留给原图、文献图版与资料编制者共同复核。 |
| 上层辇乘者、下层官服形象 | 陈勤学第115–117页提出女神身份比对；杨会娟、刘灿姣第112–114页提示官员式装束和“敕封”文字有模拟礼仪的意义。 | **确认**车轮、乘者、随从、旗与盖的组合；**待核实**每辆辇车乘者。上层不以神名编排停靠点。 |
| 折扇、牛与局部动作 | 吴灿第121–123页与贺景卫、彭迪第117–119页均重视表演性，后者联系军傩。龙明盛第113–114页则以图像、地方记录讨论砍牛仪式和族群记忆。李济民第119–120页将献牲、信炮放入当地赛会材料中。 | 动作、用具和局部先后线索均可讨论；不能据牵绳的姿势补出随后发生的事，也不能将文献举出的所有礼俗串成全幅的固定程序。 |
| 绘制年代会不会改变路线？ | 发现报告第19页以地仗、砖体及服饰主张明洪武；廖方容第22–23页据辫发、红缨帽、火器等主张清早期。 | 本阶段不作断代。镜头落点依照图中可辨的形象与构图。 |

| 本地《开题报告11-11_第二铺称谓修订版》；论文拟题《图像叙事视域下的水龙祠壁画数字交互设计研究》 | Word表格正文按“研究内容摘要”、3-1、3-2、3-3定位，重排版无稳定页号。取其布局、场景、人物关系到交互探索的研究问题，以及图像分析、原型和后续评价的方法。开题中的实地调查、原型测试作为研究安排。 |

部分PDF的标题、数字或外文字体在提取时乱码，如林妙璇论文部分小标题、龙迪勇2007年文章的页眉。关键图版按页面图像对读，混入的其他文章插页未作证据。开题报告、其他论文的征引书目不计作已读原著。
