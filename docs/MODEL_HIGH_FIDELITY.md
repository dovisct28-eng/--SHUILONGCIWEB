# 水龙祠共享模型：轻量写实阶段

本版为**依据现场照片校准的设计模型比例关系**，并非现场实测、建筑测绘或扫描复原。照片用于判断墙体层次、构件关系与色彩方向；没有将整张现场照片贴到建筑上。无法由照片确认的背面、梁架细部、准确尺寸和砌筑方式仍保持简化。

## 壁画墙

- `mural-01` 保留为长廊内墙的局部画幅，左右留有旧抹灰墙；画面仍可被真实梁柱遮挡。停靠镜头移到廊梁下方，以兼顾画幅可读性和空间关系。
- `mural-02`、`mural-05` 各占主殿侧墙主要壁画墙段约 6.1 / 6.6 个设计模型单位。墙面从上至下为裸砖、壁画所属抹灰层、旧墙脚和铺地。两幅画按各自原图宽高比映射，不拉伸。
- `mural-locations.json` 中的宽高与位置是**设计模型单位，不代表现场实测物理尺寸**。构建时逐字段校验它与模型源的重复元数据一致；壁画 ID 仍为 `mural-01` 至 `mural-05`，观看路线仍为第五幅 → 第一幅 → 第二幅。
- 原始 `display.webp` 保持独立资源，通过 `module-a/mural-resources.mjs` 在 A04 按需加载。展示平面贴近墙面；加载成功后隐藏青绿色占位与金色边框。窄幅透明边缘遮罩仅作用于显示层，原始图像文件及颜色不变。

## 建筑与材质

入口统一为红砖墙、半圆砖券、较深门洞与深木门，中门仍大于两侧门。主殿屋顶、戏台朝向、回廊总平面关系未改变。屋面、木构、石础、抹灰、砖墙和铺地使用克制的哑光材质。

`shuilong-temple/generate-textures.py` 可重复生成六类建筑纹理：plaster、brick、wood、roof、stone、paving。每类有 512×512 的 BaseColor、Roughness、Normal JPEG；18 张源图共 326,534 B。纹理是受现场照片色彩和材质启发的程序绘制，并非文物采样纹理。Normal 强度为 0.18；没有给壁画加 Normal，也没有把壁画烘进 GLB。

`build-model.mjs` 将 UV 写为 `TEXCOORD_0`，把纹理的 image、sampler、texture、PBR material 嵌入 GLB。浏览器预览与离线预览使用同一 GLB；建筑纹理从 GLB 解码，不额外发起外部图片请求。纹理解码失败时保留基础色材质。

| GLB | 2,595,956 B | 3,220,776 B |

去掉了旧铺地缝逐条几何，贴图直接嵌入 GLB；GLB 仍只加载一次，三幅壁画仍逐幅按需请求。代表性截图和浏览器测试结果保存在 `docs/validation/model-hifi/`。已核查 A01—A04、A04→A05、A05—A08 基本可达、尺寸 1920×1080 / 1440×900 / 1366×768 / 1024×768、刷新、倒滚、跳过、重播、reduced-motion、单幅壁画加载失败、建筑贴图解码失败和外部 GLB 请求失败回退。

仍需现场资料确认：墙体确切尺寸、壁画与抹灰层边界、砖缝尺度、门洞厚度、未入镜梁架及石础细部。当前材质为受照片约束的视觉表达；不宜将它称为 1:1 文物复原。
