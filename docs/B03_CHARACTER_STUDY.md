## 使用

普通本地服务仍为 `Mural-Exhibition` 内运行 `npm start`，打开 `http://localhost:3000/index.html`。

- 图鉴：从全景热点打开详情。左侧完整真图，右侧标题稳定、正文独立滚动。下方切换原壁画、高清线稿、数字色稿；色稿明确标注数字化演绎，有该人物视频时沿用播放机制，结束恢复静态图。
- 人物导航：上一组、下一组、主动展开的人物索引。索引按扫描数据生成，原生按钮可用 Tab/Enter；抽屉中上下键/Home/End选择，Escape收起并恢复入口焦点。
- 体感：默认完整居中观看。双手展开/收拢沿用既有判定，揭示与收起共用 `setRevealed()`。鼠标“查看/收起人物档案”和键盘 I/Escape 使用同一状态；左右键与按钮切换人物，按钮支持 Enter。正文依旧只有 `#info-text` 一个滚动目标。
- 模式切换保留当前稳定 ID。当前人物缺少线稿/色稿时留在图鉴并解释原因，由用户主动选择，不静默换人。体感人物导航跳过素材不完整组，图鉴索引仍包含所有组。返回全景沿用原位置；窗口变更仍按原地图边界规则约束位置。
- 摄像头错误继续使用既有提示、返回选择与图鉴路径；WebGL可用但摄像头失败时，资料辅助按钮仍可使用。外部体感库无法载入时，保留既有错误/重试/图鉴回退。

## 作者资料格式

继续使用 B02 素材目录和 `/api/scan-assets`，不新增数据库，不修改稳定 ID、正式名称、热点或真实图像。录入操作见 [B02 使用说明](B02_GALLERY_AUTHORING.md)。

`info.md` 优先于 `info.txt`。兼容策略：

- `info.txt` 按已有中文编号标题和原有行段排版，不猜测栏目含义、不按关键词重新分类。已有真实内容完整保留。
- `info.md` 是安全的轻量 Markdown 子集：`#`–`######` 标题、空行分段、软换行、无序条目、引用。全部正文通过 DOM `textContent` 写入；原始 HTML、脚本、内嵌图像和行内 Markdown 标记不执行。粗体等行内标记当前保留为文本，不宣称完整 Markdown 支持。
- 人物标题始终来自 `meta.json.name`。可选 `englishName` 为作者提供的英文名；也兼容旧 txt 开头“正式名称＋独立英文名称”两行，只有第一行与正式名完全一致才提取第二行已提供的英文。其余情况保留原文，不翻译或推断。
- 栏目标题来自档案本身；“图像观察”“相关研究”等只有作者提供标题与正文才出现，不从人物名称生成描述。
- 来源沿用 `meta.json.sources`。支持字符串或 `{ "author": "...", "title": "...", "year": "...", "pages": "...", "url": "https://..." }`。只展示实际提供字段，链接仅允许 http/https。空来源显示待补充与本轮未核验提示，不补写作者、书名、页码或文化解释。
- 缺失/空档案仍可看图，并显示来源或待补充提示；请求失败提供重试，不阻断图像查看。

英文名和来源只是展示作者提供的资料，不构成本轮史料核验。原档案中的身份、神职、仪式及研究判断未经本轮重新证实。ID `10` 的旧档案首行与正式显示名不一致，保留原文待作者核对，不自动推断身份。

## 技术边界

`b03.css` 仅作用于桌面详情/体感表面。`character-study.mjs` 提供安全档案排版和可测试的相机适配数学。现有主页面保留 selection/gallery-map/gallery-detail/cyber 四种状态。

相机安全区读取阅读区 `offsetWidth` 与计算后的 `right`，排除 CSS 位移动画；加入上下操作留白。resize 只重算视锥体和相机，不重建纹理。约1.5秒揭示与资料淡入同步，覆盖旧 tween 防止快速收放冲突。减少动态效果时新增 UI 与揭示过渡立即完成。

原 TextureLoader 的回调缺乏取消和版本保护，resize 会再次加载/重建，因此本轮局部调整纹理请求为可取消 fetch→Blob→原 Three.js Texture。保留同一个 renderer、场景、着色器、平面和点阵构造；替换时释放旧纹理/几何，过期结果不上传，Blob URL 在请求全部结束后释放。静态图层继续按需加载，加载失败保留前一有效图层；档案和媒体都有版本保护、取消或清理。

B01构图、B02地图/热点/标注、移动端、摄像头权限核心、手势识别数学和阈值、模型、文物资源、模块 A 与固定低保真归档未修改。颜色、字体、尺寸和间距仍是本轮候选，并非新全局冻结规则。
