# A03 出兵·入将主题引入：实现与文案依据

日期：2026-09-22。范围：模块 A 的 A03 低保真与 A04 入口提示；以已验收的 A02 为起点。完整 A04 路线、导航和模块 B 不在本轮实现范围内。

## 1. 叙事与文案

A03 解决“知道壁画在哪里之后，为什么围绕出兵·入将观看”：将位置认知转为关注队伍出行与归来、朝向及壁面之间联系的观看线索。

| 页面内容 | 性质与依据 |
| --- | --- |
| 出兵·入将 | 已确认的项目主题 |
| 从壁画的位置，走向出行与归来的故事。 | 项目观看引导，不作为历史事实 |
| 李济民将“出兵入将”解释为迎神赛会中队伍出庙与入庙的场景。 | 对李济民（2025）第122页首段的概括，已核对 PDF 第7页原文及渲染页 |
| 以这组关系为线索，留意队伍的朝向，以及不同壁面之间的联系。 | 项目设计的观看目的，不逐幅赋予未经核实的仪式名称 |
| 研究视角：李济民，2025，第122页。主题尚有不同释读，这里提供一种观看线索。 | 作者与页码随正文展示；不同释读见该文第123页注[1]，已核对 PDF 第8页 |
| 以站在主殿、面向戏台为起点，先看身体右侧的第五幅。 | 用户已确认的项目空间基准，作为后续 A04 的入口提示 |
| 这是一条项目设计的观看路径。 | 明确数字观看顺序不等于已证实的历史观看顺序 |

不把论文“右壁/左壁”的简称直接绑定当前模型观察方向；不从作者的仪式解释推导第五幅→第一幅→第二幅的历史顺序。第三、第四幅不进入主题段。

## 2. 文献核对范围

- 主要依据：[李济民，2025，《共贺神赛：潇贺古道民间神祠壁画“出兵入将”图像主题研究》](../相关文献/李济民%20-%202025%20-%20共贺神赛：潇贺古道民间神祠壁画“出兵入将”图像主题研究.pdf)，《装饰》2025年第1期，第116–123页。核对第116页摘要及第122、123页；正文采用第122页的作者观点。
- 对照阅读：胡彬彬、吴灿（2016）《湖南江永勾蓝瑶寨水龙祠壁画释读》第22页，关注其祭祀水龙神与三军仪仗的解释；吴灿（2017）《湖南江永勾蓝瑶寨水龙祠壁画再释读》第119页，关注其宗教仪式、戏曲表演、兵马仪仗等研究方向。只核对本轮相关页，未宣称完成全部文献综述。
- 页面没有直接加载 PDF，也没有加载高清壁画母版；文献文件保留在用户新增目录，本轮提交只包含引用记录，不包含论文全文或论文渲染页。

## 3. 滚动分段

A03 从本地滚动距离 10.2 个视口高度开始，保留 A01 的5屏动画、1.2屏阅读及 A02 的4屏完整区间。A03 新增3屏，最终滚动距离为13.2屏，包含当前可见视口的容器高度为14.2屏。

| A03 内部距离（视口高度） | 状态 |
| --- | --- |
| 0–0.55 | A02 文字退出，第三/第四幅编号及对应点线同步隐藏 |
| 0–1 | 沿用同一建筑，构图移向右侧并适度缩小；相机不旋转，不重新生长 |
| 0.35–1 | 主题标题、作者观点、观看目的和来源淡入 |
| 1–2.1 | 独立稳定阅读区间，文字、模型、核心标记保持不变 |
| 2.1–2.65 | 主题文字退出，建筑回到中央，为 A04 留出构图 |
| 2.4–2.85 | 显示“从第五幅出发”和观众站位提示 |
| 2.85–3 | 稳定交接状态；明确空间路线待后续展开，可反向回看 |

所有参数由当前滚动距离推导，跳滚、停滚及反向滚动不依赖先前播放记录。A03 结束时仍共同保留三幅位置，不播放路线、不突出依次抵达效果。A04 后续需从本段接续，实现真正的前行与转向。

自动化和截图检查用于确认可读性、滚动行为与恢复，不等于证明用户已理解主题。最终体验理解仍待用户验收。模型墙位与历史观看顺序的核实限制继续保留。导航仍按既定规划等待开发，A04 完整路线尚未实现。
