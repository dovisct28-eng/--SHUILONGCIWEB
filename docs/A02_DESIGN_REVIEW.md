## 2. A01 → A02 过渡方案

### 目标

让用户感到自己从 A01 的建筑 Hero 继续走入建筑布局，而不是离开一个页面再打开另一个页面。A01 的最终画面应保持稳定，A02 只在独立阅读区间结束后开始引入空间信息。

### 建议的连续过渡

1. **稳定交接**：A01 阅读区间末端保留左侧完整建筑、右侧标题与简短说明；不新增编号、连线或路线高亮。
2. **空间层切换**：进入 A02 的前段，左侧建筑不瞬移、不重新播放旋转；其透明度和视觉权重逐步降低，同时建筑布局示意层从背景/侧后方显现。
3. **建筑布局居中**：布局示意层在 A02 内完成缩放与平移到中央。这里的“左侧 → 中央”应发生在布局层接管视觉中心之后，避免把 A01 的模型直接拉回中央。
4. **标记延后出现**：布局稳定后，再按滚动进度依次显示第五幅、第一幅、第二幅的位置标记。第三幅、第四幅可作为完整布局中的非核心位置保留，但本段不为它们编造说明。
5. **交接到 A03**：当用户已经理解“壁画在哪里”后，再进入“出兵·入将”主题入口；A03 不重新播放 A02 的完整定位过程。

### 不建议

- A01 末尾直接硬切成一张中央平面图。
- 为了居中而让建筑先向右回弹、再向左移动；这会让空间方向与滚动关系难以理解。
- 在 A02 同时播放完整建筑旋转、建筑布局变形、三幅标记和路线动画；信息层级会过载。

### 首版可验证的状态边界

| A02 进入 | 建筑与布局层连续接管，视觉中心逐步转向中央 | 模型瞬移回中央、重复 A01 旋转 |
| A02 稳定 | 建筑布局、壁画位置标记、必要的短标签 | “出兵·入将”长文案、第五→第一→第二路线动画 |

## 3. A02、A03、A04 功能边界建议

### A02 建筑空间：回答“壁画在哪里”

- 输入：A01 的稳定 Hero。
- 核心输出：建筑布局与壁画位置的空间认知。
- 允许：布局示意图、编号标记、简短位置标签、从左侧建筑向中央布局的连续重组。
- 不负责：主题解释、完整观看路线动画、人物身份和仪式释读。

> **草稿冲突待定**：用户提供的 A02 截图将“出兵入将布局介绍”和三幅高亮路线放入本段；在用户确认前，沿用“位置认知与标记”作为 A02 的最小边界。

### A03 出兵·入将：回答“这一组壁画以什么主题被组织起来”

- 核心输出：“出兵·入将”作为项目主题入口，并建立五铺壁画之间的关系。
- 允许：主题标题、极短的设计说明、整体关系或概念性连接。
- 不负责：再次完整呈现第五幅 → 第一幅 → 第二幅的行进路线。
- 资料边界：迎神赛会、军屯、梅山等解释必须注明来源或作者观点，不能写成壁画单独证实的唯一事实。

### A04 观看秩序：回答“按什么空间路径观看”

- 核心输出：第五幅 → 第一幅 → 第二幅的项目数字观看路径。
- 允许：镜头前行、左转、再次前行；局部画面横向运动只能服务于空间转向。
- 不负责：重新解释“出兵·入将”主题，或重复 A02 的位置标注说明。
- 关键验收：用户能区分“向下滚动推进”与“身体在建筑中前行/转向”这两个方向系统。

## 5. 需要用户确认的问题

1. Figma 25:7 中“建筑左侧移动到中央”是否表示建筑实体本身回到中央，还是表示布局/平面层接管中央视觉？本报告建议采用后者。
2. A02 是否只标出第五幅、第一幅、第二幅，还是要在完整布局中同时显示第三幅、第四幅的编号？若同时显示，是否已有可靠位置与称谓资料？
3. “第五幅、第一幅、第二幅”是否为正式展陈中的最终称谓，还是仅为当前项目编号？在资料核对前，建议只作为项目编号使用。
4. A03 是否需要展示“五铺”整体关系？如果需要，是否有可引用的布局/研究资料支持，不把“五铺”误读为五幅按编号顺序观看？
5. 顶部导航是否允许跨段跳转？若允许，是否接受跳转后直接落到阶段起点而不是播放完整前置过渡？
6. Figma 中 A02 及相邻分镜的具体文案、标记位置和导航样式，需在画布可读后再次核对；当前不应据此进入正式展陈文案或开发。
7. 用户提供的 A02 截图是否代表新的设计决定：A02 是否同时承担主题布局介绍与三幅路线高亮？若是，A03/A04 是否需要合并、后移或改为解释与细节段？
8. A02 的“点击按钮”是一次性进入下一状态，还是仅作为滚轮提示/辅助操作？这会影响与 A01“同一进度对应同一画面”的一致性。
9. A02 中央对象是三维建筑模型、二维布局示意，还是两者叠加？需要确认其与 A01 左侧建筑的连续变换方式。

## 6. 结论

当前可以确认 A02 草稿希望在中央对象上建立整体位置认知，并使用第五幅 → 第一幅 → 第二幅的高亮路线；但尚不能确认这是否意味着 A02 吸收 A03/A04 的职责。建议在用户确认前保留“ A01 稳定 Hero → A02 布局层居中接管 → A02 显示位置标记 → A03 主题 → A04 空间观看路线”的既有边界，同时把截图中的路线高亮列为待决方案。若确认截图方案，则必须重新划分 A02、A03、A04，避免同一路线在多个段落重复出现。
