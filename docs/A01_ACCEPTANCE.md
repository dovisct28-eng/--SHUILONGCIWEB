# A01 浏览器收尾验收记录

> 验收日期：2026-09-21。范围仅限模块 A 的 A01 及其 A02 回中占位；不代表 A02 已实现。

## 1. 验收环境与方法

- 运行入口：`node module-a/a01/server.mjs`
- 页面：`http://127.0.0.1:4173/module-a/a01/?debug`
- 浏览器：Codex 内置 Chromium 浏览器，使用浏览器原生 viewport override 设置指定 CSS 视口。
- 视觉检查尺寸：1440×900、1920×1080、1366×768、1440×1024、1024×768（较窄桌面）。
- 关键状态通过实际键盘滚动进入；调试层读取页面真实阶段与进度。DOM 尺寸检查用于辅助确认横向溢出，视觉结论以实际截图为准。

## 3. 可逆滚动与状态验收

- 前进路径实测依次到达 `travel → growth → copy → reading → a02-transition`，没有跳回自动动画。
- 1440×900 下，正向到达 `scrollY=2361 / 3935 / 4722` 后再反向回到相同位置，分别得到完全相同的阶段和数值：
  - `2361`：`growth`，动画 `0.5247`，模型 `0.7215`，模型位移 `0vw`；
  - `3935`：`copy`，动画 `0.8744`，模型 `1`，文字透明度 `0.21911839696222202`，模型位移 `18vw`；
  - `4722`：`reading`，动画 `1`，阅读 `0.2056`，文字透明度 `1`，模型位移 `18vw`。
- 在 A02 交接状态停滚约 0.9 秒，`scrollY=6296`、过渡进度 `0.7956`、文字透明度 `0.10830204663923171`、模型位移 `1.9494368395061707vw` 均未变化。
- 反向继续滚动可恢复到 `scrollY=0`、`travel`、动画进度 `0`、模型进度 `0`。
- 页面末端实测过渡进度为 `1`，模型位移为 `0vw`、A01 文字透明度为 `0`，说明现有一次性回中已完成；没有第二次回中。
- iframe 内存在五个 `.mural-label` 元素，但在 A01 及当前 A02 占位末端实测全部不可见，符合“进入正式 A02 后才允许显示”的边界。
- 浏览器控制台没有 warning 或 error。

## 5. 限制与结论

- 本轮使用的浏览器工具能够真实设置指定 CSS 视口，因此以上不是根据代码推算的“模拟通过”。
- 截图为浏览器 viewport PNG；Codex 工具界面中的预览可能缩放，但仓库内保存的是原始 viewport 截图。
- 验收通过的是低保真布局、滚动可逆性、稳定阅读区间和 A02 回中占位。空间入口素材、正式文案、最终材质和 A02 标记仍不在本次完成范围内。
- 结论：A01 可以完成低保真收尾；未发现需要修改 A01 代码的问题。
