## 视觉与叙事

本轮概念为「建筑压近，关系浮现」。旧版稳定阅读态是左侧正文与远离正文的右侧小模型；现在同一建筑向中央展开，文字处于前景，建筑处于中景，暗场形成远景。主标题仍是“从出行与归来，看壁画之间的联系”；kicker、作者观点、观看任务、来源、不同释读提示和观众站位全部保留。没有新增历史结论。

- **A02→A03**：沿用最新 A02 已有的10.2–10.95屏场地、植被、远山与暖补光释放。A03 四层暗场同时接管；景观在10.95屏消隐，建筑不重新加载或生长。没有复制或新建山、树、草及地形。
- **构图与尺度**：`composition.mjs` 管理 A03 专属目标，reading 采用真实 viewport 宽、94%高的渲染容器与独立相机距离/FOV，所有默认参数在 A03 权重为零时失效。`--model-scale` 保持1；没有 CSS scale 放大截图。模型横移从旧19vw改为本轮10vw，向中央回压并进入正文右缘附近。1920×1080实测投影占宽58.4%，1440×900为62.0%；62.0%超出建议45%–60%的上沿，但该值不是冻结上限，保留文字和标签安全优先。
- **光影**：复用现有太阳光、半球光、雾和材料。阅读态 exposure .84，sun 2.9，fill .36，FOV34；采用与 A02 相近的主光方向。压低铺地、屋顶及木构的亮度和饱和度，保持砖、木、灰面材料区别。每帧先恢复基础材质再应用权重，不累积改色，真实壁画材料不参与。
- **背景**：深墨灰/墨蓝灰底、大尺度低对比斜向软光、远层空气、1.1%固定 Grain。无圆形 glow、Bloom、粒子或新 renderer。前景暗渐变仅承托阅读区域，来源仍可读；三幅标签处于承托结束处之外。
- **marker**：继续使用原 GLB 壁面节点投影；只插值 screen-space 标签位置。①②⑤形成上/中/下的观看坐标，引线为.8px、末端避让标签。第三/第四幅点线同步退出。交接时第五幅保持清楚，第一/第二幅标签降低至76%而不隐藏；没有提前播放路径。
- **排版**：宋体主标题两行，桌面候选3vw、上限58px，行高1.34；正文18px/1.9，来源14px/1.85。kicker→标题→研究观点→观看任务→来源→hint的透明度依次建立，无逐字、打字机、弹性或大位移。
