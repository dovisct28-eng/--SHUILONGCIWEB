# A01 Cinematic Ink Landscape / 墨境入景 v2

2026-10-03。核实开发基线：`fab296b3a558a7037da99bb2f30c67cf3c5ecafd`，本地与远程 master 一致。本轮是 **待用户审图的实现版本**，不是 `A01 High Fidelity v2 Approved`，不冻结字体、色值或全局视觉规范。

## 资料与任务范围

依据 [高保真规范](HIFI_VISUAL_SPEC.md)、[设计规格](DESIGN_SPEC.md)、[内容地图](CONTENT_MAP.md)、[A01 既有实施](A01_INK_SPATIAL.md) 与用户 v2 任务书执行。Before/After 图是旧版视觉比较，分镜展板是艺术方向；都不是建筑测绘依据。用户随后明确选择喀斯特远景。

本轮只改变 A01 展示相机、环境、光影、材料与后期，并在原 6.2–7.2 屏交接恢复共享状态。GLB、model-source.js、真实壁画原图、壁画元数据、A02–A08 控制器、模块 B 和归档引用不改。共享预览增加受控 A01 的模块初始化、退出和渲染接口，这是接入同一世界空间所需的跨文件修改；独立预览与后续章节仍走既有方案。

**A01 中新增山谷、山体、地貌、植被、雾与天空属于数字叙事艺术化环境，用于建立空间氛围与视觉层次，并非对湖南江永水龙祠周边真实地貌、植被或水系的测绘复原。**

## Camera / scroll

候选 A：沿用 .24rad 俯角偏移；B：.36rad 更低；C：.30rad＋-.10rad 方位偏移。三张 1440×900 实际截图见 [相机比较](validation/a01-cinematic-v2/camera/candidates.png)。A 保留更多院落视面；B 体量更明显但院落压缩；C 对主殿、院落与纵向延伸的平衡较好，因此继续采用 C。未镜像建筑或变更坐标。

仍为原 5 屏动画、1.2 屏稳定阅读、1 屏交接；20% / 65% / 82% 外层分段不改。任务书推荐 38%–55% 等比例用于视觉分析，没有当成新的冻结边界。近看实际主殿，4% 后连续后撤，完整结构线早于实体；原实体按高度显露和旋转保留，材质、光、环境叠合进入；65% 前实体完成，再按既有规则右移和显字。

滚动为唯一时钟；没有开场自动播放、timer、锁滚轮或新 RAF。天空静止、远谷小幅视差，世界树、坡面、雾和建筑按同一相机形成真实视差。reduced-motion 取消新增近景后撤和视差，保留完整场景及原进度。

## Environment / embedding

远景喀斯特画面包含近岩壁、峰丛、远脊和大气远脊，明度、饱和度与细节随距离递减。它是远景 matte；没有把整个场景做成图片，近地环境为真正 WebGL 空间。天空与山谷共用 209,634 B 本地 WebP，避免新增重复文件与解码依赖。来源、prompt、hash 见 [资产记录](../shuilong-temple/environment-assets/a01-v2/README.md)。

96×96 网格坡面在 `x ±6.05`、`z -16.65…13.15` 内与原台基底部 `y=-.615` 对齐；超出后逐渐下坡并按世界距离软化边界。固定种子的非对称树群、较矮的近墙灌木、石块使用 instancing。枝叶是分布于三维树冠的细碎刷纹面，枝干和叶片接受同一太阳光，不用整棵树图片替代近景。

环境 Pass 第一版发现旧无限 ShadowMaterial 地面会深度遮住下坡；A01 改由坡面接收太阳落影，旧平面在 A02 恢复。首次树冠块状感明显，改为细叶刷纹后重新截取 Environment。最终 Composite 进一步缩小远离台基的地面范围、增加近墙灌木及近地雾，避免大块草地像展示底板。

## Lighting / material / post

原一盏方向光与 Hemisphere 保留，太阳位置 `(-16,22,16)`、暖色 `#ffd4a1`、强度 4.25；fill 为蓝灰、强度 .83；曝光 .98。PCFSoftShadowMap 2048² 不增加投影灯。受光侧墙、院落亮区和主殿前部暗区分开，檐下仍保持结构可辨。

屋面、砖、木、抹灰、石与铺地各自使用原 PBR 贴图；`a01-material.mjs` 在原 shader 中加入世界构件坐标的低强度变化。瓦面冷灰而不纯黑，roughness 局部变化；砖墙低饱和红褐、墙脚遮蔽；木构提高与屋面的区分；灰墙/石/铺地分别承光。没有改贴图文件、UV、材质纹理 repeat 或几何。

法线图片可能晚于控制器初始化；首次有 normalMap 时记录 GLB 的真实 .18 强度，之后才乘 A01 系数。退出后精确恢复。roughness shader 在 weight=0 不夹紧原值，避免污染后续章节。真实壁画排除在表面 shader 与材质控制之外。

后期不是完整 GTAO/SSAO 库：采用低成本、无额外场景遍历的 **12 点深度 AO**。一遍渲染 HalfFloat HDR 色纹理与深度，2 samples MSAA；一遍屏幕 shader 根据邻域深度与局部斜率计算遮蔽、做轻冷暖调色、轻暗角，保留 alpha，再按原 ACES 输出。没有 Bloom、LUT、景深或法线预通道。AO 不具备完整法线/多尺度遮挡精度，需要按本轮截图审查；不能称 GTAO。

后期采样 DPR 上限 1.5，原 renderer 的 DPR 上限仍 2。色+深度与 MSAA 存储按 `36 × 目标宽 × 目标高` 字节估算，不包含驱动内部开销、阴影贴图、DOM 合成或所有建筑纹理。进入 A02 时所有新增权重归零；A04 拥有相机时环境和 post 关闭，恢复 34° FOV 与共享材质。

## Known limitations / review status

本轮未使用环境素材作为文化资料，也未提升建筑测绘可信度。原屋面纹理重复、单像素线条、程序化近地细节和深度 AO 的精度仍有局限。远景是艺术化 matte，无法自由环绕；A01 使用受控镜头，不提供自由相机。低性能 GPU、长时间总内存与复杂驱动失败尚不能由本机抽样保证。

**待用户审图，未视觉冻结。** 通过技术验收后同步的是可审查实现，不等于用户已批准 `A01 High Fidelity v2 Approved`。
