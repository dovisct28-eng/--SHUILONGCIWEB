## 2. 第二幅、实际壁面与《入将图》核对

- **用户确认**：第二幅壁画就是模块 B 的《入将图》。这条确认作为当前项目的内容对应事实使用。
- **仓库证据**：`水龙祠壁画素材/壁画原图/第二铺壁画原图.png` 与模块 B 使用的 `Mural-Exhibition/public/assets/splash-bg.png` 文件大小同为 149,142,026 bytes，SHA-256 同为 `30EC4A04567C71226FD53CB6C563234FA795BD6FB2412055D9FE635E46029641`。两者是逐字节相同的文件，与用户确认相互印证。
- **仍不能由仓库证明的现场事实**：`mural-02` 所标注的“主殿右侧内墙”是否就是该原图在真实水龙祠中的准确壁面。模型文档明确称墙面高度、画幅大小和位置为依据示意图建立的暂定示意值，并非实测数据。
- **结论**：已确认“第二幅壁画 ↔ 第二铺原图 ↔ 模块 B《入将图》目标底图”的对应；不能把“第二幅 ↔ 真实主殿右侧内墙”的模型描述升级为已核实现场事实。

## 4. A02 实施条件判断

**A02 具备进入低保真实施的条件，但必须把标记称为“项目编号/模型示意位置”，不能宣称为实测墙位。** 理由如下：

1. 五个稳定节点、位置元数据和现成屏幕投影逻辑齐全，足以验证位置标记、标签避让和多视口表现。
2. 模型与用户布局示意在相对位置上没有发现会改变 A02 标记落点的冲突；不同“左右”描述可由相反观察方向解释。
3. A02 不需要加载三幅高清原图，也不需要证明《入将图》的现场壁面，因而现场核实缺口不会阻塞本阶段的低保真位置标记。
4. A04→A05 的“从第二幅实际壁面进入《入将图》”仍应保留资料门槛；在现场壁面未核实前，不应把这一交接标为事实验收通过。
