## 2. 交接与回退

| 交接 | 正向状态 | 反向要求 |
| --- | --- | --- |
| A01→A02 | Hero 阅读结束，同一建筑回中后出现位置标记 | 先隐藏编号，再恢复 Hero；回中只发生一次 |
| A02→A03 | 核心三幅位置稳定，主题短文进入 | 恢复位置说明，不重播建筑生长 |
| A03→A04 | 主题退出，建立主殿面向戏台的出发站位 | 恢复 A03 相机与文字 |
| A04→A05 | A04 完整路线与三节点保持在全景；用户下滚后由 A05 使第五幅节点成为导读焦点，再进入真实图像 | 回到 A04 完整路线终态，不重播三维行走 |
| A05→A06 | 第五幅巡视抵达左端，短暂提示 ⑤→①，随后进入第一幅 | 恢复第五幅左端，不重播空间路线 |
| A06→A07 | 第一幅巡视抵达左端，短暂提示 ①→②，随后进入第二幅 | 恢复第一幅左端 |
| A07→A08 | 《入将图》巡视抵达左端，保持观看尺度，标题与入口出现 | 恢复第二幅左端 |
| A08→模块 B | 用户主动点击“进入探索”，打开 `http://localhost:3000/` | 浏览器返回时恢复进入前的模块 A 位置 |

A04 不再以“完整路线→再次聚焦第二幅→A05”作为**规划中的交接**。A05 从全景中的 `mural-05` 起步，无需重播 A04 行走，也不让镜头从第二幅骤然飞回第五幅。A04 对后续输出完整空间全景、⑤→①→②路线、三个节点位置及可复用的空间定位数据；A05 自己负责第五幅的空间到图像过渡。A03→A04、A04→A05 仍由滚动驱动并可逆；A04 内部自动播放不锁滚轮、不自动滚页。

**当前实现**：A04 的 16–18 视口高度区间保持全景与完整路线，并逐步强调第五幅。`getA04GuideStart()` 提供第五幅导读起点与 overview 相机；`getA04Handoff()` 仅为同值兼容别名。A05 低保真首轮接续该全景状态；旧第二幅聚焦实现的历史记录见 [A04 记录](A04_PROTOTYPE.md)。

## 3. A05—A08 章节设计

### A05 第五幅壁画导读

从 A04 全景路线中的第五幅节点进入 `mural-05-display.webp`。先呈现一次可稳定阅读的整体介绍，文字淡出后保持统一尺度，随纵向滚动从画面最右端连续巡视到最左端。末端只保留简短的 ⑤→① 提示。第五幅是独立的完整观看章节。

### A06 第一幅壁画导读

从 ⑤→① 的简化提示进入 `mural-01-display.webp`；沿用同一组件，整体介绍之后以统一尺度从右端连续巡视到左端。末端只保留 ①→② 简短提示，不复演 A04 行走路线。

### A07 第二幅《入将图》导读

从 ①→② 的简化提示进入 `mural-02-display.webp`；沿用同一组件，整体介绍之后以统一尺度从右端连续巡视到左端，为模块 B 自主探索建立入口。A07 可以保留略长的介绍和滚动距离，但不增加局部解释、放大或热点。既有第二幅研究记录留在内部内容地图，页面只使用有明确来源的整体表述。

### A08 《入将图》探索交接

沿用 A07 左端终态的《入将图》画面和观看尺度，突出标题与“进入探索”按钮，不增加新知识。只由用户主动点击进入模块 B 大屏入口 `http://localhost:3000/`；滚动本身不跳转。保留浏览器返回原章节与滚动位置的要求，不耦合模块 B 内部状态。

三幅 `display.webp` 作为模块 A 的网页展示素材入库；A05 仅按需加载第五幅，后续章节接近时再预载下一幅。`detail.webp` 不属于 A05—A07 基础导读，也不与三幅展示图一同加载。文件入库不代表图像释读、最终采用版本或现场壁面已经核验；不得改写母版。

**统一交互**：A05—A07 使用一个可复用的二维导读组件。固定视口中，壁画图层按实际渲染宽度减去视口宽度计算行程；进度由纵向滚动确定，三幅均从右端向左端观看，反向滚动精确还原。没有局部焦点、缩放、热点、人物节点或详情面板。介绍文字只在进入阶段出现，巡视时把画面还给壁画。研究观点注明作者与年份；项目路线不称为历史观看顺序。

## 4. 导航与实施批次

全局阶段仍为“建筑空间／主题／观看路径／图像导读”；A05、A06、A07 共属图像导读，A08 为其结束状态。“图像导读”全局入口落在 A05 第五幅导读的首个稳定状态，不直达第二幅。局部进度可显示“第五幅→第一幅→第二幅”，不把三幅加入全局主导航。全局“进入探索”是用户主动跳章快捷入口，仍直接进入模块 B。详见 [导航规划](MODULE_A_NAVIGATION_PLAN.md)。
