## 2. 交接与回退

| 交接 | 正向状态 | 反向要求 |
| --- | --- | --- |
| A01→A02 | Hero 阅读结束，同一建筑回中后出现位置标记 | 先隐藏编号，再恢复 Hero；回中只发生一次 |
| A02→A03 | 核心三幅位置稳定，主题短文进入 | 恢复位置说明，不重播建筑生长 |
| A03→A04 | 主题退出，建立主殿面向戏台的出发站位 | 恢复 A03 相机与文字 |
| A04→A05 | A04 完整路线与三节点保持在全景；用户下滚后由 A05 使第五幅节点成为导读焦点，再进入真实图像 | 回到 A04 完整路线终态，不重播三维行走 |
| A05→A06 | 第五幅恢复整体，简化空间关系提示 ⑤→①，第一幅成为焦点 | 恢复第五幅导读终态 |
| A06→A07 | 第一幅恢复整体，简化路线提示 ①→②，第二幅成为焦点 | 恢复第一幅导读终态 |
| A07→A08 | 《入将图》恢复完整图像，标注淡出，标题与入口出现 | 恢复第二幅导读终态 |
| A08→模块 B | 用户主动点击“进入探索”，打开 `http://localhost:3000/` | 浏览器返回时恢复进入前的模块 A 位置 |

A04 不再以“完整路线→再次聚焦第二幅→A05”作为**规划中的交接**。A05 从全景中的 `mural-05` 起步，无需重播 A04 行走，也不让镜头从第二幅骤然飞回第五幅。A04 对后续输出完整空间全景、⑤→①→②路线、三个节点位置及可复用的空间定位数据；A05 自己负责第五幅的空间到图像过渡。A03→A04、A04→A05 仍由滚动驱动并可逆；A04 内部自动播放不锁滚轮、不自动滚页。

**实现差距**：当前 A04 代码的 16–18 视口高度区间仍聚焦第二幅，`targetMuralId: mural-02` 与 `getA04Handoff()` 均服务旧交接。它们是现有实现事实，不是新规划认可的 A05 唯一目标。下一轮 A05 开发应先以最小范围改造该末段：A04 保持全景终态并暴露中性空间状态，A05 接管第五幅焦点；同时更新 A04 相关测试和浏览器检查。不得改动 A04 三幅顺序、自动观看、全景回撤、路线总结或共用模型结构。本轮只记录接口目标，不修改代码。

## 3. A05—A08 后续任务

### A05 第五幅壁画导读

从 A04 全景路线中的第五幅节点进入 `mural-05-display.webp`，稳定展示整体构图，给出简短基本介绍及 1—3 个经图像和资料逐项核实的可见线索，收起标注并恢复完整画面。局部如需更高分辨率，可按需使用 `mural-05-detail.webp`。交接给第一幅时只短暂恢复简化空间/路线关系。不得将第五幅仅作过场。

### A06 第一幅壁画导读

从 ⑤→① 的简化提示进入第一幅节点与 `mural-01-display.webp`；展示整体、简短基本介绍、1—3 个经核实的视觉线索，再恢复整体。局部按需使用 `mural-01-detail.webp`。本段是独立导读，不复演完整 A04 行走路线。

### A07 第二幅《入将图》导读

从 ①→② 的简化提示进入 `mural-02-display.webp`；稳定呈现《入将图》整体，进行基础介绍与 2—3 个经核实的视觉观察，最后恢复完整图像。局部按需使用 `mural-02-detail.webp`。原 A05 关于第二幅的候选导读内容迁至本段；研究解释须注明作者，不能将争议释读写成事实。A07 可略完整于前两段，但详细探索留给模块 B。

### A08 《入将图》探索交接

沿用 A07 最终完整《入将图》，淡出导读标注、突出标题与“进入探索”按钮。只由用户主动点击进入模块 B 大屏入口 `http://localhost:3000/`；滚动本身不跳转。保留浏览器返回原章节与滚动位置的要求，不耦合模块 B 内部状态。

三幅的 Web 展示图与高清展示图均在本地工作树核对存在，但目前属于未追踪素材，不能据此确认 GitHub `master` 或另一台机器已有这些文件。A05 开发前须确认其稳定本地路径或按用户素材管理决定入库。文件存在不代表图像释读、裁切范围、最终采用版本或现场壁面已经核验。不得改写母版，也不得一次加载全部高清素材。
