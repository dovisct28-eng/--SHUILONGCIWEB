- 以下 A03—A06 的分镜、信息量和开发顺序为本轮规划方案；具体素材、镜头与文案须在低保真验证中落实，不能当作已实现或已核实的历史事实。
- A01 已有浏览器原型；指定多尺寸视觉验收与关键截图归档仍未完成。上一轮仅更新了规划文档，不能据此将 A01 标记为全部验收通过。
- A02—A06 尚未实现；模块 B 已有核心功能。

## 2. 每段只解决一个主要问题

| 段落 | 用户的问题 | 主要画面与动作 | 留给后段的内容 |
| --- | --- | --- | --- |
| A01 建筑开屏 | 我来到了哪里？ | 入口穿越、建筑生长旋转、右移，左侧标题和主题预告 | 壁画编号、路线、具体释读 |
| A02 建筑空间 | 壁画在哪里？ | 同一模型回中，五幅位置总览，再共同强调核心三幅 | 三幅之间的先后行进 |
| A03 主题引入 | 接下来围绕什么主题观看？ | 沿用建筑与核心位置背景，简短引出“出兵·入将”及观看意图 | 人物细节、完整路线、五幅位置重复讲解 |
| A04 空间观看路径 | 我沿什么路径走近壁画？ | 第五幅→第一幅→第二幅；表达前行、左转、再前行 | 长篇图像释读、热点探索 |
| A05 图像导读 | 画面中可以先看什么？ | 从空间中的壁面过渡到真实图像；整体构图与少量局部线索 | 自由缩放、人物节点和详细资料 |
| A06 探索交接 | 如何继续自主观看？ | 沿用目标图像形成稳定入口，点击“进入探索” | 模块 B 内部交互 |

A01 的“出兵·入将”是标题预告；A03 必须补充观看目的，不能只把同一标题再展示一次。A05 负责有节制的导读，A06 负责操作方式的交接。

这些编号是同一条连续叙事的逻辑段落，不要求每段都占一个全屏，也不预设六个独立网页。

## 3. 段落交接与回退

| 交接 | 前段结束状态 | 后段开始动作 | 反向滚动要求 |
| --- | --- | --- | --- |
| A01→A02 | 右侧完整模型，左侧文字，阅读区间结束 | 文字淡出，同一模型回中，稳定后才显示编号 | 先隐藏编号，再回到右侧 Hero |
| A02→A03 | 五幅位置存在，核心三幅共同强调 | 保留空间背景，定位说明弱化，主题短文进入 | 恢复位置说明，不重复生长或定位动画 |
| A03→A04 | 主题已可读，空间背景稳定 | 主题退出，建立主殿面向戏台的站位，指向第五幅 | 恢复主题段的相机与文字状态 |
| A04→A05 | 路径到达第二幅所在空间，停稳 | 经核对的壁面与对应真实图像连续对齐、放大 | 图像收回到同一壁面，不跳到另一幅 |
| A05→A06 | 导读结束，目标图像清楚可见 | 导读标注淡出，目标标题与探索按钮出现 | 恢复最后一个导读状态 |
| A06→B | 图像和按钮稳定 | 用户点击明确入口打开现有大屏探索 | 测试浏览器返回后 A06 状态恢复 |

## 4. A03 任务：主题引入

目的：从“位置认知”转向“主题观看”，保持简短，避免形成第二个开屏。

建议分镜：

1. 沿用 A02 的中央建筑与核心三幅位置，弱化辅助标签。
2. 显示“出兵 · 入将”与一段简短观看引导；已有资料支持的研究释读可注明作者后使用。
3. 留出阅读区间，文字退出，交给 A04 的出发站位。

首版建议只使用一段短文，不逐幅分配未经核实的“出兵/入将”主题标签。具体年代、仪式和人物身份继续按 `CONTENT_MAP.md` 的资料状态处理。主题内容不足时缩短本段，不以重复位置介绍填充。

交付：三帧分镜、文案及来源清单、与 A02/A04 连续的可逆过渡。验收：用户理解主题与下一步观看目的，画面没有重播五幅定位或路线动画。

## 5. A04 任务：空间观看路径

目的：完整呈现项目的第五幅→第一幅→第二幅路径。路线只在本段正式展开。

建议分镜：

1. 标明观察站位：站在主殿、面向戏台；定位身体右侧的第五幅。
2. 停留观看第五幅所在壁面，建立当前空间位置。
3. 沿院落空间前行、左转，抵达第一幅。
4. 再次前行，到达主殿右侧的第二幅；停稳准备进入真实图像。

可以保留弱化的整体位置示意帮助辨向；相机不得穿墙、镜像建筑或把三幅拼成同墙。低保真先验证路径和转向，再决定是否需要完整三维镜头。用简化示意表达的部分须标明，不能称为已完成实景漫游。

资料门槛：核对模型坐标、站位方向和三幅编号与原图的对应关系。模型源码中的“左右墙”不是足够的实地证据；方向判断必须回到用户提供的站位与布局示意。

交付：路线分镜、站位与转向说明、关键节点进度、正反向验证截图。验收：路径准确且可逆，用户能分清滚轮操作方向与建筑内行进方向。

## 6. A05 任务：图像导读

目的：让观众从建筑空间进入壁画画面，获得自主探索前的基本阅读线索。

建议分镜：

1. 从 A04 到达的壁面进入对应原图，先完整展示整体构图。
2. 选取 2—3 处已经核实的可见线索作简短导读，例如人物队列、旗帜或器物；选择以实际图像为准。
3. 收起局部标注，恢复足够完整的画面，交给 A06。

原 `CONTENT_MAP.md` 已将 A05 的导读要点放在《入将图》上，本轮继续沿用这一方向。但“第二幅编号—实际壁面—《入将图》素材”必须核实：若并非同一对象，应先修订 A04→A05→A06 的交接，不能通过替换图片掩盖断裂。

资料不足时先完成整体图像和位置过渡，局部释读保留待核验项。A05 不复制模块 B 的热点、自由缩放、节点详情；图片使用可追溯的 Web 版本，不改母版，不一次加载所有超大原图。

交付：素材对应表、局部范围与简短文案、来源记录、整体到局部再恢复的分镜。验收：图像内容未被改变，导读不重复路线，详细探索仍由 B 承担。

## 7. A06 任务：聚焦与进入探索

目的：结束滚动引导，明确将操作权交给用户。

建议分镜：沿用 A05 最终目标图像 → 弱化导读信息并突出《入将图》标题 → 稳定显示“进入探索”。避免再次完整播放一轮局部放大导读。

用户点击按钮后进入已有大屏 WebGL 入口 `http://localhost:3000/`；不因滚动自动跳转，不接入 `/m`。低保真联调需记录启动模块 A 与 B 的方式，验证 B 可达、浏览器返回及已有交互不受影响。A06 仅通过入口连接，不耦合 B 内部加载或热点状态。

交付：最终入口画面、跳转与返回验证、本地启动说明。验收：能稳定阅读并主动进入探索，不丢失返回路径。

## 8. 开发顺序与停止条件

| 批次 | 工作内容 | 完成后才能推进的条件 |
| --- | --- | --- |
| P0 A01 收尾 | 1440×900、1920×1080 及较窄视口实测，关键截图；必要时修正遮挡、回中和阅读区间 | 记录实际尺寸与证据；未验收不能标完成 |
| P1 A02 | 同一模型回中、五幅位置、核心三幅共同强调、回退 | 节点与位置核对，标签无明显重叠 |
| P2 联合分镜 | 一次规划 A03—A06，建立编号/壁面/原图/主题/来源对应表 | 确认《入将图》对象与交接；有冲突先沟通 |
| P3 A03+A04 | 短主题段与完整空间路线串联实现 | 主题不重复定位，路线与转向可逆且正确 |
| P4 A05+A06 | 图像导读、探索入口、模块 B 联调 | 原图对应准确、文案可追溯、跳转返回正常 |
| P5 整体验收 | 连续滚动、快速跨段、刷新恢复、尺寸变化、资源加载和性能检查 | 核心流程通过后进入高保真 |

A03—A06 此时不锁死滚动长度或每段百分比。先以关键状态和交接验证阅读节奏，再配置距离；不要求六段等长。停滚保持、反向恢复、阅读区间和边界状态应统一测试。
