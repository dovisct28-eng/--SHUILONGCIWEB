# 项目背景（PROJECT_CONTEXT）

> 本文件描述项目背景与定位，不描述具体代码实现。设计规格见 DESIGN_SPEC.md，内容管理见 CONTENT_MAP.md。

## 项目对象

- **研究对象**：湖南江永勾蓝瑶水龙祠壁画《入将图》
- **研究重点**：《入将图》的整体图像叙事结构及其数字交互转译

## 项目定位

本项目为“勾蓝瑶水龙祠壁画数字交互设计”项目的本地 Web 交互原型，以本地运行（localhost）为主要部署方式，将水龙祠的建筑空间、壁画观看秩序和图像叙事转化为数字交互体验。

核心体验路径：
水龙祠建筑 → 建筑布局 → 壁画位置 → 出兵/入将主题 → 第五幅→第一幅→第二幅的空间观看路径 → 聚焦“入将图” → 进入自主探索

## 项目组成

本项目由两个相对独立的交互模块组成，属于统一项目中的两个模块，而非两个无关网站。

### 模块 A：水龙祠壁画叙事引导页面（Landing）

- **职责**：让用户理解“为什么来到《入将图》”。
- **形式**：滚动驱动的叙事引导——水龙祠开屏 → 建筑空间认知 → 壁画所在位置 → 出兵·入将主题 → 第五幅→第一幅→第二幅的空间路线 → 壁画整体浏览 → 聚焦《入将图》 → 进入探索。观众站在主殿、面向戏台时，身体右侧为第五幅；前行左转到第一幅，再前行到主殿右侧的第二幅。这是项目设计路径，不预设其为历史观看顺序。
- **当前状态**：待开发（当前开发优先级，见 AGENTS.md）。

### 模块 B：《入将图》交互探索（Exploration）

- **职责**：让用户真正探索《入将图》。
- **形式**：对《入将图》进行自主探索，包括大图浏览、缩放、平移、局部查看、热点、节点、详情信息等已有交互。
- **当前状态**：核心功能已基本完成，视为已有核心成果，具体内容以当前项目代码为准。
- **代码位置**：`Mural-Exhibition/`（详见 DESIGN_SPEC.md 与 AGENTS.md「代码组织原则」）。

## 模块关系

模块 A（水龙祠叙事引导）→ 《入将图》 → 【进入探索】 → 模块 B（《入将图》交互探索）

- 模块 A 可以调用/进入模块 B；
- 模块 A 不应依赖模块 B 的内部实现细节（缩放逻辑、热点系统、Canvas/WebGL 核心、大图加载逻辑、节点系统等）；
- 进入模块 B 应尽可能通过明确的入口或路由完成。
