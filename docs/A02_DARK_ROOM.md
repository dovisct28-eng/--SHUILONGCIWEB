## 候选视觉值

| 参数 | 本轮候选 / 表达 |
| --- | --- |
| Base Tone | `#0b141b / #182126 / #20272a / #121b20` 宽线性分布 |
| Light Field | 低对比斜向照度，70px blur，无径向圆、halo 或独立背景 WebGL |
| Atmosphere / 前层 | 后层微冷、边缘渐暗；CSS 位于 renderer 后方，不罩住建筑；建筑距离采用原 fog |

| 建筑材料 | 压低 paving、stone，保留屋面/砖墙相对主光与檐下暗部；无新几何、材质实例或贴图 |

## 内容与边界

标题保留“02 / 建筑空间”“壁画，在建筑的何处”“先认识建筑，再看五幅壁画的位置。”。五幅编号只使用原项目数据，模型位置及示意说明继续保留；没有补写实际墙位、文化释读或历史顺序。

先建立五幅，随后⑤①②共同提高字重、锚点和引线对比；③④保留并降低对比。没有路线、箭头、依次行走、强光晕或呼吸。A02 核心段保留完整屋面，定位依然来自模型内部节点的真实屏幕投影，不能把投影锚点当成露出的现场壁面。

reduced-motion 沿用直接显示 A01 稳定 Hero 的方式；A02 仍由用户滚动建立建筑、全部五幅和核心三幅。无新增自主动态，未声称所有章际相机位移已变为静态。
