## 视觉与实现

- **环境融合 / 地面 / 接地**：复用已有 Three.js 地形、岩石、植被及阴影，不重建建筑、不新增模型体块。A02 中压低外围色彩，加入细微土壤明度变化；地面使用平滑透明边界，避免原地形退出时的颗粒边缘。树影使用相同世界坐标边界退场，避免可见场地退出后遗留阴影。
- **光场**：改变 A02 主光方向和屋面/砖墙/台基/院落相对受光权重；复用原方向光和半球光，加入两盏不投影的局部暖补光，分别托起院落与廊道。灯光只在 A02 有强度，离开和倒滚按同一进度恢复；没有灯具模型、Bloom 或独立灯光时钟。
- **前中后**：外围植被和墙根形成近层暗部，完整建筑为中层主体；沿用 A01 已加载的设计性山谷图作低对比远层，以遮罩退入暗部。场地和远景是设计辅助，不是水龙祠实测周边地貌。
- **构图**：宽屏同一相机稍靠近，1024×768 保留完整轮廓。建筑占宽为 55.8% / 62.0% / 55.8% / 67.2%（依次1920、1440、1366、1024）；宽而矮的视口优先标题、轮廓和底部安全区，未强行达到推荐占宽。
- **标题 / 标记**：标题放大并保持展陈信息层；编号与幅名分层，核心①②⑤用暖中性色编号及引线，③④保留后退。锚点仍取原模型节点投影，未移动五幅数据，未新增路线或说明卡片。编号 DOM 只在呈现模式改变时建立，不在每帧重建。
- **五状态**：进入→建筑稳定→全部五幅→核心三幅→逆向沿用既有滚动状态。A01 同一建筑只回中一次，停滚不自行运动，A02 全部五幅先建立后共同强调①②⑤。
