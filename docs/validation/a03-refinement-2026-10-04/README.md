- 本地进度0–0.65：完整屋顶与海报；0.65–1.20：屋面由1降至.66；1.20–1.65：继续到.15；1.65–2.10：完整建筑轮廓、梁架、内院及三铺位置稳定；2.10后标题/正文退场、①②降至.38、⑤保持1；2.65–3.00屋面进一步到.08，接入A04既有入口。
- 仅屋顶透空不足以看到第五铺：近侧主殿/围墙实际遮挡其内墙。复用已有砖/灰面材质，用世界坐标软边界降低该段外墙权重；不改几何、布局或anchor，保留侧墙/端墙/梁架。随A04入口13.20–13.55屏逐渐恢复原材质、阴影及深度状态，A04相机/路线/controller未改。
- 外墙材质在模型内共享，shader按材质去重，仅接入一次，避免重复透明衰减。真实壁画材料不参与，也未改变母版、颜色或人物；A03显示的绿色区域是既有模型壁画位置示意，不是新壁画图像。图片仍由A04原加载接口接管。
- ①第一铺、②第二铺、⑤第五铺是原mural-01/02/05投影；仅调整标签负空间、1.1px引线、19px编号、15px名称、5px锚点与透明度。引线终点避让标签，起点仍在真实anchor。第五铺提示随投影；标签布局在最后.35屏回收，避免进入A04突跳。
- 复用sun、fill、courtyard、gallery四盏灯；透空时小幅提高既有两盏局部灯权重，并让courtyard向主殿靠近，未新增灯具。透空后保留木/砖/灰面差异及阴影。阴影状态与屋顶opacity分开控制，保留A02末端的实际渲染基线。
- 沿用山、树林、地貌及雾。双字区在既有foliage shader中软避让，外围恢复；每层透明权重很低是因为多个树冠层会叠加，并不等于把整片树林删掉。透明植被在A03不写深度，避免遮罩排序污染；A01/A02恢复原模式。无新canvas/renderer/RAF/后处理/全屏纹理。
