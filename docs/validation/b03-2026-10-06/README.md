## 性能观察

图鉴不启动新持续RAF，不创建renderer；静态图层按需加载，切换/退出清理视频及旧请求。体感始终复用一个renderer；布局计算只在图像完成/揭示状态/resize时执行。展开、收拢与resize不重建纹理或几何，不触发新的图像请求；`results.json`记录renderer资源计数与有限重复人物访问的JS堆观察，`b02-regression/results.json`记录30次静态访问后显式GC的JS堆。

上述不是长期泄漏的充分证明，不覆盖浏览器完整进程RSS、图像解码内存或GPU字节。未把无头浏览器RAF调度频率当作物理屏幕FPS；未声称普通展厅PC实测流畅。现有点阵密度、着色器和MediaPipe模型保持，本轮没有新的动画引擎。

本轮体感有限样本：12次真实资源人物切换，每次最终纹理/几何计数均为2/2；显式GC后的JS usedSize从5,129,212 B到5,354,004 B（+224,792 B，约220 KiB），未观察到renderer对象计数持续增长。揭示/收拢连续反向触发新增资源请求为0。8次模拟摄像头会话开始/停止均为8，最多同时1，结束0。样本有限，不能据此承诺长期无泄漏。
