# 模块 A 导览与阅读衔接

基于 `7444fd42420e36f7d86327e61ebc9b34a0ba8db0`。A01 明示滚动操作，A03 突出五铺壁画展厅入口，目录单独标明可直接探索第二铺。A02 标注出现时主殿屋顶局部退让，廊屋和其他建筑体量保留。五个标注统一用「铺」，引线仍来自既有模型锚点。

正式展厅总览显示「从大门进入」，按钮、方向键与滚轮启动同一条入场导览。抵达第一铺才显示铺次，路线弹窗标出当前停点。第二幕说明支持悬停、键盘焦点和点击选中，对应图中编号联动。「回看第二铺全幅」接到第三幕，入口旁说明图鉴和体感的选择。

Chrome 验证了 A01 至三幕的正式主线、三种入场输入、说明联动和 1366×768、1440×900、1920×1080 下的布局，包含常规和减少动态。28 项相关 Node 测试与正式入口构建检查通过。体感摄像头不在本次验收范围内。
