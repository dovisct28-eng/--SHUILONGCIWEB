## 视觉判断与限制

阅读版面扩大图像、重组信息与按钮，细读增加有目标的观察区域和整体位置反馈。B 组被选为默认是本轮设计判断，不代表用户已经批准。

安全区域融合的艺术化程度明显弱于 AI 整图，檐下暗部仍有较强模型感。生成整图的所有木构与柱脚没有被当成准确建筑证据。放大依然使用展示图，没有新增高清细节，不能宣传为母版级观察。

未进行新史料核验、人物身份识别、实地测量或用户研究；“88个人物”等原正文沿用现有页面记录。三处观察点只核对可见形态。未进行跨 GPU、移动触屏或长时显存验证。当前为独立候选，正式接入仍待用户视觉确认。

工作区原有模块 B 素材、归档脚本和其他用户未提交内容均不纳入本轮提交；本轮只暂存独立原型及本目录精选与报告。全仓 `git diff --check` 中用户原有 info.txt 尾随空格不在本轮范围，交付检查以本轮暂存 diff 为准。
