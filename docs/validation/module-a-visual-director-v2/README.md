## 任务书审查与修订

1. 原“壁画在三幅所有状态始终一级”与已有 INTRO 阅读结构冲突。改为介绍态标题是阅读焦点，巡视态壁画绝对一级，保留三幅独立介绍与完整右端至左端巡视。
2. 原“当前路径／走过痕迹／未来路线”容易被理解为行走期间显示导航。仅在既有 46–58 秒回撤后总结中使用，保留 58 秒时间线、停靠镜头、前行、转向、回撤以及正反滚动边界。
3. 建筑模型是依据项目资料约束的设计示意；⑤→①→②是用户确认的数字空间路线，不称作现场实测复原或已证实的历史观看顺序。
4. A01 与 A03 重复“出兵·入将”是标题层级竞争，并非叙事内容互相矛盾。按用户确认保留 A01；A03 小主题“出兵·入将”，一级观看引导“从出行与归来，看壁画之间的联系”。撤销原任务书“出兵先出现／入将后出现”。
5. 全局导航为已有独立待开发规划，本轮不纳入。没有把候选方案升级为冻结要求。

## 视觉参数与明确取舍

- 字体打样为 Noto Serif CJK SC Medium / Noto Sans CJK SC Regular 的本地 WOFF2 子集，OFL 授权、版本和 SHA 随文件保存。仅 A02–A08 注册，A01 使用原字体；正文与标题均有系统 fallback。
- 三组 Accent（暖灰、灰绿、灰褐）在 A02 标记、A04 总结路线、A08 入口联合比较。当前采用暖灰候选；判断理由是与原壁画及砖木关系平稳，弱标记仍可辨。该结论是本轮视觉判断，尚待用户冻结。
- 次要标签若仅靠低透明度会失去阅读性。本轮保留文字约 0.8 权重，通过更弱的点和线区分；核心三幅最终为 1。原浏览器测试的“次要文字 opacity<0.5”更新为当前可读规则，未删去核心三幅或位置断言。
- A02 推荐“建筑宽度 55–68%”不是冻结条件。当前核心态实测占视口宽度：1440×900 为 54.54%，1024×768 为 64.62%，1366×768 为 48.46%，1920×1080 为 49.09%。低高度／宽视口优先保持完整轮廓与上下信息安全区，没有裁掉建筑来满足单一比例。
- 四尺寸 A08 文本与真实背景采样：入口最低对比度为 5.34–7.23，正文为 7.51–9.24。仅验证本次背景与状态，不外推到任意图像、系统或字体设置。
