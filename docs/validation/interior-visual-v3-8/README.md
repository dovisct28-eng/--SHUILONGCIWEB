# V3.8 离庙回望与仪式首屏

正式入口为 `/module-a/gallery/`。本轮 GitHub 基准为 `b879dce47f9109fa9bcbc9dfb2f2288469bc8df9`。

第五铺巡视后沿既有左廊绕过戏台，经中央门洞离庙。相机清出门洞后在继续外移的同时回转，3.5 秒内完成朝向和视野调整，并逐渐减速。右侧定镜保留屋顶、正门和山景，第一幕直接叠在同一实时画布上。左侧采用「五铺壁画，一场仪式」双行标题与短说明，底部按 01–05 显现原比例壁画缩略图。按钮在第一幕出现后即可操作。

## 浏览器验收

| Chrome CSS 视口 | 第一幕 | 第二、三幕 |
| --- | --- | --- |

| 1920×900 | 标题、正文、索引、品牌和按钮完整 | |

| 1366×768 | 标题、正文、索引、品牌和按钮完整 | 裁图、标注、全幅和按钮完整 |

五种视口的第一幕均可在一屏内阅读。浏览器从第五铺全幅触发真实巡视、绕台和离庙。1920×1080 采样中，越过门槛至朝外偏转约 3° 的时间由约 1.56 秒缩短至 0.80 秒。第一幕显示时的相机姿态与离庙末帧一致。交接前后 26 个屏幕采样帧中，建筑主体区域的平均亮度变动约 2.7（0–255），未检出黑帧。

第二、三幕双向切换使用同一张第二铺展示图，过渡期间仅显示配准的过渡图层。模块 B 入口实际打开本地页面，浏览器返回和刷新均恢复第三幕。1366×768 下用系统减少动态设置完成离庙与三幕切换。模块 B 的验证范围为本地页面交接，摄像头体感和用户视觉验收待确认。

18 项相关 Node 测试通过，覆盖离庙轨道、正式路线、第二铺六处细读点与模型及图像基线。构建检查确认母版和正式入口一致、本地依赖可解析、低保真归档引用固定。
