## 优化清单

| 分类 | 发现 | 处理方向 |
|---|---|---|
| 调试状态错误 | seekRoute 遗留第一铺阅读合成层 | 使用原逆向退出接口 |
| 视觉 | ③④⑤标题约56px且居中，完成后仍保留 | 共用投影字阶、上方靠左、降低完成态存在感 |
| 视觉 | ②亮度较早上升，标题尚未充分建立 | 与其余壁画统一先标题后亮起曲线 |
| 状态风险 | 细读和索引图片未等待 decode | 在同一 busy 事务内等待当前图像 |
| 生命周期风险 | 重复选同一环境会重新创建投影；pagehide 未完整释放 finish | 幂等选择与统一退出清理 |
| 返回风险 | 非 BFCache 返回需要重走①至⑤ | 直接恢复有效第五铺停点，恢复期间锁定输入 |
| 正式整合缺口 | 正式 A 仍包含旧三铺路径，V3.4 为开发入口 | 保留 A01–A03 构图，主动接入共用五铺控制器 |
