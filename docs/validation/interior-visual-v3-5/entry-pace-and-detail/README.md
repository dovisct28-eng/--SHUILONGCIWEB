基线为 `223a5cf6eb93e26b1592852a7f657348ba95cf2b`。普通动态导览从接近大门开始平滑放慢，经门洞、戏台右侧进入右廊。原路径的九个停点、相机关键帧和第一铺墙面停靠继续沿用。整段镜头的设定时长从 17.4 秒增至 21.6 秒，第一铺显影接在镜头末尾。减少动态沿用短转场和标题停留。

## 浏览器验收

Windows Chrome 无头模式访问 4173 正式展厅。三种视口分别覆盖普通和减少动态，检查单次输入停靠第一铺、五铺正逆向、细读缩放、拖动、键盘、索引、复位和切换局部后的出处显示。六组均无控制台错误或资源加载失败。构建检查及 26 项专项单测通过。
