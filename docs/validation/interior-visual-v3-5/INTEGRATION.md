第五铺主动点击前先检查3000连接，失败则留在当前阅读态；busy 防止重复跳转。既有 explorationAvailable 仅证明服务连接，并非跨域内部健康检查。真实B页面及其两个模式入口已实际核对。返回时 BFCache 保留当前对象；文档被重新加载时，使用已记录的第五铺有效停点直接恢复，不再依次播放①至⑤。整个初始化及恢复事务完成后才解锁输入。

模块B服务器及内部功能、素材目录、接口均未修改。本轮沿用已有本地服务，不停止用户原有进程。不可用状态由浏览器对真实localhost:3000连接制造 connection-refused 进行验证，未实际停止用户服务。模块B体感依赖外部CDN，实机启动出现GSAP/Hands加载失败；没有把替代依赖或模拟摄像头当成真实通过。详见 TEST-RESULTS.md。
