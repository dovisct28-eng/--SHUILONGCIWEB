# V3.5 穿门转向与细读文案

基线为 f38cbc067f8dd5423e63117012669b68a31dfe8d。普通动态的自动导览用一条局部连续曲线穿门、绕过戏台并对准右廊。曲线沿用原路径经验证的门内、戏台侧和右廊位置。门内交接处保持运动，视线在过门后提前带向廊口。额外时长从 4.2 秒收为 2.0 秒，且在进入右廊前结束。

用 5 ms 间隔采样计算，穿门到对准右廊期间的最大水平转角约由 71° 降至 51°，水平转角变化的峰值约由 327°/s 降至 60°/s。这是轨迹数据。廊口构图另用正式页面分帧检查。

细读页保留局部标题、图像定位和观察说明。出处字段和页面出处行已移除，研究记录见[壁画细读资料](../entry-pace-and-detail/README.md)。

30 项专项单测和构建通过。Chrome 普通和减少动态共六组，实际滚动至第一铺墙面。Combined B 模型在改动区间按 150 段采样，检查相机中心和沿三轴的六个 ±0.12 偏移，结果均无相交。另在 1440 × 900 普通动态下回归完整五铺正逆向、细读定位、文案、复位、滚轮和按键。
