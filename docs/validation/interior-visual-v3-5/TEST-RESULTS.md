## 性能与局限

六组busy期间的父页面requestAnimationFrame P95为7.1–7.6ms，最大间隔513.9–819.7ms，7–14个间隔超过50ms。这组包含碰撞检查、解码、GPU准备及运动，不能换算为真实显示帧率。

进一步分离发现后墙固定碰撞采样一次耗时约666ms。已将同一会话重复采样改为复用首次成功结果，并用原渲染器提前上传纹理、compileAsync准备着色器。未增加Renderer、模型或替换图像。edge结果中已缓存、预热后的④→⑤连续运动101个样本，P95 7.6ms、最大7.8ms，无超过50ms间隔；仅证明这一代表段和这台设备，不能代表全路线所有设备。

首次准备仍可能等待约0.5–1.4秒；期间锁定操作、保留原空间，不以降低真图质量掩盖。没有对多GPU、移动端、超长运行作稳定性承诺。第三/第四铺照片与墙位未完成现场测绘配准，阅读使用保持比例的可逆软过渡。第五铺转向AI失败继续使用零安全蒙版的原模型回退。
