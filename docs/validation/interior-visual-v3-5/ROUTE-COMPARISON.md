两个方案都是当前待核对的空间映射。方案A不称为“现场正确版”，方案B也不称为“考证正确版”。左右按本项目面对主殿后墙时的模型视线描述；报告的观察朝向与现场对应仍待确认。

已核对用户截图和本地《湖南江永水龙祠壁画的发现报告》（刘灿姣、林伟，2016）PDF第3页、刊物第20页：文中将第三铺描述为盘龙，第四铺描述为麒麟，并分别给出主殿正面左、进门右的位置表述。这个核对支持“报告怎样写”，不单独解决当前报告与现场的方向分歧。方案B按用户提出的左盘龙、右麒麟路线建立，不据此添加历史观看顺序的结论。

## 使用

正式展厅 `/module-a/gallery/` 顶部“路线对照”可选择A或B。切换时重新从建筑入口开始，并清除该次交接恢复标记，避免把另一方案的墙位、相机、阅读状态带入当前方案。刷新保留URL中的选择。浏览器从模块B返回时只恢复同方案第五铺。

- 方案A：`/module-a/gallery/?layout=model`
- 方案B：`/module-a/gallery/?layout=report`
- 也可从 `/module-a/a01/?layout=report` 经保留的A03构图进入B方案。A03明确标为“现有模型位置示意”，不把该示意当作B方案的现场证据。

共用一个study控制器、一套真实图片和阅读控件。配置集中在route-cases-v3.5.mjs；不交换图片文件、编号、简介或裁切，不镜像素材，不修改Combined B建筑几何。第三铺仍使用已确认的1286×636盘龙透明轮廓版本，第四铺仍用1280×939麒麟裁切版本。

方案A保持原曲线与安全AI投影。方案B新增第二→左第三、左第三→右第四、右第四→左第五的曲线，仅更改必要空间轨道。因为旧AI机位并非按这条轨道配准，B的后墙与第五铺段使用真实模型材质安全回退；第一至第二铺原已验证的融合保持。没有新生图，也没有将旧AI图强套新机位。
