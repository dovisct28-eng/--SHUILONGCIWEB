## 验收范围

使用忽略目录 `tmp/b-ux-01-validation/` 中的远程 Module B 副本加本轮修改/六个授权抠图进行实际 Chrome 验收。未把作者工作区用作标注测试写入目标。四个桌面视口为 1920×1080、1440×900、1366×768、1280×800。

每个视口检查入口、全景、热点键盘聚焦、详情、体感默认/光标/阅读、中断反馈和模式切换。确认新增说明无溢出、与主体/按钮/摄像头预览不重叠，人物索引换人及模式往返保持 ID。低动态、键盘和页面按钮可使用。缺档案、缺图层和长简介均由标明用途的只读 API 响应模拟，未写入作者数据。

HF 对全部七组 figure 在四视口检查默认/阅读/恢复，共 28 组人物视口、84 个状态；用真实旋转面板矩形和 alpha 占用网格检查人物遮挡，并保留同一人物恢复的几何一致性断言。剩余兼容展示单独检查。

相关 `npm test` 包含 110 项单元/保护回归，并由现有语法检查覆盖内联模块与 server。新增 regression 检查四步文案、成功弱化、真实中断优先、阅读提示仅随实际溢出出现，以及 V4.2 核心文件/生产 callback/舞台时间线与参考提交一致。最终浏览器命令及运行结果见 [TEST_RESULTS.md](TEST_RESULTS.md) 与 [validation-summary.json](validation-summary.json)。

## 验证限制与首轮记录

实际摄像头、真实观众站位/低光/遮挡/恢复及展场体验为 **PENDING**。浏览器驻留/识别状态使用合成摄像头与 Hands/Pose 输出，经生产 callback 和状态机运行，不证明真实手势硬件验收。移动端不在本轮范围，**NOT_TESTED**。

本轮实际浏览器视觉复核通过只针对记录的桌面浏览器环境。正式 summary/sources 的缺项和真实模型/摄像头环境验收仍需补齐，不表示作品最终封版或作者最终视觉批准。
