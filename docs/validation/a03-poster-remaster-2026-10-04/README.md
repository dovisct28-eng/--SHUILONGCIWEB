## 测试与复现

本项目是原生 ES modules，无打包器；构建检查包含源码语法、预览内联模块解析、受保护资源和固定归档引用校验。使用已安装Chrome和本机Playwright，先启动 `node module-a/a01/server.mjs`，设置 NODE_PATH 为可用依赖目录，再运行：

```text
node --test
node module-a/a03/build-check.cjs
node module-a/a03/remaster-check.cjs
node module-a/a03/browser-check.cjs
node module-a/a03/regression-check.cjs a01
node module-a/a03/regression-check.cjs a02
node module-a/a03/regression-check.cjs a04
node module-a/a03/performance-check.cjs
node module-a/a03/boards-check.cjs
```

88项单元测试覆盖源/内联等价、状态、字体、材质恢复、阴影深度、模型与归档等。A03四尺寸（1920×1080、1440×900、1366×768、1024×768）覆盖过渡25%/60%、稳定、三铺标记、⑤交接与A04入口；验证停滚、正向/倒滚、快/慢滚轮、跳滚、刷新恢复、resize及 reduced motion。另有1440×1024检查。结果见 [results.json](results.json)、[构建](build-results.json) 和 logs。

基线保护对照共40帧：A01多阶段、A01→A02、A02稳定/五幅/核心、A04入口。A04入口仅在前后两份截图中同时隐藏已授权变更的A03交接文案，实际建筑及A04界面继续对照。允许8-bit小量化误差；超过4级的像素比例须小于.5%且最大差≤16，或仅边界不足.05%的稀疏像素且最大差≤32。1024宽10.2屏会因滚动整像素取整略过边界，记录其稀疏差异而不误报为场景变化。历史A02回归允许返回时全画面≤2级量化误差，仍校验状态与较大差异。

历史A01脚本末端断言更新到本轮授权A03候选；历史A02标签阈值按已验收A02的.75调整。原A01/A02/A04脚本不修改，由独立wrapper执行并记录。A01 72动画帧/四尺寸/6种降级及A04 58秒过程/暂停/跳过/重播/纹理回归保留。

## 资源与真实性

继续使用同一个scene/renderer/canvas，4盏已有灯；未新增几何、纹理、post render target、RAF或环境图像。复用 `karst-valley.webp` 与已有地形/植被。A03关闭原有post通道，未新建后处理；内存统计中的既有target仍可能保留，并不表示本轮新增。稳定态恢复可见植被会增加draw calls/三角形处理量，详细前后采样见 [performance.json](performance.json)。本机headless Chrome的帧间隔包含调度，不能解释为GPU耗时或跨设备流畅保证。

沿用本地Noto子集，补齐“庙”和指定文案；两文件合计137428B，相比基线增加512B，未新增字体文件/CDN或A01首屏字体请求。

最终专项、40帧保护对照、历史A01/A02/A04回归和构建检查均通过，页面错误及资源失败为0。四尺寸建筑投影占宽71.6%–72.3%，标题字形被真实场景完全遮挡的像素比例9.9%–18.6%，并非整块标题消失。

本机最终采样（90帧静止、90帧滚动，单位ms；p95仅作本机比较）：

| 尺寸 | 静止p95 前→后 | 滚动p95 前→后 | draw calls 前→后 | 三角形 前→后 |
| --- | --- | --- | --- | --- |
| 1920×1080 | 8.1→6.7 | 26.5→30.1 | 52→58 | 90562→199454 |
| 1440×900 | 7.3→7.7 | 26.6→32.1 | 52→58 | 90562→199454 |

两组均为64个geometry、20个texture、1个canvas；scene中灯光仍为4盏，新post targets为0。滚动成本略增，与可见环境残留和更大的画布有关，不把静止采样差异宣传为性能提升。实际加载约12.06MB，资源清单在JSON；字体补字仅替换原两个文件。

建筑继续使用既有设计模型；没有根据AI效果图修改建筑几何。A03环境仅是A02环境的低权重设计残留，不作为现场历史地貌复原依据。文物图像、Module B、A04–A08源码与固定低保真Tag/分支未改。用户工作区原有归档修改、素材删除及无关未跟踪文件不纳入本次提交。手机没有进行完整视觉验收。本轮不继续A04高保真开发。
