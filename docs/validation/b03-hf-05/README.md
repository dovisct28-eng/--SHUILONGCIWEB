## 单向手势冻结规则

有效左、右、斜向挥动只调用 `goToNextCharacterFromGesture()`，其唯一索引动作 `loadSeriesData(currentSeriesIndex + 1)`。当前数组沿用最后→第一个的循环语义。所有成功反馈均顺时针，不把实际delta符号映射到人物索引或动画方向。

READY→触发→锁定：持续张手即使超过1000ms也不重复跳人。原闭手分类连续3帧确认，或检测到手离场，才重新待命；重新待命保留最后触发时间，仍须满足1000ms冷却。双手展开/收起与阅读规则继续沿用。鼠标“←上一组”、下一组及左右键保留。

## 修复过程与验证限制

初次沙箱运行在新验收目录遇到Node EPERM，随后用用户已授权的本项目测试提权执行。动态脚本曾从模块外访问局部OrbitStage、给未使用池节点设置无效动画时间；已改为模块内测试hook并只操作有效节点。30次资源测试发现部分cached入场标记stable时最后错开连接仍有约1.6ms未完成，已让稳定时间覆盖最后一项入场，同时验收等待所有所检查stage tween归零。B01回归首次缺少原脚本依赖的4175静态服务，启动已有只读服务与真实A08指向的3000服务后重跑通过；B02首次误用作者服务，换普通观众服务后重跑通过。录屏审阅中浏览器seek后截图可能仍是旧合成帧，准确时间点审阅改用FFmpeg实际解码，正常播放核验仍由Chrome完成。前次结果/错误诊断留local，最终版本重跑通过；没有通过放宽资源数量上限来掩盖累积。
