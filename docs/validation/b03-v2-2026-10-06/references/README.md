# 用户提供的视觉参考

四张原始 PNG 从用户附件原样复制，仅用于视觉方向对照；不是实测截图，也不构成人物身份、数量、档案内容、历史或真实建筑地貌的证据。页面使用正式仓库数据和素材。实际运行截图在上级目录，明确区分。

参考 PNG 副本仅保留本地并由 `.gitignore` 排除，不随代码重复上传。以下名称是本地文件名；GitHub 上保留此说明，不以参考图替代实测证据。

- `provided-default.png`：图鉴原壁画参考。
- `provided-line.png`：图鉴线稿参考。
- `provided-index.png`：人物索引参考。
- `provided-theatre.png`：体感剧场关键帧参考。
