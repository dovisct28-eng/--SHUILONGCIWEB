# V3.6 展厅解说依据

页码优先用本地 PDF 页序定位。本页供项目内部校核。

## 五铺壁画

> 从右侧走廊到主殿两侧，长长的队伍沿墙铺开。后墙上的麒麟与盘龙，在两侧的队伍之间形成一处停顿。回看这五铺，人物、仪仗与瑞兽共同构成了水龙祠的祭祀图景。

- 刘灿姣、林伟《湖南江永水龙祠壁画的发现报告》，PDF 第 2–3 页「四、壁画的题材及内容简介」。记录右廊、主殿两侧的人物仪仗，以及主殿后部的盘龙与麒麟。作者的第三、第四铺编号与展厅编号有别，页面依经用户确认的③麒麟、④盘龙显示，介绍中只列两种图像。
- 胡彬彬、吴灿《湖南江永勾蓝瑶寨水龙祠壁画释读》，PDF 第 2–3 页（刊页 23–24）。记录各铺画面以及祠堂内的空间分布。「形成一处停顿」属于展陈的阅读设计。
- 本地《开题报告11-11》2-2-1 节转述彭迪等的观看秩序，沿右廊、主殿右侧、主殿中央到主殿左侧，与本项目绕过后墙抵达左侧的总体观看方向一致。论文为彭迪、黄佳、陈奕含、成文昊《湘南勾蓝瑶寨壁画空间叙事结构与数智化修复路径研究》，《文物鉴定与鉴赏》2025 年第 17 期，114–117 页。本地未找到全文，公开试读可核对题录和研究范围，后墙内部次序及左侧走廊在原文中的具体位置仍待核对。展厅第五铺后经右侧通道离庙。[期刊试读](https://czstsg.dps.qikan.cn/pc/maga/text-read?id=wwjd20251728)

## 队伍与祈愿

> 有人骑马，有人步行。鼓乐、旗幡和华盖穿插在队列之间，供桌旁也有人迎接。画上的「风调雨顺」「五谷丰登」，让我们看到勾蓝瑶寨的人们在祭祀中寄托的愿望。

- 《发现报告》PDF 第 3 页与《释读》PDF 第 2 页共同记录骑乘与步行、鼓乐、旗帜、华盖、供桌与迎接的人物。两篇都记录第二铺所绘「风调雨顺」「五谷丰登」，《释读》将这些文字解释为祭祀祈愿。
- 吴灿《湖南江永勾蓝瑶寨水龙祠壁画再释读》，PDF 第 2–4 页，联系瑶族地区其他宗教绘画讨论折扇与仪式的多重关联。李济民《共贺神赛：潇贺古道民间神祠壁画“出兵入将”图像主题研究》，PDF 第 3–7 页，结合区域祠庙与碑刻解释迎神赛会。该文所论出入方向与《发现报告》的左右壁解释不同。展厅以画面共同证据串联仪式主题，具体仪式名、人物身份、步骤和历史方向留待核实。

## 走近第二铺壁画

> 清理后的第二铺主体保存较完整。云纹把队伍分成三层，车马、旗帜、折扇和祠前供桌仍可辨认。接下来，可以用图鉴或体感交互，走近这些人物，看看他们手里拿着什么、身边又有谁。

- 《发现报告》PDF 第 3 页和《释读》PDF 第 2 页均记录右下局部受烟火影响，清理后主体较完整，并描述云纹分层、辇车、折扇、旗帜和祠前供桌。保存表述对应清理后的文献记录，现场现状另待核查。
- 本地《开题报告11-11》「研究方案」以第二铺为交互深化对象。展厅从可辨认的队列和器物引出图鉴与体感。
