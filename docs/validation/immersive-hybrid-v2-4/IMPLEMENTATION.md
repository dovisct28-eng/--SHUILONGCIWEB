# 当前实现状态：规划数据，尚非 V2.4 原型

`src/v24-murals.mjs` 保存五幅 id、标签、原图路径（目前仅第一、第二幅）、模型中心、墙面旋转、宽高、候选停靠机位、阅读机位、转场和状态。`muralGeometry()` 按平面旋转推导观看侧法线及 TL/TR/BR/BL 四角。第二幅停靠机位只是探查候选，尚未启用；第三至第五幅的图像与镜头标记为未定。未修改原 `mural-locations.json`。

`scripts/v24-route-probe.cjs` 对运行中的 V2.3 模型设置候选机位并导出截图和双向射线结果。它是诊断工具，并不创建新的观看流程。依赖本地 4186 服务和已有 Playwright，使用说明与依赖路径见上级展厅 README。检查不足及路线草案见 `MODEL_ROUTE_AUDIT.md`。

本轮没有实现 V2.4 页面、图像接管、2.5D 图层、第二幅合成或状态机，也没有更改已有 V2.3 合成器和正式页面。V2.3 阅读器仍是复用候选，扩展第二幅之前需先把其硬编码的第一幅元数据和单图纹理依赖安全地参数化，并检查真实深度遮挡、UV 和色彩管线。
