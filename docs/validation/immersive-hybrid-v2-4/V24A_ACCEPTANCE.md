## 使用与成果

项目根目录启动 `$env:A01_PORT='4186'; node module-a/a01/server.mjs`，打开 [V2.4-A 独立入口](http://127.0.0.1:4186/module-a/immersive-hybrid-v1/v24.html)。滚轮、方向键或底部按钮沿 V2.3 的原路径移动；右廊末端点“走近壁画”，停靠后可点壁画或“展开壁画”，进入正面阅读；“详细查看”支持缩放和拖动，关闭后返回阅读，再返回墙面、廊道。阅读时滚轮不会推进路线，在详细查看中滚轮调整倍率。右上“场景调试”可切换 Original 3D / AI Scene（仅受限的表面投影）/ Hybrid、墙/地开关、手动接管权重和自动轨道，显示机位与资源信息。素材缺失时可继续原建筑；重新加载页面可重试。

原 V2.3 入门轨道、真实模型、环境、Renderer、Canvas、深度和第一幅原位/数字阅读能力原样复用；没有替换原入口。V2.4-A 新增脚本读取三个模型机位矩阵，将三张生成图中限定的墙面、地面区域投影到从 GLB 原表面提取的两组几何上；前景柱梁、戏台、其余建筑由原模型显示并提供遮挡。投影随相机前进、转向与返回共同运动，图像权重按同一时间和朝向计算；这不是整屏淡出或单一背景缩放。壁画使用既有 2880×990 真实原图和深度合成器，未由 AI 重绘。

模型参考、3 张生成原件、Web 版本、完整 prompt、生成日期、取样局限和模型机位矩阵见 [素材来源](../../../module-a/immersive-hybrid-v1/assets/v24a/PROVENANCE.md)。旧 S01–S04 和上轮 east-mid 不用于本次投影。参考图、近景范围和区域参考源于真实模型运行画面；区域图仅用于检查，产品使用有限取样范围和模型深度，不把区域图描述成已通过的遮挡分割。

## 实际视觉判断

- [同机位原模型与生成候选对照](selected-v24a/12-model-ai-comparison.webp)，[原 3D / Hybrid 右廊对照](selected-v24a/13-original-hybrid-corridor.webp)，以及 [真实浏览器连续录屏](selected-v24a/11-interaction.webm)。录像由实际页面和自动点击录制，为 1440×900 WebM，完整 Blob 已解码抽查；不是静态图片拼接。
- 墙面和地面确实出现生成画面细节，第一幅可以保持独立真实纹理；[右廊](selected-v24a/06-corridor.webp)、[墙面停靠](selected-v24a/08-mural-dock.webp)、[展开](selected-v24a/09-mural-reading.webp)、[返回墙面](selected-v24a/10-return-wall.webp)可直接检查。
- **不足：** 室内大部分仍是原 3D，生成内容是墙和地的局部空间投影，门内没有形成整组 AI 室内环境的充分接管。场景变化主要发生于绕过戏台之后，不应把[过渡中](selected-v24a/04-projection-transition.webp)或[转向完成](selected-v24a/05-stage-turn.webp)称为完整接管。
- 三张生成图有不同光照和细节，投影边缘、材质变化及地面烘焙阴影可能在运动中显露，且墙面局部与真实壁画的材质衔接仍偏生硬。当前使用的是限制范围的平面投影，不是通过量化误差验证的多视角几何重建。不得仅凭自动通过或几张静帧宣称没有漂移、重影或视觉跳变；需审阅录像并进一步调试。
- 因核心的“高保真生成式室内场景自然接管”未完整实现，A 独立入口、E 真图交互、G 记录和已测交互具备；B/C/D 的完整视觉质量，以及 H 对更广泛设备的稳定性尚不能判通过。本轮保留可运行实验，非视觉候选验收通过。

## 验证

- Node 单元测试 25 项通过，包括新权重曲线的连续、边界与确定性；`node --check` 通过。没有声称完整项目构建均通过。
- [浏览器记录](v24a-browser-results.json)：Chrome 156，1440×900、1920×1080、1366×768；验证同机位原画面与投影画面确有差异、鼠标点击真实壁画、滚轮阅读隔离、放大与拖动、三轮往返资源计数、快速重复调用、滚轮/键盘、窗口变化、图片 503 回退和 WebGL 不可用的提示/重试。视口测试使用减少动态模式；常速流程见录像。没有测量物理显示器、低性能设备或实体交互。
- [无录像性能样本](v24a-performance-results.json)：1440×900，本机一次流程，图像加载与解码约 82–181ms；预热两次同步绘制调用约 852ms，包含着色器、图像首次使用等多项成本。11 个动作的 RAF 间隔 P50 约 4.1–4.2ms、P95 约 4.3–4.7ms，最大 41.6ms；稳定资源为 52 个几何 / 28 个纹理。该 RAF 样本不等于实际显示刷新率，也不保证其他设备表现。
- WebGL 上传函数共记录 36 次 CPU 调用，累计约 292ms、最大一次约 116.7ms，其中包含原建筑资源；这些是 API 调用计时，不是 GPU 完成耗时，也不能单独归因到新图。详细记录保留，未用平均 FPS 代替。
- [录像记录](v24a-record-results.json)包含事件、视频时长、哈希和视口；[解码记录](v24a-video-decode.json)来自完整视频 Blob。录像与无录像性能样本分开。
