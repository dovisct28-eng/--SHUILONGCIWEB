## 原问题与机位选择

原 sampleMuralTurn 只从 x=3.85 移至 x=3.55 并转向壁画，仍停在 z=7.65，随后直接用虚拟阅读相机展平。真实相机到壁画中心方向与正面法线偏角为 65.2699°，因此数字转换角度过大。本轮保留原斜向发现，先移动真实相机，再开启原合成器。

壁画中心 `[4.865,1.55,4.8]`，法线 `[-1,0,0]`，宽 3.65、高 1.2547，来自现有锚点和 mural-locations.json；都是设计模型坐标，不是现场测绘。候选计算：`center + normalize(normal) * standOff`。

先探查八个候选，再实施动画。x=2.30、2.65、3.00 的直达路线在 13 组双向偏移射线中分别产生 20、8、2 个交点，涉及廊柱；交点数不等于独立障碍物数。x=2.30 终点取景较完整，但路线穿柱且落在庭院地坪，不采用。这不是证明所有可能绕行路线都不可行，本轮选择不离开廊道的局部调整。

## 通行、遮挡与限制

- 初步检查中心及三个轴的 ±0.065、±0.12 偏移，共 13 组双向射线；最终路径 0 命中。终点到四角及中心的五条视线无建筑交点，柱梁、墙体和戏台未挡住目标壁面。
- 对正式 sampleMuralFront 在真实 GLB 中采样 241 个位置，逐三角形检查半径 0.12 的球体最近点，并检查相邻位置的双向射线。附近参与三角形 20 个，接触 0、路径命中 0，最小表面距离 0.124951。
- 包络剩余裕量约 0.004951 模型单位，仅用于相机，不代表人的通行净宽。检查是离散模型采样，不是连续体积求解或现场验收。室内近裁面约 0.045。
- 终点脚下地坪 y≈0.32，仍在廊道；建筑、廊柱和壁画锚点未移动。

## 运动与数字交接

| 阶段 | 时长 | 处理 |
|---|---|---|
| 斜向发现 | 1450ms | 原 sampleMuralTurn 保持 |
| 自动正视 | 1600ms | 位置与单位视线球面插值，共用 quintic smootherstep，起止速度/加速度为零 |
| 停稳 | 320ms | 真相机保持，reading=0，阅读 UI 隐藏 |
| 数字展开 | 1400ms | 前12%同纹理接管，12%—88%虚拟阅读机位沿法线后撤，84%起出现 UI |

正视比建议的 0.9—1.4 秒略长，因为需完成约 2.866 模型单位移动和约 65° 转向，避免掠过壁面。减少动态模式各运动阶段约 100ms，取消停稳等待。

真实相机从 `[3.55,1.38,7.65]` 平滑到 `[3.30,1.55,4.80]`，位置与朝向同时变化。到达后保持，原合成器继续使用同一纹理、壁面几何、深度纹理和连续投影矩阵；没有第二 Renderer、照片替换、二维翻转或四边形强拉伸。虚拟机位主要沿法线后撤补足全幅，旋转需求已归零。背景在该真实机位渐弱。

数字阅读的画幅比例 2.909062，原图为 2880/990；微小差异来自既有模型高度的四舍五入，本轮不改锚点。返回使用 reading 1→0、同一停稳、front 1→0，最后再由原 turn 1→0 返回廊道。每帧从固定端点重算，无累积偏移。

用户仍使用原来的四个操作：走近壁画、展开壁画、返回墙面、返回廊道，没有增加转正按钮。共享控制器仅增加可选 front/hold 回调，合成器仅增加可选阶段采样器；只有 v24.html 的 data-mural-front=v24a1 启用。旧 V2.3 不传配置，仍使用原转向和 1750ms 阅读展开。

配置保留 muralId、center、normal、尺寸、发现/正视机位及运动参数，供后续复用；其他四幅的路线、碰撞、阅读机位及配准仍须单独验证。

## 生成场景与输入保护

G01/G02/G03 资源、投影矩阵、模型表面和原轨道权重保持。新 pose 带 muralFront 参数，其贡献由 1 平滑降至 0，在 front=0.75 时回到原模型表面；反向同函数恢复。手动 AI 模式及权重也受此机位有效范围限制，不强投失配参考图，真实壁画纹理独立。没有整屏切黑或新增素材。

front、hold、reading 受同一个 busy 锁控制；重复点击和跳点立即拒绝，不排队。过渡期间阅读控件 inert；V2.4 捕获过渡滚轮并在连续输入后短暂静默。阅读态滚轮只在详情弹窗中调整倍率。注入真实 front 绘制失败后，恢复廊道稳定状态、释放锁并成功重试。
