## 实现范围与材料边界

仅 B03 体感：`public/index.html` 的体感材质/动画/资源接入、`public/orbit-stage.mjs` 的环绕演出、`public/b03.css` 的体感阅读和低动态状态、新 `public/mural-surface.mjs`。同步更新测试和本轮文档。图鉴、B01/B02、模块 A、HF-02 纯布局/Alpha算法、摄像头算法、手势数学及阈值、热点/ID/姓名、扫描/保存协议与素材均保持。

材质通过现有 Three.js r160 的 MeshBasicMaterial 着色器钩子处理 figure 显示，不改 org/line/color/figure 文件。与原 map 同一纹理、同一 renderer，不生成图像、不增加外部请求。颜色只作受限的局部明暗，Alpha不变，没有透明洞、补画、改动作/持物/比例或全图变黄。关闭材质、稳定显影且临时隐藏装饰后，1440×900 全画面截图与不带钩子的原 MeshBasicMaterial **RGBA完全一致，差异像素0**。这是渲染恢复证明，不是历史保存状态证明。

材质算法为静态哈希颗粒＋双线性平滑值噪声斑驳；纹理坐标乘实际CSS显示尺寸，兼顾DPR和人物尺度，resize只更新uniform。Alpha四邻域限制处理在内部并生成低强度边缘光。裂纹候选为扰动的稀疏细线，默认0；没有人脸语义判断，所有位置统一保持低强度。环绕彩色局部保存≤380px未处理RGBA，再从原像素生成约主体一半强度的颗粒和斑驳；共享一次生成的CPU噪声场（<1.2MiB）减少切换重复计算，不占GL纹理，不会叠加累积。轮廓、轨道、文字和山谷不加壁画肌理。

## 动画与交互

| 状态 | 候选时长/规则 |
|---|---|
| 首次显影 | 1.05秒；暗影、局部颜料形成、短暂真实Alpha边缘反馈，迅速建立原主体 |
| 已缓存/已测量人物 | 0.62秒；无资源之外的等待 |
| 轨道演出 | 同一时段内由短弧增长；节点、面板、连接按约36%/48%/70%进度起步，最多5块错开25ms |
| 展开/收拢 | 主体0.65秒，面板安全终点再淡入0.15秒，共0.8秒；右侧简介0.16秒后淡入 |
| 离场 | 0.12秒；立即并行读取下一资源，过期动画/请求取消 |
| 稳定观赏 | 无持续轮廓粒子；10秒轨道微弱呼吸，至多两个12秒节点轻微明暗变化 |
| reduced-motion | 显影、轨道、收放即刻稳定；运行中切换偏好也取消旧动画 |

所有鼠标、键盘及原手势调用同一loadSeriesData/setRevealed状态，没有第二套识别或展示逻辑。HF-02 的布局种子、位置、数量和安全碰撞规则未改。展开区仍只显示作者summary、原英文与图鉴入口提示；正式summary当前为空，阅读框随内容收缩，不生成三段介绍或英文名称。

## 资源与降级

figure主体/轮廓共用一张纹理；反馈预算从≤80,000降至≤6,000顶点，仅短暂绘制。最近三套资源LRU缓存不重复请求/解码/上传，figure最多3张GL纹理，纯旧图层最多6张；超出即淘汰释放。切换旧几何/材质释放，晚到结果不上传，Blob URL最终释放，退出清空缓存、小Canvas、tween和GL几何/纹理；renderer继续沿用一个。resize不加载图像、不扫描Alpha、不重建纹理。

现有RAF采样两个连续120帧窗口，平均间隔均>28ms才降低装饰；隐藏/长间隔不形成慢窗口。降级停止点阵反馈、轨道/节点呼吸、边缘光/环境融合/裂纹及环绕入场，保留人物分辨率、摄像头、原交互及阅读连续性。会话内不反复升降，退出复位；阈值是软件保护初值，仍需展厅实机校准。

## 性能记录

同机Chrome `154.0.8037.98`、1440×900、headless、Camera边界替身，修改前后分别采样约10秒rAF及12次人物切换。详细原值见[基线](performance-baseline.json)和[候选](performance-candidate.json)。候选另作120秒稳定运行、周期资源采样和强制GC前后JS堆记录。rAF频率、无头浏览器时间和JS堆不等于真实摄像头响应、GPU帧完成时间或展厅60FPS；不得据此承诺实机性能。

| 同条件软件指标 | 基线 HF-02 | HF-03 |
|---|---:|---:|
| rAF平均间隔 | 4.166ms | 4.168ms |
| rAF P95 / 最大间隔 | 4.60 / 5.10ms | 4.60 / 8.40ms |
| 11次缓存人物资源就绪均值 | 136.55ms | 55.36ms |
| 11次缓存人物达到opacity≥.999均值 | 353.27ms | 479.64ms |
| 初始正式01 GL纹理 / 几何 | 2 / 2 | 1 / 2 |
| 两分钟固定观赏纹理 / 几何 / renderer | 未测相同时长 | 每20秒采样始终2 / 2 / 1（已缓存01与本地05） |
| 候选两分钟GC后JS堆 | 无匹配GC对照 | 5,544,900→5,595,936 B，增加51,036 B；backing storage保持5,254,108 B |

缓存资源就绪约减少59%；新增显影演出让缓存人物opacity阈值耗时更长，未宣称所有切换指标均更快。该opacity阈值早于整段0.62秒演出结束，不代表全部环绕已稳定。首次不同人物05的opacity阈值约1,570→828ms，依赖原先本地未提交作者素材，不作为不同正式素材验收。JS堆原始采样受GC影响，不能拿基线/候选不同GC时点证明整体内存降低；两分钟稳定资源数量和GC后约50KiB增长只证明此软件窗口内未观察到持续资源累积。rAF并非GPU完成帧数；测试没有真实摄像头输入，也没有足够样本承诺长期稳定性。
