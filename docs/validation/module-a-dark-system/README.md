# 模块 A 全屏开场与深色视觉统一验收

日期：2026-10-03。开发基线：`c6f021454dd4f7ab9afb4d597703f1cdd2548086`，修改前 fetch / 本地 HEAD / origin/master / GitHub master 一致。当前为技术验收通过、待用户整体视觉审查；不代表视觉冻结。

建筑、壁画与光影属于空间层；文字、编号、文献与说明属于展陈信息层。深色负责空间，米白负责信息。具体 HEX、字号、镜头和窗口参数是本轮高保真打样值。

## 实现和范围

- `module-a/a01/cinematic-state.mjs` 把 cinematic、Hero、回中和环境退出分开。0–48% iframe 的实际显示框等于 viewport，取消 CSS scale；48–58% 连续收束到既有 Hero 尺寸。开场近景/后撤继续由真实相机位置、target 与 FOV 控制，不改变模型几何；沿用 V3 三级轮廓与 58–70% 世界坐标光扫。5 屏动画、1.2 屏阅读不变。
- 树问题包含两条实际代码路径：A01 的透明环境材质继续写入深度；交接时 `1-heroWeight` 会重新显示旧浅色景观。前者改为不透明存活片元＋世界坐标 dither/discard，颜色与深度同时停止；定制深度材质共用退出 uniform 和世界噪声，阴影同步退出。visibility≤0.04 隐藏整个环境组。后者在受控 A01 场景中停用旧景观返场。没有全局关闭植被 depthWrite。
- 6.2–6.55 屏环境和 DOM 山谷先退场；6.4–7.0 屏建筑/镜头一次回中；6.55–7.2 屏 A02 标题/footer 接管。建筑始终存在，深色背景连续，A02 时 A01 景观、线、Post、FOV 和特殊材质状态恢复/退出。
- A02 墨灰建筑观察、暖灰编号/细引导线/较小锚点；A03 同一建筑沉暗，主题成为阅读主体；A04 非当前建筑降低亮度，路线使用暖灰，当前标注增加局部深色承托；A05–A07 共用深色观看空间与弱暖褐灰外部阴影，介绍遮罩在巡视时退出；A08 深色底、稍暖局部承托和主动入口。
- A04 controller 仅把旧 CSS scale 的显示尺寸换算为实际 iframe 尺寸，保留等价显示边界。自动时钟、camera path、focus/return、路线几何、replay 和滚动所有权均未改；`path.mjs` 未改。A05–A07 controller / progress / 文案 / 原始图片未改。GLB、model-source、墙位、metadata、UV、模块 B 和固定归档引用未改。

- 色板和视觉候选待用户冻结审查；全局导航尚未实现，本轮没有声称完成导航。

- 保留用户原有低保真启动器/归档文档改动、素材删除与既有未跟踪文件，本次提交不包含它们。
