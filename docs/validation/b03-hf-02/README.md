# B03-HF-02 · 多人物自适应与环绕面板布局

2026-10-07。执行前 fetch / ls-remote 确认 HF-01 已实际推送：本地 HEAD、origin/master、GitHub master 均为 `6220d742143568ddd96f219bac715cdc3ef8a77d`。本记录为软件/浏览器验收及视觉候选，作者最终审图与实机验收仍待完成。本阶段止于自适应布局，没有进入第三阶段复杂动态和材质重制。

## 实现

- 一次原Alpha扫描同时计算24×24占用网格、原始/带余量边界、有效比例、像素重心、上下/左右占用比例。Alpha≥1均保守保留，细物和弱边缘会扩大避让；不去噪、不删除真实结构、不改原图。网格不识别脸、武器、动作或身份。
- 新增纯算法 `orbit-layout.mjs`。模板由实际有效比例和重心偏差决定，接近得分以稳定ID打破平局；FNV-1a＋Mulberry32种子为ID/版本/默认或展开模式，布局版本为 `b03-hf-02-v1`。无ID编号布局表、无Math.random、无随机重试。
- 每个内容在有效人物边界椭圆及视口负空间中生成正常/较小候选，最多320候选、8轮有限组合。旋转面板加4px边饰，避让占用单元10px、实际功能区12px、其他面板16px。人物主要视觉中心预留；合格组合再按空间利用、平衡、间距、面积及模板偏向评分，不以面板数量单独定胜负。
- 不足时换候选/缩小次要框/减少框/减弱轨道，最终可以0–1块；装饰不改变人物的原fitScale、作者scale、anchor/offset和人物安全区。原camera/figure校准继续生效。
- 局部图先由缓存网格挑选，再用最大380px小Canvas核对实际非透明覆盖≥4%；无合格裁切则省略。源窗口低于24px不制造模糊局部；面板边长至多为源窗口像素的1.25倍。真实颜色/比例保持，轮廓只来自同源Alpha。独立line/color没有可靠局部配准，故使用允许的抽象轮廓，不制造错配局部，不增加资源请求。
- 5个面板DOM/Canvas节点复用；几何缓存最多64份小数据、布局缓存最多16套，不保留全分辨率像素或额外图像引用。默认/展开分别保留稳定布局，收起恢复原结果。无额外RAF、Three.js renderer或GL纹理。
- 简介使用实际目标DOM边界，异步内容/字体就绪后更新；切换人物保留打开状态，清空旧面板并取消请求，晚到结果由版本阻止。面板在人物过渡期间隐藏、在安全端点显现；轨道和连接线避开功能区遮罩，快速反向覆盖已有tween。
- 作者模式新增可选面板上限、模板、左右偏向、轨道强度和归一化整体偏移；预览/恢复/复制继续沿用现有工具。复制保留summary/layout/bounds与未知元数据，恢复仅清除已识别预览校准；不写meta.json，不变扫描/保存协议。

接口、参数范围与示例见 [人物研究说明](../../B03_CHARACTER_STUDY.md)。颜色、面板尺寸/权重和评分参数仍为可审查的设计候选，技术通过不构成永久视觉冻结。
