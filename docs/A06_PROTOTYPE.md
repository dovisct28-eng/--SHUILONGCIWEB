# A06 第一幅整体导读

- 滚动区间：25–32 个视口高度；25–25.4 与 A05 短暂交叠，二维壁画交叉淡化，不返回建筑模型。
- 资源：`MURAL_RESOURCES['mural-01'].display`；在进入前两个视口预载。按实际图片比例和视口宽度计算从右端到左端的行程。
- 结构：整体介绍、文字退出、完整巡视、左端停留及 ①→② 提示。向上滚动、刷新和调整窗口尺寸均由滚动位置重新计算。
- 页面文案依据：刘灿姣、林伟《湖南江永水龙祠壁画的发现报告》（2016），刊物第 20 页（本地 PDF 第 3 页）关于第一铺位置及骑马、步行人物的描述。页面中的第五幅→第一幅是项目确定的数字观看路线，不能推为历史观看顺序。人物身份和仪式名称未作判断。
