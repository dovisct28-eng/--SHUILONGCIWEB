## 2. Design Read 与三项控制参数

**已冻结规则 / Design Read**：模块 A 默认按照用户尚未建立水龙祠建筑、壁画位置与观看路径关系的进入场景组织信息。以空间理解和连续观看为核心，采用克制的中文编辑排版、建筑空间展示和真实壁画导读。

这是一项信息组织前提，不是已经用户研究确认的人群画像，不推定观众的年龄、知识程度或理解效果。

| 参数 | 已冻结的全局参考值 | 执行含义 |

## 3. Art Direction 与整体节奏

**已冻结规则 / 总 Art Direction：建筑建立空间，壁画主导观看，界面克制退后。**

辅助设计原则：**空间清晰、材料可信、观看从容。**

**已冻结规则 / v1.1 执行概念：「墨夜光场」。** 深色由明暗、空气、距离、局部照度和负空间共同构成观看场；A02–A08 延续同一暗空间体系，不能用七种独立背景或一张贯穿背景图替代连续设计。完整模型见第18章 [Dark Spatial Field / 暗空间视觉场](#18-dark-spatial-field--暗空间视觉场)。

| 原则 | 可执行判据 |
| --- | --- |
| 空间清晰 | 建筑轮廓完整；标记可追溯到壁面；路线保留前行、转向和回撤关系；正文不遮住正在解释的空间 |
| 材料可信 | 建筑材质受资料约束，环境明确为设计表达，真实壁画保持独立原图；不把视觉重构称为实测复原 |
| 观看从容 | 每章保留稳定阅读状态；巡视时介绍退出；停止用户驱动的滚动时画面稳定；控件可辨且不抢占主体 |

- **已冻结规则**：A01–A04 为建筑与空间建立阶段；A05–A08 为真实壁画接管阶段。A04 是空间运动高点，A05–A07 是图像观看高点。
- **已冻结规则**：A05、A06、A07 使用统一导读体系，均为独立完整章节，不把第五幅和第一幅弱化成第二幅的过场。
- **推荐范围**：保持连续深墨灰/墨蓝灰空间底色、哑光建筑与低对比外围环境，通过内容、尺度关系和留白形成章节区别。
- **待打样项目**：A01 建筑与水墨的接地；A02–A08 非景观光场、空气距离、阅读承托和章际明度连续性。不得把 A01 环境打样授权延伸为后续章节景观返场。
- **禁止项**：普通 SaaS 页面、商业卖点卡片、传统博物馆门户栏目化；水墨全站滤镜；UI 模拟古代器物。

## 4. Visual Hierarchy Budget / 视觉权重预算

### 4.1 冻结预算

- **已冻结规则**：每个稳定 viewport 原则上只能有一个一级视觉主体；二级视觉信息原则上不超过两个；三级说明信息必须退后。
- 一级承担当前观看或理解任务；二级补充该任务所需的标题、解释或操作；三级提供来源、资料边界和辅助状态。可按内容分组，但不得把所有竞争元素合称一个组来规避预算。
- **已冻结规则**：全局导航和叙事进度不能与一级主体争夺注意力；背景环境永远不能超过建筑或真实壁画的视觉权重。
- **已冻结规则**：光场、空气层、暗角与 Grain 同样进入权重审核。稳定画面中背景不得成为一级；若首先注意到光晕、噪点、雾或渐变，须退回打样修正。
- **已冻结规则**：A05–A07 巡视状态下，真实壁画必须成为绝对一级主体。介绍、来源及其遮罩退出，不新增持续释读层；仅保留轻量位置提示与必要导航。
- A03 阅读态以“从出行与归来，看壁画之间的联系”的观看引导标题为一级，“出兵·入将”为小级别主题标识，建筑作为二级辅助；这是 2026-10-03 用户确认的标题层级修订。A05–A07 介绍态以本幅标题为阅读焦点、壁画暂作承托，进入巡视后一级明确交还壁画。A08 保持壁画为一级，标题与 CTA 作为二级入口组。
- 过渡帧允许短暂交叠，不能把两个同等强度的主体持续到稳定状态。若确需例外，须记录具体状态、原因及设计审核结论。

### 4.2 预算验收

- **推荐范围**：缩小至整体缩略图检查“先看到什么”，再按原尺寸检查字体、标记与操作可读性；结合面积、对比、饱和度、运动和遮罩评估，不只比字号。
- **待打样项目**：每章稳定态标注一级、二级、三级的截图；A02 五幅标记与建筑、A04 路线与建筑、A08 CTA 与壁画的联合权重。
- **禁止项**：多个大标题并列、多个饱和色焦点、主体运动时背景持续漂浮；以过淡小字换取形式上的层级。

## 6. 中英文字体、层级与字体工程

### 6.1 排版方向与推荐范围

**已冻结规则**：宋体标题＋黑体正文／功能文字。英文只用于必要译名或真实信息，不增加装饰性英文副标题。正文不使用书法体。

| 角色 | 字号推荐范围（桌面 CSS px） | 字重／行高推荐范围 |
| --- | --- | --- |
| A01 主标题 | 72–96 | 宋体 500 左右，1.1–1.2 |
| 章节标题 | 36–52；短主题可在样稿中比较更大一级 | 宋体 400–500，1.2–1.35 |
| 导语 | 20–24 | 黑体 400–500，1.6–1.8 |
| 正文 | 17–19 | 黑体 400，1.75–1.9 |
| 导航、标签、控制 | 14–16 | 黑体 400–500，1.4–1.6 |
| 来源、资料边界 | 13–14 | 黑体 400，1.6–1.8 |

- **推荐范围**：正文每行约 24–32 个汉字，标题字距 0–0.06em，正文 0–0.02em；窄屏正文可比较 16–18 px，不以无限缩小文字解决溢出。
- **待打样项目**：思源宋体/Noto Serif SC 标题与思源黑体/Noto Sans SC 正文的具体文件、字重、拉丁字符协调、标题断行及品牌字样。只选实际需要的一套宋体和一套黑体，候选并非同时加载。
- **禁止项**：用极细笔画、超大字距或低透明度制造“高级感”；同一标题临时混用字体强调；将所有来源缩成难读微字；伪造英文译名。

### 6.2 工程约束

- **已冻结规则**：本地运行优先，以项目本地 WOFF2 提供网页字体；不依赖 Google Fonts、外部字体 CDN 或联网授权服务。核对授权与子集化许可，记录来源和版本。
- **已冻结规则**：仅引入实际需要的字重；中文字体合理子集化或分块资源控制。子集须覆盖上屏文案、标点、数字、拉丁字母、状态/错误文字及引用作者姓名，文案变化后复查缺字。
- **推荐范围**：首轮以标题一个字重、正文一个字重起步；只有层级确有需要才增加功能字重。变量字体与静态子集比较真实传输量后选型，不默认加载完整 CJK 字库。
- **已冻结规则**：明确 fallback。标题候选链为“已选本地宋体 → Songti SC → SimSun → serif”；正文候选链为“已选本地黑体 → Microsoft YaHei → PingFang SC → system-ui → sans-serif”。字体别名按实际打包文件确定，不能声明不存在的自托管资源。
- **推荐范围**：使用 `font-display: swap`，优先仅预载首屏必要子集，其余按实际使用请求；通过回退字体度量和稳定容器减少换字跳动。
- **已冻结规则**：不能因高保真排版显著增加首屏资源负担。打样必须列出字体请求数、WOFF2 总量、首屏实际字节及换字前后布局；与同机同缓存条件下的无新增字体基线对照。
- **待打样项目**：字体字节预算、子集生成清单、预载集合及性能阈值，须在字体接入前记录并确认。超出预算先缩减字重/子集，不默认扩大预算。
- **禁止项**：阻塞首屏等待字体、预载所有章节完整字库、仅测字体已缓存状态、忽略 fallback 缺字或标题溢出。

## 7. 网格、间距、留白与信息安全区

**已冻结规则**：12 列网格只用于文字、导航、标记、UI 控件和信息安全区。建筑模型、真实壁画、水墨环境、Three.js 镜头及主要视觉画面不强制服从网页栅格。

| 项目 | 推荐范围 | 执行与打样要求 |
| --- | --- | --- |
| 桌面 UI 外边距 | 视口宽的 5%–7% | 窄桌面可比较 24–48 px；保持可读而非机械比例 |
| 网格沟槽 | 24–32 px | 不作为模型镜头或图像切片的计算依据 |
| 基础间距级差 | 8、12、16、24、32、48、64 px | 用于同类元素一致性；允许光学修正 |
| 标题至正文 | 20–32 px | 长标题换行后仍有层级 |
| 正文段间／来源间隔 | 12–20／20–28 px | 来源独立成组，不挤进正文 |
| 顶部信息安全区 | 导航＋进度实际高度，再留 16–24 px | 按渲染高度计算；禁止固定猜测后遮住标题/标签 |
| 底部控制安全区 | 控件实际高度，再留 16–24 px | A04 控制与图像交接提示不得相压 |
| 标签与文字最小视觉间隔 | 12–16 px 起步 | 连线、标签、模型投影联合检查 |

- **已冻结规则**：建筑标签的锚点跟随真实模型投影，标签轨道可受 UI 网格约束；不能为了对齐栅格移动壁画节点或镜像模型。

## 11. Motion Design 与 reduced-motion

### 11.1 冻结原则

- Motion 只服务空间解释、章节转换、注意力和操作反馈。一个时刻只有一个主要运动焦点；镜头运动时文字、背景和控件不做竞争性表演。
- A01、章节滚动交接和 A05–A07 巡视由滚动进度决定：停滚稳定，反向恢复，不锁滚轮、不自动滚页。A04 内部自动观看是明确例外，保留既有状态管理。
- A04 保留三幅观看、停靠、回撤、路线总结及完成终态，允许跳过、重播、提前离开和后台暂停；从 A05 返回完整路线终态，不重播行走。
- A05–A07 的“右端到左端”是观看方向；图层相应向右移动。按实际渲染宽度减视口宽度计算行程，图像可完整容纳时行程为零，不能强行放大制造运动。

| 动效对象 | 推荐范围 | 待打样项目 | 禁止项 |
| --- | --- | --- | --- |
| 文字进入/退出 | 透明度为主，位移可从 0–16 px 比较 | 阅读开始和退出的完整可读帧 | 拆字、打字机、书法描摹 |
| UI hover/active | 120–180 ms，颜色/边界反馈优先 | 与焦点状态一致性 | 磁吸、弹簧、持续呼吸 |
| 滚动交接 | 沿用进度函数和既有状态边界 | 透明度重叠、画面接缝 | 将毫秒 UI 动效时长套入滚动时间线 |
| A04 自动路线 | 当前 58 秒作为回归基线 | 40–45 秒只可作未来独立对照评估，改变时序前另行确认 | 将建议时长视为已批准修改 |

### 11.2 reduced-motion 的当前基础与未来边界

- **已冻结规则**：不漏掉内容、三幅完整可观看范围或主动探索入口；不新增自动动效。减少动态效果不等于删除章节。
- 当前 A01 按 V3/深色系统记录在 reduced-motion 下直接显示稳定 Hero，跳过局部穿行与线稿显现；章节交接及 A02/A03 仍主要由用户滚动控制，不能宣称全流程已经实现全静态替代。
- 当前 A04 在 reduced-motion 下直接采用完整路线终态，仍保留滚动入口与向 A05 的交接；不运行 58 秒自动观看。
- 当前 A05–A07 展示高度采用约 70vh，仍按实际宽度保留从右端到左端的完整范围；不是强制将超宽图压入单屏。A08 继承同一模式下 A07 的终态，入口可用。
- **待打样项目**：A01 减旋转、章际减位移等进一步降级方案；这是未来单独评审的增强项，不是本次改写时间线的授权。
- **禁止项**：把 reduced-motion 设置作为跳过壁画内容的理由，或只移除动画却留下不可达文字/控件。

## 13. 章节交接与反向恢复

| 边界 | 已冻结的视觉继承 | 验收重点 |
| --- | --- | --- |
| A01→A02 | 同一建筑右侧回中，阅读结束后接管；导航回中后出现 | 只回中一次；倒滚先隐藏标记/导航再恢复 Hero |
| A02→A03 | 空间延续，③④退出，说明转为主题 | 不重复五幅介绍、不提前播放路线 |
| A03→A04 | 文字退出，空间成为一级，滚动进入路线 | 模型连续，无硬切和文字重叠 |
| A04→A05 | 全景总结后接近第五幅，模型投影接二维右端起点 | 模型/图像比例不拉伸；遮罩不提前洗白模型；反向完整路线可恢复 |
| A05→A06 | 第五幅左端→简短⑤①提示→第一幅介绍 | 仅交接窗短暂交叠，不能把两幅误看成同一壁面 |
| A06→A07 | 第一幅左端→简短①②提示→第二幅介绍 | 同一体系；不改变观看方向 |
| A07→A08 | 同一图像、同一尺度、同一左端 | 无跳变或重复加载，仅入口层改变 |
| A08/导航→B | 明确点击入口，离开模块 A | 返回恢复各自来源；B 不叠加 A 导航 |

- **推荐范围**：优先透明度与位置继承；视口 resize 后仍保留当前章节语义位置。
- **待打样项目**：A04→A05 投影矩形接缝、两幅交接重叠透明度、导航出现与退出边界的视觉感受。
- **禁止项**：模型到图像伪装为现场逐像素配准、跨章飞行、反向自动重播、缩短阅读区间为装饰腾位置。
- **已冻结规则 / v1.1**：A02–A08 光场参数随既有进度连续插值；正向、反向与章际端点一致。不能在章节边界直接替换独立 gradient；不改变任何滚动长度、巡视行程或 A04 自动时钟。第18.5节规定参数职责和恢复验收。

## 14. 响应式、可读性与性能预算

- **已冻结规则**：桌面验收覆盖 1920×1080、1440×900、1366×768、1024×768；更窄视口至少保证信息与入口可达，不将模块 B 移动端 `/m` 自动接入模块 A。
- **推荐范围**：窄屏优先调整 UI 排布、文字宽度与安全区；用统一导读尺度规则重新计算图像行程，不将页面整体缩小。正文放大和字体 fallback 下不得遮住主要操作。
- **已冻结规则**：键盘可操作、焦点可见、隐藏章节不可聚焦；对比度按第 5 章验收。来源说明和争议边界不能为适配被删除。
- **已冻结规则**：保留 GLB 单次加载、环境本地资源与失败回退、三幅壁画按章节接近请求；不同时加载大母版，不新增无必要 Canvas、常驻 RAF 或后处理器。
- **推荐范围**：首轮视觉实现保持模型几何与贴图量零增长，优先通过排版、材质参数和既有资源改善效果。
- **待打样项目**：字体预算和全流程性能阈值须建立同机、同视口、冷/热缓存对照；记录资源字节/请求、首屏文字可读时间、模型就绪、图片解码、帧间隔及内存。明确浏览器、GPU、样本数量，不把既有 headless 单次抽样解释为跨设备保证。
- **禁止项**：凭感觉宣布性能无影响、把模型 ready 当所有图片解码完成、只测稳定静态画面或缓存命中情况。

## 15. Anti-AI / Anti-slop 禁止项

**禁止项**：

- 紫蓝渐变、霓虹发光、装饰粒子、鼠标光晕、无意义玻璃拟态。
- “中国红＋金色＋祥云＋卷轴＋印章”等泛化非遗视觉模板；UI 模拟卷轴、匾额或古代器物；笔刷字与伪旧纸纹堆叠。
- 三等分功能卡片、Bento 拼贴、八章统一居中大标题、为差异强行交替左右版式。
- 每章机械重复“英文小标题＋编号＋装饰点＋分隔线”；虚构档案编号、年份、地理数据或引用。
- 标题无限放大、正文过细过淡、来源微字化；为视觉简洁删掉资料边界。
- 云雾、树木、山体持续循环，或把水墨、噪点、sepia 永久铺在壁画上。
- AI 修复替代文物、无依据重绘人物与建筑、将学术解释写成唯一结论。
- 为新鲜感重写 A05–A07 三套版式或复制模块 B 深入探索功能。
- 蓝紫科技光、金色/星空粒子、Bloom、Lens flare、发光边框、大面积模糊彩色 blob、景观灯光圈、卡片堆叠、巨型英文装饰字与无功能装饰。
- 用“`background:none` + 内容”冒充高级极简，或把降低复杂度理解为删除暗空间层。此项约束观看场结构，不禁止 UI 元素透明或沿用透明 iframe。

**已冻结规则**：真实来源、必要滚动提示、地点名称、路线节点和重复的统一导读框架有明确职责，应保留。Anti-slop 不能成为删除必要信息或否定既有叙事的理由。

**推荐范围**：优先移除无功能装饰，再检查内容与图像层级。**待打样项目**：现有章节编号和重复状态文字与新导航的取舍，需保留必要定位信息，不能机械全删。

### 16.2 v1.1 逐页开发制度（已冻结规则）

开发顺序固定：**A02 → A03 → A04 → A05 → A06 → A07 → A08**。本轮只完成规范、检查、commit、push 和远程核实；下一阶段仅开发 A02。每页技术与视觉验收通过并经用户审图后冻结该页，再进入下一页。未通过时只修正当前页，不继续下页。

“冻结该页”指已审图的章节范围与状态，不自动冻结全局 Accent、字体文件、精确光照、字号或间距。候选继续登记，只有对应决策明确通过才转为冻结。单页阶段允许检查邻页接口，不能借验收顺带开发邻页。全局导航仍是独立待开发任务，本轮不接入，不把“规范已确认”写为“已实现”。

| Phase A02 | A02 建筑暗室与必要 shared visual infrastructure | 不开发 A03；正向/反向、四尺寸、reduced-motion、状态截图与性能检查通过，用户审图后冻结 A02 |

### 16.3 每页统一验收门槛

每页单独记录五种状态，并在 **1920×1080、1440×900、1366×768、1024×768** 各提供代表截图及相应过程证据，不能只交最终稳定帧。

| 状态 | 必须回答/记录 |
| --- | --- |
| 进入态 | 如何继承上一章主体、位置与光场 |
| 稳定态 | 唯一一级主体、二级预算与前中后亮度关系 |
| 运动态 | 滚动或既有自动过程中的空间关系；停滚/暂停是否符合原规则 |
| 结束态 | 下一章交接前最终画面；不提前开发下一章 |
| 逆向态 | 向上滚动是否恢复正确端点、信息和光场，无残留/跳变 |

每页必须逐项回答以下视觉审查问题，注明截图尺寸、状态、依据和待修正项。以下是审图判断，不能冒充用户研究或史料结论；任一明显失败不得进入下一页。

1. 第一眼看到什么？
2. 一级主体是否唯一？
3. 背景是否有前、中、后关系？
4. 背景是否抢主体？
5. 是否出现“对象放在黑底上”的感觉？
6. 暗部内部是否有结构？
7. 是否出现明显 CSS radial-gradient 感？

### 18.5 连续变量、时钟与恢复

**已冻结规则**：页面变化时，光场参数在既有交接区间连续插值；不能 A02 gradient A → A03 gradient B → A04 gradient C 硬切。复用现有 scroll-driven state 和 A04 tour state，保持空间、图像尺度与信息继承。

| 候选变量名 | 职责 | 实施与验收要求 |
| --- | --- | --- |
| `fieldIntensity` | 宽光场相对强度 | 服务一级主体，不机械等于章节复杂度或 DOM opacity |
| `fieldCenterX` / `fieldCenterY` | 光场相对位置 | 随构图/镜头连续，resize 后按实际舞台映射 |
| `fieldWarmth` | 极弱局部色温关系 | 只作用空间，不能改变真实壁画原色 |
| `atmosphereDensity` | 空气距离 | 不能把雾永久合成在壁画上 |
| `edgeFalloff` | 边缘衰减与前层暗部 | 不中断主体可见范围、不形成硬环 |
| `grainOpacity` | 程序纹理的弱呈现 | 不抢眼、不闪烁、不因停滚自行运动 |

名称、单位、数量、范围及插值函数均为**待打样项目**，可按当前架构调整，不在本轮新增代码 API。连续性要求已冻结；不要求未开发章节提前具备正式参数。
