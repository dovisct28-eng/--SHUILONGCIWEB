# 模块 A 两层导航规划

确认日期：2026-09-22。状态：规则已确认，等待后续开发。

本轮仅记录功能、跳转和显隐规则，不实现导航代码，不制作正式视觉样式。适用于模块 A；模块 B 保留现有界面与交互。章节职责见 [模块 A 总规划](MODULE_A_ROADMAP.md)。

## 1. 全局导航：去哪里

| 项目 | 功能 | 点击落点 |
| --- | --- | --- |
| 品牌「水龙祠」 | 返回开屏 | A01 最终稳定 Hero，完整建筑与标题可见 |
| 建筑空间 | 进入建筑与壁画位置介绍 | A02 建筑回中后的首个稳定状态 |
| 出兵·入将 | 进入主题及后续观看路径 | A03 主题起始阅读状态 |
| 图像导读 | 直接了解《入将图》画面 | A05 整体图像首次稳定呈现的位置 |
| 进入探索 | 直接进入自主探索 | 模块 B 现有大屏入口 `http://localhost:3000/` |

导航出现后，“进入探索”始终可用，与 A06 的同名按钮行为一致，均直接进入模块 B，不先跳到 A06。只有用户主动点击才进入探索，滚动不自动跳转。

## 2. 叙事进度：在哪里

固定四个阶段：建筑空间 → 主题 → 观看路径 → 图像导读，分别对应 A02、A03、A04、A05。

- 首版仅显示当前位置，不可点击跳转，避免与全局导航重复。
- 根据实际滚动状态更新；反向滚动同步回退，高亮表示当前位置，不代表已经阅读完成。
- 跳过章节不自动标记为已读，也不建立章节解锁机制。
- A06 延续“图像导读”高亮，补充状态文字“导读结束，可进入探索”，不增加第五个阶段。

## 3. 跳过章节与继续滚动

- 首次访问与再次访问均允许通过全局导航跳过章节，不强制观看前文。
- 跳转落在目标章节首个可读稳定状态，避开文字淡出、模型半生成等过渡中间帧。
- 跨章节跳转不快速播放沿途所有动画；到达后继续由滚动推进，向上滚动仍能查看被跳过的内容。
- A04 的完整观看路径通过 A03 向下滚动进入，首版不在全局导航增加独立入口。
- 精确滚动锚点随对应章节实现确定，仍须满足同一进度对应同一画面，不能依赖之前是否播放过该章节。

## 4. 返回开屏与从探索返回

- 点击品牌返回 A01 最终稳定 Hero，不自动重播整段建筑生长动画。
- 返回后两层导航隐藏；继续向上滚动可回看开场，向下滚动重新进入 A02，不新增“重新播放”按钮。
- 进入模块 B 使用当前浏览上下文中的明确入口。浏览器返回时恢复进入探索前的章节及滚动位置：从 A02 进入就返回 A02，从 A06 进入就返回 A06。
- 返回状态由模块 A 的入口与恢复机制负责，不依赖模块 B 的热点、缩放或加载内部实现。

## 5. 两层导航的显隐

- A01 全程不显示，包括开场动画及最终 Hero 的稳定阅读区间。
- A01→A02 建筑回中期间保持隐藏；回中完成后两层导航一起出现。
- A02—A06 固定显示，不随滚动方向反复收起。
- 反向进入回中过渡时淡出；退回 A01 后完全隐藏，且不可被键盘聚焦。
- 模块 B 使用自身界面，不叠加模块 A 导航。

## 6. 后续开发与验收

导航作为模块 A 内部的共用界面接入现有连续滚动容器；具体视觉样式、尺寸及适配方案留待后续开发。

开发时检查：

1. A01 与回中过渡不提前出现导航；A02 稳定后显示，反向退出符合边界。
2. 所有全局入口抵达约定的稳定画面；快速连续点击、跳转后回滚不留下旧章节标记或错误镜头。
3. 四个阶段高亮随实际位置变化，A06 的状态文案正确，进度项不误作可点击控件。
4. 品牌返回 A01 稳定 Hero，导航隐藏且不截获键盘焦点；上下滚动均可继续。
5. 全局与 A06 的“进入探索”行为一致；从不同章节进入 B 后，浏览器返回恢复各自来源位置。
6. 预留导航空间，在已采用的桌面尺寸与较窄视口检查建筑、壁画标签、章节标题的遮挡及可读性。
7. 记录模块 A 与 B 的本地启动和入口可达条件；导航规划已确认不等于入口联调已完成。

本文件为待开发规则，不代表导航已实现或通过运行验收。
