用户本轮明确授权重新导演开屏镜头与线/实体转换，覆盖原低保真“旋转生长”的 A01 视觉动作。保留 5 屏滚动时间轴、1.2 屏稳定阅读、6.2—7.2 屏的一次回中；保留右移、左侧正文显现和 A02—A08 连续叙事。阶段函数的旧 `travel/growth` 名称继续用于外层 UI 与回归，不代表 V3 仍在缩放或旋转建筑本体。

真实 GLB、`model-source.js`、壁画位置/元数据、壁画素材与 UV、A04 镜头和路线、A05—A08、模块 B 没有修改。构建仍产生同一 83,360 三角形、3,329,000 字节的 GLB，并更新离线预览的 A01 脚本副本。低保真 Tag 的解引用 commit 与归档分支仍为 `48f272497e86e4549c5bcd0dee275ff347171a3f`。

本轮使用参考 B 的构图、光与空间层次；没有依据其建筑重建 GLB。山谷和程序化景观是数字叙事的艺术化环境，不是江永地理复原或建筑测绘材料。字体、颜色、镜头参数均为当前审图实现，未升级为全局冻结规范。

## Camera

`a01-camera.mjs` 使用两条 centripetal Catmull–Rom 曲线控制相机位置与目标。开场在主殿前侧屋檐附近 `(-3.7, 4.35, -8.7)`，朝真实主殿屋面内部 `(-1.5, 3.5, -12)` 观看；随后沿檐横移、后撤、抬升。0—18% 保持局部，32—45% 释放到整体。38—48% 平滑汇入 Hero 视角，保留原后续回中及 A04 相机所有权。

模型几何及 root scale 不动。A01 模型容器固定为 .83 的展示倍率，取消随生长进度缩放及随近景进度改变容器大小；空间尺度变化来自真实相机。最终 C 方案为原共享斜俯视叠加 `phi .35 / theta -.16 / distance 14`，窄屏适度退后。FOV 为 A01 32°、交接后恢复 34°。没有 Roll、360° Orbit 或第二相机时钟。

## Line language

沿用模型源生成的 1,056 个真实结构轮廓，保留 11 个预分配线条 geometry/material；不增加默认 WebGL line width 或引入线条库。每个线段携带 `inkRank`，以淡米灰骨线、较暗结构线和极暗纹理线分级，并在 shader 中按不同窗口建立。各构件的 draw range 再按屋面、主殿、廊道、戏台、入口、院落和局部细节逐步连接。

骨线先建立空间边界，结构线随后出现，纹理线主要在 45—58% 进入。线条没有 Bloom、霓虹、宣纸滤镜或随机位置抖动。0% 保留少量较暗的大屋檐线；没有显示全祠或早期标题卡。线条仍是单像素 LineSegments，精细边缘不等于手绘墨迹。

## Light Sweep

58—70% 的实体转换采用建筑世界坐标，不采用全局 opacity crossfade。光扫坐标为 `dot(worldPosition, (-.018, .13, .028))`；阈值由 `1.0` 移到 `-.9`，加入 .018 量级的固定空间起伏及柔和边缘。右后、较高的屋面先承光，随后进入木构、墙体、院落及较低基础。线 shader 使用同一坐标、阈值与起伏，已实体化位置的线随光扫收退。

物体透明度保持 1；shader 负责局部显现和未照亮区域的 discard。所有构件预先存在，不逐帧创建几何或 clone 材质。定制深度材质和实体材质共用 reveal / hero uniforms，阴影也随同一光扫建立；退出 A01 后 hero uniform 为 0，局部显现与空气处理均关闭。真实壁画排除在这些材质和深度材质之外。

初版光扫上沿过高，58—62% 几乎保持静止；最终根据实际模型范围降低上沿，61% 已能看到远端屋面，64% 为实体屋面/墙体与未完成的近端线构并存。最终五状态见 [光扫截图](validation/a01-cinematic-v3/03-light-reveal-final/)。

## Lighting、空气与 Post

原一盏太阳方向光及 Hemisphere 补光保留。A01 太阳位于 `(-16,22,16)`，暖色 `#ffd4a1`，Hero 强度 4.5；补光为冷灰蓝，强度 .72，明显弱于主光；曝光 .98。该光源在 Hero 视角中对应右上/右后方向，建筑、地形、树冠、灌木和石块共用它。近地雾使用与空气一致的克制灰色，不声称具有体积散射物理精度。

屋瓦改为暖中性灰，砖墙保持低饱和红褐，台基石材降低亮度。PBR 原贴图、UV 和纹理文件不变。材质 shader 依据与相机的真实距离逐渐降低远端对比、向空气色靠拢；墙脚有轻量低空空气。没有用强 DOF 模糊远端结构。

继续使用原两遍 HDR / 深度 Post：2 samples MSAA、12 点轻量 depth AO、轻冷暖调色和极轻暗角。没有新增后处理库、第二 Renderer、第二渲染 RAF、Bloom、LUT、grain 或色散。Post DPR 上限仍为 1.5；1440 / 1920 的目标缓冲估算约 31.41 / 46.71 MiB，不代表总 GPU 内存。

## Environment integration 与资源

近地坡面以 144×144 网格增加接近台基外侧的土坡，内部仍在院落下方；外侧土脊带有非均匀起伏，覆盖石基下部。坡面自身不改变真实建筑。非对称实例化植被保留，墙脚和近端采用六个不同高度的组团而非平均环绕；近镜树冠构成暗部。近景、建筑和中景树通过同一相机产生真实视差，没有用图层横滑伪造全部深度。少量真实石基仍可见，目的为打断独立台座的完整轮廓，不是抹掉建筑基础。

六片固定世界空间雾分布于前端墙脚、侧墙、谷地与远端，配合地形承光、树影、石块和部分下部遮挡软化基础边缘。建筑近端材质保持清晰，远端更接近环境空气色。天空/谷地 DOM 使用分开的进度窗口；近地景观随 70—82% 建立，文字继续在 82—100% 显现，随后完整阅读。

新增 `environment-assets/a01-v3/karst-valley.webp` 为 1586×992 / 102,818 B，两个 DOM 视图共用同一本地 URL。用内置 imagegen 生成不含建筑的艺术化远景，Sharp 仅进行 WebP 编码，没有修复、重绘或覆盖文物。原 V2 资源保留。完整 prompt、原始生成文件及 SHA256 见 [资产记录](../shuilong-temple/environment-assets/a01-v3/README.md)。页面运行不依赖生成工具或远程 API。

## 状态恢复与降级

停止滚动保持状态；倒滚按同一纯进度恢复。A01 退出时环境、Post、材质、灯光、FOV 和线条复位，A04 拥有相机时 A01 权重为 0。A04 的真实自动路线、墙位和三幅导读没有改动。

减少动态效果时从开场直接显示完整稳定 Hero，包括文字；相机、文字位置和景观固定，取消穿行、复杂显现和视差。依然能滚入 A02，三幅导读与主动探索入口保留。

分别阻断 A01 环境模块（同时覆盖植被/雾）、Post 模块、远景图片和 Art 模块时，仍能显示建筑与正文并进入 A02。另外实际注入错误 GLSL，确认 Post 编译失败进入已有 catch、关闭增强并直接渲染正常建筑；临时 shader 错误回调在 finally 中恢复，A02 仍可进入。没有锁滚轮、强制滚动、新增开场自动播放或额外 UI。
