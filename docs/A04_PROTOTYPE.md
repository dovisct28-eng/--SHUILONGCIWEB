## 评审决定

- 第五幅→第一幅→第二幅的顺序保留。参考图 01 已沿侧廊前行，因此是“前往第一幅”的中途状态；全景总结 01 改为第五幅观察站位，02 生长至第一幅，03 沿对侧返回第二幅。
- 第五幅观看后先转回戏台方向再前行，横向左转至第一幅，然后转向主殿返回第二幅。不是一直向前或一直向左。
- 第二幅首次观看属于空间镜头；回撤后用户下滚的聚焦才属于图像交接。A05 不应重置相机再放大。
- 不锁滚轮；提前离开者不保证看完自动过程。取消自动过程后，以短暂连续桥接进入统一交接路径，反向恢复完整路线。
- 连续斜俯视为本轮设计表达，不称为实景第一人称漫游。壁画区域仍为模型占位面，未加载高清母版。

## 滚动与自动时间线

距离以视口高度计：A01—A03 原有区间保持至 13.2；13.2–14 为连续放大入口；14–16 为自动播放停留区；16–18 为用户滚动驱动的第二幅交接。边界保留小于约两像素的容差，避免不同视口的滚动取整误激活。

自动时间线为 58 秒，可跳过或重播。停滚仍自动推进，结束保持全景，不滚动页面。边界回退到 13.65 以下取消未完成播放；完全回到 A03 清理路线并恢复既有模型状态。自动完成后，在 A04 范围内回看不重播；从 A05 返回直接恢复完整路线。

| 秒数 | 动作 |
| --- | --- |
| 0–5 | 从放大全景连续进入主殿出发站位，面向戏台 |
| 5–8 / 8–11 | 转向第五幅 / 稳定观看 |
| 11–19 | 转回戏台方向，沿出发侧前行 |
| 19–23 / 23–26 | 左转并观察第一幅 / 稳定观看 |
| 26–36 / 36–39 | 转向主殿，返回第二幅 / 稳定观看 |
| 39–45 | 抬高、回撤至完整建筑 |
| 45–46 | 全景短暂停留 |
| 46–48 | 第五幅出发站位保持 |
| 48–52 / 52–54 | 路线延伸到第一幅 / 短暂停留 |
| 54–58 | 沿对侧返回第二幅，前段保留 |
| 58 以后 | 完整路线保持，等待用户下滚 |

刷新恢复与减少动态效果直接呈现终态。后台以 `document.hidden` 暂停计时，返回后继续。播放中下滚取消自动播放，以 800ms 连续桥接当前镜头至可逆交接路径。跳过直接呈现全景终态；重播只保留一套有效时钟。按钮使用原生 button；隐藏章节为 hidden/inert。

## 空间坐标依据与边界

模型 Y 向上、+Z 向入口/戏台、−Z 向主殿。壁画墙面坐标来自 `mural-locations.json`；行走线由本次设计配置，不是现场测量。

| 状态 | 镜头位置 | 观察目标 |
| --- | --- | --- |
| 出发 | (-2.7, 3.8, -11.75) | (-2.7, 2, 4.8) |
| 第五幅 | (1.2, 5.8, -11.75) | (-4.52, 1.85, -11.75) |
| 横向左转 | (-2.7, 3.8, 4.8) | (3.8, 1.55, 4.8) |
| 第一幅 | (2.6, 6.8, 4.8) | (4.865, 1.55, 4.8) |

| 回撤中间态 | (1, 12, -10) | (0, 0, -3) |

这是高于行走线的辅助观察镜头，镜头位置不等于人的脚下站位。路线起点为 (-2.7, .56, -11.75)，出发侧 X=-2.7，横向跨越 Z=4.8，到第一幅观察点 (3.8, .36, 4.8)；回程转入 X=2.7，再至 (2.7, .56, -11.75)。主殿台阶过渡在 Z=-8.05 至 -7.4。柱间净距由现有源码中的柱位置验证；不推导实际建筑可通行性。

屋顶在 A04 渐隐。2026-09-24 共用模型已重新布置围墙装饰条与廊柱，第一幅占位面不再与装饰条重叠；A04 的临时淡化处理已移除。原有标记可能随局部镜头出画，仅当前目标需清楚可辨。

## 全景与交接构图

全景相机方向 theta=4.4、phi=.72，目标 (0,-2.3,-1.75)。按投影与视口宽高比二分计算距离，约束初始投影宽≤68%、高≤61%；实际可见模型比例通过投影所有可见几何顶点测量，排除全局地面、阴影、文字和透明屋顶，而非使用 iframe CSS 大小。

| 视口 | 可见模型宽度 | 可见模型高度 |
| --- | --- | --- |
| 1440×900 | 64.5% | 56.3% |
| 1920×1080 | 60.6% | 58.8% |
| 1366×768 | 60.5% | 58.8% |
| 1024×768 | 65.1% | 47.2% |

高度不硬凑原任务书 60%–80%，遵循评审通过的优先级：完整轮廓、路线与文字安全区优先。全景模型占屏宽均超过60%。壁画墙在轻量写实阶段已按照片校准为设计模型比例，A04 的真实展示图继续按原始宽高比进入安全构图；不能把模型单位解释为现场实测尺寸。
