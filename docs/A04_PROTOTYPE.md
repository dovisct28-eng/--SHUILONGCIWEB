# A04 空间观看路径：实现与验收记录

日期：2026-09-22。范围：模块 A，A04 与 A03/A05 必要交接。依据：用户提供的 V2.0 任务书、三帧路线图及本任务评审后用户确认的修订方案。基线本地提交 `9b87625`；GitHub 连接失败，不能声称已核实最新远程。

## 评审决定

- 第五幅→第一幅→第二幅的顺序保留。参考图 01 已沿侧廊前行，因此是“前往第一幅”的中途状态；全景总结 01 改为第五幅观察站位，02 生长至第一幅，03 沿对侧返回第二幅。
- 第五幅观看后先转回戏台方向再前行，横向左转至第一幅，然后转向主殿返回第二幅。不是一直向前或一直向左。
- 第二幅首次观看属于空间镜头；回撤后用户下滚的聚焦才属于图像交接。A05 不应重置相机再放大。
- 不锁滚轮；提前离开者不保证看完自动过程。取消自动过程后，以短暂连续桥接进入统一交接路径，反向恢复完整路线。
- 连续斜俯视为本轮设计表达，不称为实景第一人称漫游。壁画区域仍为模型占位面，未加载高清母版。

## 文件与接口

- `module-a/a04/path.mjs`：镜头关键帧、世界坐标路线和纯函数采样。
- `module-a/a04/controller.mjs`：自动播放、滚动交接、恢复、按钮及异常处理。
- `module-a/a04/styles.css`：简短顶部标题、底部文字安全区。
- `shuilong-temple/a04-scene.mjs`：模型内相机接管、路线、节点、投影构图及遮挡处理。
- 现有 iframe 公开 `setA04(state|null)`、`getA04State()`、`getA04Overview()`、`getA04Handoff()`。
- 同一渲染循环在 A04 激活时使用 A04 相机；否则沿用已有环绕相机，避免两套控制同时写入。模型、渲染器、GLB 均只创建一次。
- `getA04State()` 返回 `targetMuralId: mural-02`、`handoffStartCamera`、`handoffEndCamera`、`handoff` 进度、当前相机和几何投影包围盒。A05 后续应沿用此状态。
- 外层延续既有同源接口；ready 消息同时校验 window 与 origin。

## 滚动与自动时间线

距离以视口高度计：A01—A03 原有区间保持至 13.2；13.2–14 为连续放大入口；14–16 为自动播放停留区；16–18 为用户滚动驱动的第二幅交接。边界保留小于约两像素的容差，避免不同视口的滚动取整误激活。

自动时间线为 58 秒，可跳过或重播。停滚仍自动推进，结束保持全景，不滚动页面。边界回退到 13.65 以下取消未完成播放；完全回到 A03 清理路线并恢复既有模型状态。自动完成后，在 A04 范围内回看不重播；从 A05 返回直接恢复完整路线。

| 秒数 | 动作 |
| --- | --- |
| 0–5 | 从放大全景连续进入主殿出发站位，面向戏台 |
| 5–8 / 8–11 | 转向第五幅 / 稳定观看 |
| 11–19 | 转回戏台方向，沿出发侧前行 |
| 19–23 / 23–26 | 左转并观察第一幅 / 稳定观看 |
| 26–36 / 36–39 | 转向主殿，返回第二幅 / 稳定观看 |
| 39–45 | 抬高、回撤至完整建筑 |
| 45–46 | 全景短暂停留 |
| 46–48 | 第五幅出发站位保持 |
| 48–52 / 52–54 | 路线延伸到第一幅 / 短暂停留 |
| 54–58 | 沿对侧返回第二幅，前段保留 |
| 58 以后 | 完整路线保持，等待用户下滚 |

刷新恢复与减少动态效果直接呈现终态。后台以 `document.hidden` 暂停计时，返回后继续。播放中下滚取消自动播放，以 800ms 连续桥接当前镜头至可逆交接路径。跳过直接呈现全景终态；重播只保留一套有效时钟。按钮使用原生 button；隐藏章节为 hidden/inert。

屋顶在 A04 渐隐。2026-09-24 共用模型已重新布置围墙装饰条与廊柱，第一幅占位面不再与装饰条重叠；A04 的临时淡化处理已移除。原有标记可能随局部镜头出画，仅当前目标需清楚可辨。

## 全景与交接构图

全景相机方向 theta=4.4、phi=.72，目标 (0,-2.3,-1.75)。按投影与视口宽高比二分计算距离，约束初始投影宽≤68%、高≤61%；实际可见模型比例通过投影所有可见几何顶点测量，排除全局地面、阴影、文字和透明屋顶，而非使用 iframe CSS 大小。

| 视口 | 可见模型宽度 | 可见模型高度 |
| --- | --- | --- |
| 1440×900 | 64.5% | 56.3% |
| 1920×1080 | 60.6% | 58.8% |
| 1366×768 | 60.5% | 58.8% |
| 1024×768 | 65.1% | 47.2% |

高度不硬凑原任务书 60%–80%，遵循评审通过的优先级：完整轮廓、路线与文字安全区优先。全景模型占屏宽均超过60%。交接相机正对第二幅，距离由壁面宽5.5、高2及视口计算，使壁面完整进入安全构图；模型比例为示意，不保证与未来原图逐像素对齐。

- 18项单元测试：A01—A03 13项，A04 5项，覆盖关键帧停留、连续性、路线累计、章节反向和模型柱间净距。
