# A05 第五幅壁画导读：下一轮开发任务书

状态：待开发。依据：2026-09-24 [模块 A 总规划](MODULE_A_ROADMAP.md)、[设计规格](DESIGN_SPEC.md)、[内容地图](CONTENT_MAP.md)及 [A04 实现与验收记录](A04_PROTOTYPE.md)。本文件仅定义下一轮范围，不代表 A05 已实施或验收。

## 目标与边界

A05 让用户从 A04 完整路线全景中的第五幅节点，进入第五幅真实图像，完成基础导读，然后为 A06 第一幅做交接。第五幅必须有独立整体画面、简短介绍和 1—3 个经核实的可见线索。不得只作为通向《入将图》的过场。

仅修改模块 A 的 A04→A05 交接所需最小接口与 A05 低保真页面；不改变 A04 的第五幅→第一幅→第二幅观看顺序、58 秒自动段、回撤、路线总结或共用模型结构；不开发 A06—A08，不修改模块 B。

## 开发前核对

1. 读取 A04 当前控制器、场景公开接口、滚动进度和测试。当前 16–18 视口高度旧末段仍聚焦第二幅，`targetMuralId: mural-02` 是已实现旧交接；不要把它当成新 A05 的目标。
2. 核对 `mural-05` 模型节点与展示图 `水龙祠壁画素材/网页展示图/mural-05-display.webp`。高分辨率细部候选为 `水龙祠壁画素材/高清展示图/mural-05-detail.webp`；确认尺寸、裁切与颜色，保留母版不变。
   这些 WebP 目前在本地工作树存在但未被 Git 追踪；开发前须确认素材入库或稳定本地路径，不能假定其他克隆已具备。
3. 逐项核实拟展示的 1—3 个可见线索在图中的位置及来源；图像观察、论文释读、项目设计决定分别记录。资料不足时只展示已核实的整体图像与基本信息，不编造局部解释。

## 交互状态

1. A04 自动观看结束停在完整建筑全景、⑤→①→②路线和三节点。用户继续下滚，A05 从第五幅节点建立视觉焦点，不重播三维行走，也不从第二幅镜头突然飞回第五幅。
2. 第五幅真实图像首次稳定展示整体构图；短文与视觉线索逐步出现；最后清除标注，恢复完整画面。局部放大是受控叙事展示，不提供自由缩放、人物热点或详情面板。
3. A05 末端只预留向 A06 的 ⑤→① 简化空间关系交接，不开发第一幅正式导读。
4. 反向滚动回到 A04 完整路线终态；从全局“图像导读”直达 A05 时落在第五幅首个可读稳定状态。刷新、快速跨段、跳过 A04 后进入 A05 均应有一致的可恢复状态。

## 接口与实现约束

- 将 A04 输出定义为中性的完整全景、路线、三节点位置与空间定位数据；移除“第二幅是 A05 唯一目标”的规划绑定。具体数据形状以当前代码最小改动为准，更新接口说明。
- 清理或调整旧第二幅交接预览与 `getA04Handoff()`、`targetMuralId` 的使用，但只限 A04→A05 边界。保留历史验收文档对旧实现的真实记录，并追加新实现差异。
- 大图按需加载，优先展示 Web 版本；不一次载入所有高清图，也不改壁画母版。
- 章节仍属同一连续滚动叙事；A04 内部自动播放不锁滚轮、不自动滚页，A04→A05 由用户滚动驱动且可逆。
