# AI 融合 V3

本轮采用 V2 已生成的 B/A 四机位候选与安全蒙版，不新增无标定整景图。来源和生成记录继续追溯 V2 `generation-manifest.json`、`AI_SCENE_RECORD.md`。AI 是环境艺术候选，不作为文物图像。

V3 独立 surface-layer 复用真实 Combined B 原三角面、相机矩阵及 depthTest。墙/地/木构最大权重从 V2 .74/.30/.32 调到候选 .90/.48/.58；蒙版和投影边界未放大。新增实例级半球补光 .65、暖反射点光3.5（无可见灯具），以及廊屋面原材质克隆后的纹理 emissive .11，随进入室内渐入；外部 time≤.85 权重归零，不修改源模型。

材质自发光是克制暗部可读性候选，不能等同于真实光照复原。对比按钮同时关闭新补光；选原模型也关闭新补光。原型退出后由页面实例销毁，不修改正式运行实例。

投影仅适用于门内至第一铺四个已标定机位；第二至五铺只保留有限补光，关闭第一铺 AI 图投影，避免拉伸借用。后续场景 AI 尚未新增，需先确认墙位和对应机位。动态测试包括前后机位、转向、正面阅读、模式切换；首铺转正时投影退出，原壁画不调色。
