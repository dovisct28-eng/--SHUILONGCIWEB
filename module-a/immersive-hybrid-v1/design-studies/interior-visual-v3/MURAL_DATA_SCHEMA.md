# 五铺数据与复用

`murals.json` 为独立 V3 的五铺配置。id/order/title 为设计编号与观看标题；wall/position/width/height 来自 `shuilong-temple/mural-locations.json`，单位为模型设计单位；rotation 为朝内墙面法线的 Y 旋转；image/source 分别为运行资源与可追溯母版；camera 是候选停靠；wallStatus 与 registration 分开记录现场证据和图像配准状态。

全幅/细读共用一套 DOM、拖动缩放及全图位置索引。`setImageSize` 从图片自然尺寸更新 fit/pan/minimap，不把第一铺的 2880×990 写死到其他图。一次只加载当前铺图像，保留当前相邻资源的浏览器缓存；不加载 150–300MB 母版。第三/四铺附带照片是原 JPG 逐字节复制，总计约 580KB，未裁切、修复或增绘。

第一铺三处观察点沿用 V2，其余铺提供自由缩放而不复制第一铺观察解释。逐铺有语义的观察点仍待独立核对，不把自由缩放说成已完成全部观察点设计。

第一铺原状态机保持。第二/五铺使用候选表面淡入和共用阅读；第三/四铺不把含梁架、砖基的未校正照片贴成复原壁画。返回全幅、返回墙面、上一铺与主动继续下一铺由显式操作触发；全幅或细读滚轮不会跳到下一铺。
