# 视觉系统：暗廊寻迹 → 壁面显影 → 图像细读

本轮为候选系统，不新增全局视觉冻结。依据 `docs/HIFI_VISUAL_SPEC.md` 的建筑建立空间、壁画主导观看、界面克制退后，以及任务书 V2 的独立原型授权。

## 层级与材质

入廊：建筑为一级，位置与行动为二级。原木柱、檐口与墙面保持结构，AI 增加安全区域内的自然颗粒和局部照度。整景图没有直接覆到屏幕上。未新增射灯、灯带、景观、体积光、循环雾或粒子。

显影：第一铺从暗态进入正常显示，墙上的黑体仅承担观看提示，不加光晕和金边。沿用原 500 / 850 / 900 ms 淡入、停留、亮起时序；实例级亮度映射改为 smootherstep，端点仍为 0.14 与 1。0.14 是线性色彩乘数，不是感知亮度百分比。

全幅：真实图像为一级。将标题与位置/尺度分置于顶部，以一条细线组织下方导语、原介绍和单一细读入口。返回墙面为较弱动作。没有画框、图像阴影、滤镜、渐变覆盖或新增文物纹样。

细读：图像保持原色，侧栏不覆盖图像；缩略图视窗交代所在位置，观察点只描述旗幡、骑乘与并行人物等可见形态。无身份、仪式、象征或历史顺序推断。

## 候选 Token

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 墨灰 | `#141B1E` | 阅读底色，与建筑暗部衔接 |
| 米灰 | `#DED8CB` | 标题、当前状态和主要动作 |
| 暖中灰 | `#B0B1A9` | 正文、位置和辅助信息 |
| 暖灰 Accent | `#C7B79C` | 当前细线、焦点、长卷范围 |
| 分隔线 | `#8C8D82` / 30% | 编辑分区，不承担唯一状态含义 |

阅读底色上的主文字、次文字对比度分别约 12.3:1、8.0:1；空间叠加文字仍需结合实际背景审阅。Accent 不作为跨 A02/A04/A08 已冻结色彩。真实图像不受 UI 色板处理。

## 字体与布局

- 复用本地 `a01-serif.woff2`，`font-display: swap`；没有新增字体文件。缺字回退 Songti SC / SimSun。功能与正文使用 Microsoft YaHei / PingFang SC / system-ui 黑体。
- 桌面外边距 5vw（32–100px）；顶部功能区 100px，低高度视口缩至 82px。
- 全幅标题 44px；1920 视口 52px；768 高视口 36px。正文 14px / 1.95，宽屏 16px，低高度 13px。这些较规范推荐正文小，是本轮以原图完整显示为优先的独立样稿值，待审图。
- 细读右栏约 258px，宽屏 290px；长卷索引约 220px。原图始终等比缩放，没有将图像拉成容器比例。
- 完整阅读由 CSS Grid 分配上方标题、图像主体与下方信息，适配 1440×900、1920×1080、1366×768。1024 以下提供布局回退；未以移动端验证替代桌面验收。

## 动态与操作

空间行进与显影继续使用既有轨道和锁定规则，不创建第二条相机路径。叠加纹理沿四机位投影矩阵插值；转向壁画/转正时退出。没有常驻额外 RAF。

模型完成原位展开后，HTML 真图从原 compositor 的最终四角矩形接续到编辑版面，650ms 平滑位移/等比缩放；信息后出现。反向先还原矩形，再接回原阅读→墙面的逆过程。没有直接切黑。

局部定位 650ms；拖拽/滚轮实时反馈。`prefers-reduced-motion` 或预览选项减少动态时省略新增过渡，既有状态机沿用其减少动态逻辑。键盘可进入细读画面，用方向键平移、+/− 缩放、0 复位，Escape 返回完整图像。
