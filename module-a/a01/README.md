# A01 浏览器低保真原型

在仓库根目录运行 `node module-a/a01/server.mjs`，打开 `http://127.0.0.1:4173/module-a/a01/`。

页面使用 5 个视口高度映射 A01 四阶段动画、1.2 个视口高度作为稳定阅读区间、1 个视口高度过渡到 A02 占位。真实三维模型来自 `shuilong-temple/水龙祠-交互预览.html`，通过 `setIntroProgress(0…1)` 接口按滚动进度显现和旋转；A01 中模型 iframe 禁止直接交互，并始终隐藏壁画标记。

运行进度映射测试：`node --test module-a/a01/progress.test.mjs`。

当前空间入口是低保真几何占位。介绍文字是设计引导语草案，正式素材、旋转角度、镜头和阅读区间长度仍需视觉验收后调整。
